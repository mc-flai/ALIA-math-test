This repository contains the dataset and code for evaluating Large Language Models (LLMs) on high-school-level mathematical reasoning in Catalan, using questions from the Kangaroo Mathematics Competition (https://cangur.alcoi.upv.es/edicions.php). The questions that do not contain any figures are gathered in a single file. The dataset is formatted as an Excel file with questions, multiple-choice options, ground truth answers, and scores (dataset)

It includes the scripts to access models such as GPT, DeepSeek, Gemini, Gemma, Llama, and ALIA (codes). 

Experiments were conducted via API services and local/cloud instances for different model sizes. The raw results, as well as an updated Excel file with the response of each model and its reasoning process, are available, too (raw_responses).
