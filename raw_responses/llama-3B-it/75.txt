Raonament:

Per determinar si el punt $P(2, -1)$ pertany a la recta representada per l'equació $ax + by = c$, podem substituir els valors del punt en l'equació i verificar si el resultat és verificable.

Anem a examinar cada opció:

A) $a = −1, b = 1, c = −3$

Sustituïm els valors del punt en l'equació:

$−1(2) + 1(-1) = −3$

$−2 − 1 = −3$

Aquesta equació és verificable, però no és necessari que sigui el cas més simple.

B) $a = 1, b = 0, c = 2$

Sustituïm els valors del punt en l'equació:

$1(2) + 0(-1) = 2$

$2 + 0 = 2$

Aquesta equació és verificable.

C) $a = 0, b = 3, c = −3$

Sustituïm els valors del punt en l'equació:

$0(2) + 3(-1) = −3$

$0 − 3 = −3$

Aquesta equació és verificable.

D) $a = 10, b = 15, c = 5$

Sustituïm els valors del punt en l'equació:

$10(2) + 15(-1) = 5$

$20 − 15 = 5$

Aquesta equació no és verificable, ja que $5 \neq 5$.

E) $a = 1, b = 2, c = 1$

Sustituïm els valors del punt en l'equació:

$1(2) + 2(-1) = 1$

$2 − 2 = 1$

Aquesta equació no és verificable, ja que $0 \neq 1$.

Però, en el cas D) $a = 10, b = 15, c = 5$, la equació no és verificable, ja que $5 \neq 5$. Això significa que el punt $P(2, -1)$ no pertany a la recta representada per l'equació $ax + by = c$ quan $a = 10, b = 15, c = 5$.

Resposta: D
