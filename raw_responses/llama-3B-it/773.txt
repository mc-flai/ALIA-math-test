Raonament:

Per començar, considerem les quatre línies rectes que passen per l'origen de coordenades. Podem representar-les amb les equacions:

y = mx (on m és la pendentat)

Aquestes línies intersequen la paràbola y = x² - 2 en vuit punts. Podem representar aquests punts com (x, y) i escriure les següents equacions:

x² - 2 = mx... (1)
x² - 2 = -mx... (2)
x² - 2 = mx + 2... (3)
x² - 2 = -mx - 2... (4)

Aquestes equacions representen les interseccions de les línies amb la paràbola. Per trobar el producte de les coordenades x dels punts d'intersecció, podem multiplicar les equacions (1) i (2):

(x² - 2)(x² - 2) = m(x)(-x)
x⁴ - 4x² + 4 = -mx²
x⁴ + mx² - 4x² + 4 = 0

Aquesta equació és una equació quartica en x². Per a que aquesta equació tingui solucions reals, el discriminant (D) ha de ser no negatiu. El discriminant d'una equació quartica en x² és:

D = b² - 4ac

En aquest cas, a = 1, b = m i c = -4x² + 4. Per tant:

D = m² - 4(1)(-4x² + 4)
D = m² + 16x² - 16

Per a que D sigui no negatiu, m² + 16x² - 16 ≥ 0. Aquesta desigualtat és sempre verda per a qualsevol valor de m i x², però no és suficient per garantir que les equacions (1) i (2) tingui solucions reals.

Per trobar el producte de les coordenades x dels punts d'intersecció, podem multiplicar les equacions (3) i (4):

(x² - 2)(x² - 2) = m(x + 2)(-x - 2)
x⁴ - 4x² + 4 = -m(x² + 4x + 4)
x⁴ + mx² + 4mx + 4m = -4x² - 8x - 8
x⁴ + mx² + 4mx + 4m + 4x² + 8x + 8 = 0

En aquest cas, a = 1, b = m + 4 i c = 4m + 8. Per tant:

D = (m + 4)² - 4(1)(4m + 8)
D = m² + 8m + 16 - 16m - 32
D = m² - 8m - 16
