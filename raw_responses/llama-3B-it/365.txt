Anomenem les longitudes dels tres costats del rectangle a x, y i z.

Segons la pregunta, si sumem les longitudes de tres dels costats, el resultat obtingut és 20 o 22. Això significa que podem escriure les següents equacions:

x + y + z = 20... (1)
x + y + z = 22... (2)

Aquestes equacions mostren que la suma de les longitudes de tres dels costats és constant, independentment de quina combinació de costats s'agreguen.

Per trobar el perímetre del rectangle, cal sumar les longitudes de tots els costats. El perímetre d'un rectangle és igual a 2(l + w), on l és la longitud i w és el més amplà.

A partir de les equacions (1) i (2), podem deduir que la suma de les longitudes de tots els costats és:

x + y + z = 20... (1)
x + y + z = 22... (2)

Sumant les dues equacions, obtenim:

2(x + y + z) = 20 + 22
2(x + y + z) = 42

Dividint per 2, obtenim:

x + y + z = 21

Aquesta suma és igual al perímetre del rectangle, que és igual a 2(l + w). Per tant, el perímetre del rectangle és:

Perímetre = 2(l + w) = 2(x + y + z) = 2(21) = 42
