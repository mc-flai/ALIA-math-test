Raonament:

1. El problema diu que Jordi tria un nombre, li'n resta 1 i al resultat li'n suma 2. Això significa que el nombre inicial (x) satisfa la següent equació:

x - 1 + 2 =?

Simplifiquem l'equació:

x + 1 =?

Aquesta equació no és suficient per determinar el valor de x, però podem continuar amb el problema.

2. Després, Jordi divideix el resultat per 3. Això significa que el resultat anterior (x + 1) s'ha dividit per 3:

(x + 1) / 3 =?

Aquesta equació no és suficient per determinar el valor de x, però podem continuar amb el problema.

3. Després, Jordi multiplica el nombre que ha obtingut per 4 i obté 56. Això significa que el resultat anterior (x + 1) s'ha multiplicat per 4 i ha donat 56:

(x + 1) × 4 = 56

Dividim les dues parts per 4:

x + 1 = 14

Aquesta equació permet determinar el valor de x:

x = 14 - 1

x = 13

Però, aquesta no és una de les opcions. Podem revisar les equacions anteriors per veure si hi ha alguna connexió amb les opcions.

Revisem la segona equació:

(x + 1) / 3 =?

Podem multiplicar les dues parts per 3 per eliminar la divisió:

x + 1 = 3 × 14

x + 1 = 42

Aquesta equació permet determinar el valor de x:

x = 42 - 1

x = 41

Això coincideix amb una de les opcions.

Resposta: D) 41
