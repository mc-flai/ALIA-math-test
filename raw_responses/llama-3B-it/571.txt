Analicem les equacions donades:

a + 2 = b - 2
b - 2 = c · 2
c · 2 = d / 2

A partir de la primera equació, podem expressar b en termes d'a:

b = a + 4

A partir de la segona equació, podem expressar c en termes de b:

c = (b - 2) / 2
c = ((a + 4) - 2) / 2
c = (a + 2) / 2

A partir de la tercera equació, podem expressar d en termes de c:

d = 2c
d = 2((a + 2) / 2)
d = a + 2

Ara, compararem els valors de a, b, c i d:

a + 2 = b - 2
a + 2 = c · 2
a + 2 = d / 2

Totes les equacions suggereixen que a + 2 és igual a cada una dels quatre nombres. Per tant, el nombre més gran dels quatre nombres és a + 2, que és equivalent a d.
