Raonament:

Primera etapa: Analicem les equacions donades.

2017 + x = y²... (1)
2017 + y = x²... (2)

Segona etapa: Podem reorganitzar les equacions per aïllar x i y.

x = y² - 2017... (3)
y = x² - 2017... (4)

Tercera etapa: Sustituïm l'expressió de y per x en la primera equació.

x = (x² - 2017)² - 2017

Això es pot expandir i simplificar per obtenir una equació quartica en x.

Quarta etapa: Resollem l'equació quartica per x.

Després de simplificar i resoldre, obtenim dos possibles valors per x: x = 2016 o x = -1008.

Quinta etapa: Sustituïm els valors de x en les equacions originals per determinar els valors de y.

Si x = 2016, llavors y = 2016² - 2017 = 2016 - 1 = 2015.

Resposta: C)

Si x = -1008, llavors y = (-1008)² - 2017 = 1008² - 2017 = 1008 - 1 = 1007.

Sisena etapa: Comprovem si els valors de x i y satisfont les condicions originals.

Si x = 2016 i y = 2015, llavors 2017 + 2016 = 2015², que no és igual a 2017 + x = y².

Si x = -1008 i y = 1007, llavors 2017 + (-1008) = 1007², que és igual a 2017 + y = x².

Sèptima etapa: Ensenyem la resposta correcta.

La resposta correcta és C) -1008.
