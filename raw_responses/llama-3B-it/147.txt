(3x + 4y) = 4(5x - 2y)

3x + 4y = 20x - 8y

A continuació, podem reorganitzar l'equació per aïllar les variables x i y:

3x - 20x = -8y - 4y

Això es simplifica a:

-17x = -12y

A continuació, podem dividir per -17 per aïllar x:

x = (12/17)y

(2x + 5y) / (4x + 3y) = (2((12/17)y) + 5y) / (4((12/17)y) + 3y)

(24/17)y + 5y) / ((48/17)y + 3y)

(24/17 + 85/17)y) / ((48/17 + 51/17)y)
