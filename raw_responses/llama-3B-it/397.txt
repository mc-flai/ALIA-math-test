Comptem amb la identitat trigonomètica:

tan x + cot x = π

A partir d'aquesta identitat, podem reescriure-la en termes de sen i cos:

sin x / cos x + cos x / sen x = π

Multiplicant per cos x sen x, obtenim:

sin^2 x + cos^2 x = π cos^2 x sen x

Simplificant, obtenim:

1 = π cos^2 x sen x

A partir d'aquesta expressió, podem reescriure-la en termes de sin x · cos x:

sin x · cos x = 1 / π

La resposta correcta és:

Resposta: E) 2/π
