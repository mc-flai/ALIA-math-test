Anem a considerar el nombre de partides que es jugaran en el torneig. Cada jugador jugarà exactament una vegada contra tots els jugadors dels altres equips. Si hi ha n equips, cada jugador jugarà n-1 partides.

El nombre total de partides jugarades serà igual al doble del nombre de partides que jugarà cada jugador, però dividit per 2, per no comptar les partides que jugarà cada jugador dos vegades (una vegada contra cada jugador de l'altre equip). Això es igual a:

(2n-2) * n / 2

Per simplificar, podem escriure:

n(2n-2) / 2

Aquesta expressió representa el nombre total de partides que es jugaran en el torneig.

El problema estableix que no es possible jugar més de 250 partides en total. Podem establir una desigualtat per representar aquesta restricción:

n(2n-2) / 2 ≤ 250

Multiplicant per 2 per eliminar la fracció, obtenim:

n(2n-2) ≤ 500

Aquesta desigualtat representa la restricción que impossem el problema.

Per trobar el màxim nombre d'equips que poden participar en el torneig, podem intentar trobar el màxim valor de n que satisfai aquesta desigualtat.

Podem escriure la desigualtat com a:

2n^2 - 2n - 500 ≤ 0

Aquesta desigualtat és una desigualtat quadràtica. Podem factoritzar-la per obtenir:

(2n + 25)(n - 20) ≤ 0

Aquesta desigualtat és igual a zero quan:

2n + 25 = 0 o n - 20 = 0

Resolent aquestes equacions, obtenim:

n = -12,5 o n = 20

Però n no pot ser negatiu, per tant, el màxim valor de n és 20.
