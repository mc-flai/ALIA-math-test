Raonament:

El nombre ab0 té tres xifres i és igual a la suma dels cubs de les seues xifres. Això significa que:

* La xifra de les centenes és a
* La xifra de les desenes és b
* La xifra de les unitats és 0

Per a que el nombre ab0 sigui igual a la suma dels cubs de les seues xifres, cal que:

a + b + 0 = a^3 + b^3 + 0^3

Simplificant l'equació, obtenim:

a + b = a^3 + b^3

Aquesta equació no és fàcil de resolver, però podem provar les opcions de resposta per veure quina és la correcta.

Probant les opcions, obtenim:

* A) a, 0, b: a + 0 + b ≠ a^3 + 0^3 + b^3 (no és igual)
* B) a − 1, b, 0: a - 1 + b ≠ a^3 + b^3 (no és igual)
* C) a, b - 1, 0: a + (b - 1) ≠ a^3 + (b - 1)^3 (no és igual)
* D) a, b, 1: a + b + 1 ≠ a^3 + b^3 + 1 (no és igual)
* E) a, 1, b: a + 1 + b ≠ a^3 + 1^3 + b^3 (no és igual)

Però, si probem aquesta última opció, obtenim:

a + 1 + b = a^3 + 1^3 + b^3

Simplificant l'equació, obtenim:

a + b + 1 = a^3 + b^3 + 1

Aquesta equació és igual a la que volem que sigui el nombre ab0. Per tant, la resposta correcta és:

Resposta: E) a, 1, b
