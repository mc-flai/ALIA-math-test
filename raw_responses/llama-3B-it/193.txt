ac + ad + bc + bd = (c + d)(a + b)

ac + ad + bc + bd = 4(a + b)

A continuació, podem reescriure la següent equació:

68 = 4(a + b)

Dividint per 4, obtenim:

17 = a + b

A continuació, podem reescriure la següent equació:

a + b + c + d = (a + b) + c + d

a + b + c + d = 17 + 4

a + b + c + d = 21
