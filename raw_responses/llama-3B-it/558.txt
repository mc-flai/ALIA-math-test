Per determinar el nombre de subconjunts que formen una progressió aritmètica, podem analitzar la següent forma:

{a, a+d, a+2d, a+3d, a+4d}

On a és el primer element i d és la diferència comuna entre els elements.

Per a que aquesta progressió siga aritmètica, cal que la següent condició siga satisfeta:

a+4d = 17 (el darrer element del conjunt)

A partir d'aquesta condició, podem derivar les següents:

a = 17 - 4d

A continuació, podem determinar el valor màxim de d:

d ≤ 4 (perquè a+4d = 17)

Per a cada valor de d, podem determinar el valor corresponent de a:

d = 1 => a = 13
d = 2 => a = 11
d = 3 => a = 9
d = 4 => a = 7

Per a cada valor de d, podem determinar el conjunt de 5 elements que formen una progressió aritmètica:

d = 1 => {1, 5, 9, 13, 17}
d = 2 => {2, 6, 10, 14, 18} (no està inclòs en el conjunt original)
d = 3 => {3, 7, 11, 15, 19} (no està inclòs en el conjunt original)
d = 4 => {4, 8, 12, 16, 20} (no està inclòs en el conjunt original)
