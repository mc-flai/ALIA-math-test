Raonament:

Si Guillem resol l'equació ax² + bx + c = 0 i Iolanda resol l'equació bx² + ax + c = 0, i aquestes equacions tenen una solució en comú, llavors aquesta solució és una raíz comuna de les dues equacions.

Per determinar si aquesta solució és 0, podem considerar el cas en què a i b són de signe diferent. Si a i b són de signe diferent, llavors la suma de les equacions és:

ax² + bx + c + bx² + ax + c = 0 + 0

Simplificant, obtenim:

(a + b)x² + (a + b)x + 2c = 0

Aquesta equació té una solució en comú amb les dues equacions originals, i per tant, aquesta solució és 0.

Per determinar si l'equació ax² + bx + c = 0 té exactament una solució real, podem considerar el cas en què a i b són de signe igual. Si a i b són de signe igual, llavors la discriminant de l'equació és:

Δ = b² - 4ac

Si Δ ≥ 0, llavors l'equació té una solució real. Si Δ < 0, llavors l'equació no té solucions reals.

Per determinar si a > 0, b < 0 o a + b + c = 0, no hi ha cap condició que garantizi la veritat d'aquestes afirmacions.

Per determinar si b < 0, no hi ha cap condició que garantizi la veritat d'aquesta afirmació.

En resum, sempre que les equacions tenen una solució en comú, aquesta solució és 0.

Resposta: A) La solució en comú ha de ser 0.
