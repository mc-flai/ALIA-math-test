Raonament:

Per resolver l'equació x² = 2014x + 2015, podem reorganitzar-la per formar una equació quadràtica:

x² - 2014x - 2015 = 0

Aquesta és una equació quadràtica en la forma ax² + bx + c = 0, on a = 1, b = -2014 i c = -2015.

Per determinar el nombre de solucions reals, podem utilitzar la fórmula de discriminant:

Δ = b² - 4ac

Si Δ > 0, l'equació té dues solucions reals. Si Δ = 0, l'equació té una solució real. Si Δ < 0, l'equació no té solucions reals.

En aquest cas, Δ = (-2014)² - 4(1)(-2015) = 4.072.076 + 8.062 = 4.080.138

Com a resultat, Δ > 0, l'equació té dues solucions reals.
