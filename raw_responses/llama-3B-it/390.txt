Raonament:

Analicem la informació donada:

1. El producte de tres nombres enteros és 140.
2. El valor del segon nombre és 7 vegades el del primer nombre.
3. El tercer nombre és més petit que el segon nombre en xicots.

Anomenem els tres nombres a, b i c. Segons la segona informació, b = 7a.

El producte dels tres nombres és 140, per tant:

a × b × c = 140

Sustituïm b = 7a en la segona equació:

a × (7a) × c = 140

Simplifiquem:

7a² × c = 140

Dividim per 7:

a² × c = 20

Ara, considerem les opcions per a la suma dels tres nombres:

a + b + c = a + 7a + c = 8a + c

Per a que a + b + c sigui una suma entera, a + c també ha de ser un nombre enter. Per a que a + c sigui un nombre enter, a² × c = 20 ha de ser un nombre enter.

Les possibilitats per a a² × c = 20 són:

- a² = 1, c = 20
- a² = 4, c = 5
- a² = 20, c = 1

Per a cada cas, calcularem la suma:

1. a² = 1, c = 20: a + c = 1 + 20 = 21
2. a² = 4, c = 5: a + c = 4 + 5 = 9
3. a² = 20, c = 1: a + c = 20 + 1 = 21

En tots els casos, la suma dels tres nombres és 21.

Resposta: B) 21.
