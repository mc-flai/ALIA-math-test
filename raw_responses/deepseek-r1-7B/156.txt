Raonament:

El número N és un nombre de dues xifres, per tant pots representar-lo com \(10a + b\),其中 \(a\) és la xifra de les desenes i \(b\) és la xifra de les unitats.

Segons el problema:
\[
\frac{N}{\text{suma de les xifres}} = 8
\]
Substituïnt N per \(10a + b\) i la suma de les xifres per \(a + b\), obtenim:
\[
\frac{10a + b}{a + b} = 8
\]
Multiplicant ambies parts per \(a + b\):
\[
10a + b = 8(a + b)
\]
Simplificant:
\[
10a + b = 8a + 8b \\
2a = 7b \\
\]
Ara, pots expressar aquesta equació com:
\[
a = \frac{7b}{2}
\]
Des que \(a\) i \(b\) són xifres enters entre 0 i 9, pots provar valors per \(b\) que facin \(a\) un enter:

- Si \(b = 0\): \(a = 0\), però això no donaria un nombre de dues xifres.
- Si \(b = 2\): \(a = \frac{7 \times 2}{2} = 7\), que és valid ja que 72 dividit per 9 (suma de les xifres) és 8.

Prova d'altres valors per b no donaria resultats valids. Per tant, la xifra de les unitats és 2.
