Per determinar quin cas no és possible, hem de comprobar si cada opció satisfà l'equació \( ax + by = c \) per el punt \( P(2, -1) \).

- **Opció A**: \( a = −1, b = 1, c = −3 \)
  
  Sustituïm en l'equació:
  \[
  (-1)(2) + (1)(-1) = -2 -1 = -3
  \]
  
  Resultat: \( -3 = -3 \). Possible.

- **Opció B**: \( a = 1, b = 0, c = 2 \)
  
  Sustituïm:
  \[
  (1)(2) + (0)(-1) = 2 + 0 = 2
  \]
  
  Resultat: \( 2 = 2 \). Possible.

- **Opció C**: \( a = 0, b = 3, c = −3 \)
  
  Sustituïm:
  \[
  (0)(2) + (3)(-1) = 0 -3 = -3
  \]
  
  Resultat: \( -3 = -3 \). Possible.

- **Opció D**: \( a = 10, b = 15, c = 5 \)
  
  Sustituïm:
  \[
  (10)(2) + (15)(-1) = 20 -15 = 5
  \]
  
  Resultat: \( 5 = 5 \). Possible.

- **Opció E**: \( a = 1, b = 2, c = 1 \)
  
  Sustituïm:
  \[
  (1)(2) + (2)(-1) = 2 -2 = 0
  \]
  
  Resultat: \( 0 ≠ 1 \). No possible.
