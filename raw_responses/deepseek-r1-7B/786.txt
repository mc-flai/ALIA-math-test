**Raonament:**

El sigle XXI abarca els anys des del 2001 fins al 2100. Volem saber quantos anys d'aquest període tenen una suma de dígits igual a 4.

1. **Any format**: Cada any pot ser representat com un número de four digits: \(ABCD\), on:
   - \(A = 2\) (pàra el sigle XXI)
   - \(B, C, D\) poden prendre valors des del 0 fins al 9.

2. **Suma de dígits**: La condició és que \(A + B + C + D = 4\). Substituïnt \(A = 2\), la equació es convierteix en:
   \[
   2 + B + C + D = 4 \implies B + C + D = 2
   \]
   
3. **Possibles combinacions**: Busquemos totes les combinacions de \(B, C, D\) on la suma siga 2. Aquestes són:
   - (0, 0, 2)
   - (0, 1, 1)
   - (0, 2, 0)
   - (1, 0, 1)
   - (1, 1, 0)
   - (2, 0, 0)

4. **Anys corresponents**:
   - **(0, 0, 2)**: Any 2002
   - **(0, 1, 1)**: Any 2011
   - **(0, 2, 0)**: Any 2020
   - **(1, 0, 1)**: Any 2101
   - **(1, 1, 0)**: Any 2110
   - **(2, 0, 0)**: Any 2200 (però aquest està fora del sigle XXI, que acaba en 2100)

5. **Conclusió**: Dels anys trobats, només els segents pertanyen al sigle XXI:
   - 2002
   - 2011
   - 2020

**Resposta:**

C) 3
