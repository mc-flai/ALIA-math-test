Raonament:  
L'equació donada és x² = 2014x + 2015. Per resoldre-ho, podem reorganitzar els termes per ferlo una equació quadràtica estàndard:  
x² - 2014x - 2015 = 0.

L'equació general d'una quadràtica és ax² + bx + c = 0, on el discriminant D es calcula com b² - 4ac. El discriminant decideix quants solucions reals té l'equació:  
- Si D > 0, hi ha dues solucions reals.  
- Si D = 0, hi ha una solució real (amb multiplicitat 2).  
- Si D < 0, no hi ha solucions reals.

En aquest cas, els coeficients són:  
a = 1, b = -2014, c = -2015.  

Calculant el discriminant:  
D = (-2014)² - 4(1)(-2015)  
= 2014² + 8060.  

Com que 2014² és un nombre positiu i afegint-hi 8060, el discriminant D serà evidentment positiu (més d'4.056.000). Per tant, l'equació té dues solucions reals.
