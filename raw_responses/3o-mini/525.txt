Raonament: Sigui b el nombre de xics i g el de xiques, amb b + g = 20. Si x és el nombre de parelles mi-xar (xics amb xiques), tenim que seguint els enunciats x = b/3 (la tercera part dels xics té xica) i x = g/2 (la meitat de les xiques té xic). Així, b = 3x i g = 2x. Sumant b i g, es té 3x + 2x = 5x = 20, per tant x = 4. Així, b = 3x = 12.
