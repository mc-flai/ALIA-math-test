Raonament: Sigui p el nombre de nombres positius, n el nombre de nombres negatius i z el nombre d’zeros, amb p + n + z = 50. Només multipliquem dos nombres amb diferent signe per obtenir un producte negatiu, per tant, el nombre total de multiplicacions negatives és p · n = 522. A més, p + n = 50 – z. Busquem dues xifres p i n tals que p · n = 522. Notem que 522 es pot escriure com 18 · 29, i 18 + 29 = 47. Així, tenim que p + n = 47 i per tant z = 50 – 47 = 3.

Resposta: B)
