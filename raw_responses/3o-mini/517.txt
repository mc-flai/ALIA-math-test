Raonament: Sabem que a, b i c són nombres positius i compleixen les equacions a·b = 6, b·c = 15 i a·c = 10. Multiplicant aquestes tres equacions obtenim (a·b)·(b·c)·(a·c) = 6·15·10, és a dir, (a²·b²·c²) = 900. Per tant, (a·b·c) = √900 = 30. Ara podem calcular cada variable:
 • a = (a·b·c)/(b·c) = 30/15 = 2,
 • b = (a·b·c)/(a·c) = 30/10 = 3,
 • c = (a·b·c)/(a·b) = 30/6 = 5.
Sumant-los: a + b + c = 2 + 3 + 5 = 10.

Resposta: B)
