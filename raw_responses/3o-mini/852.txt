Raonament: Si fem a talls verticals (a) i b talls horitzontals, amb a + b = 7, el nombre de trossos serà (a + 1)·(b + 1). Proveïm amb totes les combinacions possibles:
- a = 0, b = 7: (0 + 1)·(7 + 1) = 1·8 = 8 trossos.
- a = 1, b = 6: (1 + 1)·(6 + 1) = 2·7 = 14 trossos.
- a = 2, b = 5: (2 + 1)·(5 + 1) = 3·6 = 18 trossos.
- a = 3, b = 4: (3 + 1)·(4 + 1) = 4·5 = 20 trossos.

Observeu que entre els possibles resultats (8, 14, 18 i 20), el nombre 12 no apareix.
