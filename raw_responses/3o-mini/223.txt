Raonament: Anomenem P el total de pomes i p el nombre de pomes que rep cada xiquet en repartir-les entre N xiquets, de manera que P = N·p. En el cas de N−2 xiquets, cada un hauria de rebre p+1 pomes, per tant P = (N−2)(p+1). Igualant les dues expressions tenim:
  N·p = (N−2)(p+1).
Resolem:
  N·p = (N−2)p + (N−2) ⟹ Np − (N−2)p = N−2 ⟹ 2p = N−2 ⟹ p = (N−2)/2.
Ara, considerem el cas de N−3 xiquets, on cada un reb el nombre p+2. Així, P = (N−3)(p+2). Igualem amb P = N·p:
  N·p = (N−3)(p+2).
Substituïm p = (N−2)/2:
  N·((N−2)/2) = (N−3)[(N−2)/2 + 2]
  ⟹ N(N−2)/2 = (N−3)[(N−2 + 4)/2] = (N−3)(N+2)/2.
Eliminem el factor 1/2:
  N(N−2) = (N−3)(N+2).
Expandint:
  N² − 2N = N² − N − 6.
Aïllant:
  −2N = −N − 6 ⟹ −N = −6 ⟹ N = 6.
Per tant, N és 6.

Resposta: A)
