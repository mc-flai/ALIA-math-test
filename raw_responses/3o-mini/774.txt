Raonament: Primer observem que n² – 2n – 3 es pot factoritzar com (n – 3)(n + 1). Perquè |(n – 3)(n + 1)| sigui un nombre primer, el producte ha de ser, en valor absolut, primer. Això és només possible si un dels factors és 1 o –1, ja que si ambdós factors fossin més grans en valor absolut, el producte seria compost.

Considerem els casos:
1) Si n – 3 = 1, llavors n = 4. En aquest cas n + 1 = 5 i el producte és 1 · 5 = 5, que és primer.
2) Si n – 3 = –1, llavors n = 2. Aquí n + 1 = 3 i el producte és (–1) · 3 = –3, amb |–3| = 3, que és primer.
3) Si n + 1 = 1, llavors n = 0. En aquest cas n – 3 = –3, i el producte és (–3) · 1 = –3, amb |–3| = 3, que és primer.
4) Si n + 1 = –1, llavors n = –2. Aquí n – 3 = –5, i el producte és (–5) · (–1) = 5, que en valor absolut és 5, primer.

Per tant, els valors de n que compleixen la propietat són n = –2, 0, 2, i 4.
