Raonament: Escrivim les incógnites x, y i z en potències de 7, és a dir, x = 7ᵃ, y = 7ᵇ i z = 7ᶜ. Així, de les igualtats donades tenim:
 • x²·y·z³ = 7^(2a + b + 3c) = 7³ ⟹ 2a + b + 3c = 3.
 • x·y² = 7^(a + 2b) = 7⁹      ⟹ a + 2b = 9.
Observant que volem trobar xyz, que és 7^(a + b + c), sumem les dues equacions:
 (2a + b + 3c) + (a + 2b) = 3a + 3b + 3c = 3(a + b + c) = 3 + 9 = 12.
Així, a + b + c = 12/3 = 4, i per tant, xyz = 7⁴.
