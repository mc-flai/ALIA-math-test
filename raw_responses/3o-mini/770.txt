Raonament: Cal resoldre l’equació per trencar el mòdul en dues parts. 

• Si x ≥ 0, |x| = x i l’equació esdevé:
  2 – x = a·x ⟹ 2 = (a + 1)x ⟹ x = 2/(a + 1),
que té solució vàlida en x ≥ 0 si, a més, a + 1 > 0 (és a dir, a > –1).

• Si x < 0, |x| = –x i l’equació esdevé:
  2 – (–x) = 2 + x = a·x ⟹ 2 = (a – 1)x ⟹ x = 2/(a – 1),
que té solució vàlida en x < 0 si x = 2/(a – 1) < 0, cosa que passa quan a – 1 < 0, és a dir, a < 1.

Per tal que hi hagi exactament dues solucions (una per a cada cas), s’han de complir simultàniament a > –1 i a < 1.
