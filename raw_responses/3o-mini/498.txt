Raonament: Suposem, sense pèrdua de generalitat, que el punt A està a la posició 0 i que, per la distància AB = 1 cm, col·locam B a 1. Llavors podem determinar la posició de C a partir de BC = 2 cm. Hi ha dues possibilitats: C = 1 + 2 = 3 o C = 1 − 2 = –1. Si triem C = 3, llavors, donat que CD = 3 cm, D podria estar a 3 + 3 = 6 o a 3 − 3 = 0. Però la distància AD ha de ser 4 cm i, en aquest cas, ni 6 (perquè |6 − 0| = 6) ni 0 (perquè coincideix amb A) compleixen amb DA = 4, per tant aquesta possibilitat es descarta.

Si triem C = –1, aleshores, per CD = 3, D pot estar a –1 + 3 = 2 o a –1 − 3 = –4. Comprovem amb DA = 4: en el primer cas |2 − 0| = 2, que no serveix, mentre que en el segon cas |–4 − 0| = 4, que és exactament el que volem. Així, obtenim la disposició següent:  
A = 0, B = 1, C = –1, D = –4.

L'ordre creixent de les posicions és: D (–4), C (–1), A (0) i B (1). Per tant, els extrems de la recta són D i B.

Resposta: B)
