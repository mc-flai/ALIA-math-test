Raonament: Primer observem que en el segle XXI els anys van de 2001 a 2100. Si considerem un any del format 20ab (on “a” i “b” són dígits) la suma de les xifres és 2 + 0 + a + b = a + b + 2. Com volem que la suma sigui 4, hem de tenir:

  a + b + 2 = 4  ⟹  a + b = 2

Les possibles combinacions de dos dígits que sumen 2 són:
  • a = 0, b = 2  → any 2002
  • a = 1, b = 1  → any 2011
  • a = 2, b = 0  → any 2020

Aquests tres anys (2002, 2011 i 2020) són dins el període 2001–2100. Per tant, hi ha 3 anys del segle XXI amb aquesta propietat.

Resposta: C)
