Raonament: Sigui n el nombre de dues xifres obtigit amb les dues últimes xifres i, segons l'enunciat, el nombre format amb les tres primeres xifres és 4·n. Així, el nombre de cinc xifres pot escriure's com 100·(4·n) + n = 401·n. Com que el nombre ha de ser de cinc xifres i estar comprès entre 10000 i 26319, hem de complir:

  401·n ≥ 10000 ⟹ n ≥ 10000/401 ≈ 24,94 ⟹ n ≥ 25

  401·n < 26320 ⟹ n < 26320/401 ≈ 65,6 ⟹ n ≤ 65

A més, n ha de ser un nombre de dues xifres, així que n varia entre 25 i 65, ambdós inclosos. El nombre de valors possibles és 65 – 25 + 1 = 41.
