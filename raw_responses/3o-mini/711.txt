Raonament: El nombre aaabbbb té les xifres a, a, a, b, b, b, b, per tant, la seva suma és 3a + 4b. El nombre de dues xifres ab és equivalent a 10a + b. Igualem les dues expressions: 3a + 4b = 10a + b. Simplificant, obtenim 3a + 4b = 10a + b → 4b – b = 10a – 3a → 3b = 7a. Així, b = (7/3)a, i perquè b sigui una xifra, a ha de ser múltiple de 3. Provant amb a = 3, tenim: b = (7·3)/3 = 7, i com que 3 i 7 són xifres, es compleixen les condicions. Finalment, a + b = 3 + 7 = 10.
