Raonament: Cal determinar quina de les propietats (A a E) pot ser veritable sense provocar solapaments amb cap altra. Pensem-ho:

• Si n fos divisible per 3 (opció A), aleshores molts nombres, especialment els senars, també serien primers (com el 3) o senars (opció D) – per exemple, n = 3 compleix A, C i D –, de manera que no seria única.

• Si n fos divisible per 6 (opció B), aleshores n també ho seria per 3 (opció A). Per exemple, n = 6 compleix A i B.

• Si n fos primer (opció C), aleshores hauria de ser n senar en la majoria dels casos (ja que l’únic nombre primer parell és el 2, el qual provoca un solapament amb l’opció E). Així nombres com 5 o 7 serien primer i també senars (complint D), i n = 2 compliria C i E.

• Si n fos igual a 2 (opció E), aleshores n és primer (opció C) i, per tant, no seria l’única propietat.

L’única opció que pot complir-se aïlladament és la de “n és senar” (opció D), sempre que n es triï de manera que no sigui divisible per 3, tampoc sigui primer ni sigui 2. Per exemple, n = 25 compleix només que és senar (les altres propietats són falses).

Resposta: D) n és senar.
