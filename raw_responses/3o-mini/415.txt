Raonament: Partim de les dues equacions donades: 
  2017 + x = y²  (1) 
  2017 + y = x²  (2) 
Restem (2) de (1): 
  (2017 + x) - (2017 + y) = y² - x² 
  x - y = (y - x)(y + x) = -(x - y)(x + x) 
Si x ≠ y podem dividir per (x - y) obtenint: 
  1 = - (x + y)  →  x + y = -1. 

Ara sumem les dues equacions inicials: 
  (2017 + x) + (2017 + y) = y² + x² 
  4034 + (x + y) = x² + y². 
Substituïm x + y = -1: 
  4034 - 1 = x² + y²  →  4033 = x² + y². 

Recordem que x² + y² = (x + y)² - 2xy, i com que x + y = -1 tenim: 
  4033 = (-1)² - 2xy = 1 - 2xy 
  → -2xy = 4033 - 1 = 4032 
  → xy = -2016.
