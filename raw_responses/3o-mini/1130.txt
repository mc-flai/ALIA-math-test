Raonament: Sigui r la solució en comú. Així, r ha de complir:
  ax² + bx + c = 0  (1)
  bx² + ax + c = 0  (2)
Resta (2) - (1):
  (b - a)r² + (a - b)r = 0 ⟹ (a - b)(r² - r) = 0.
Com que a i b són nombres enters diferents (per tant, a - b ≠ 0), hem de tenir:
  r² - r = 0 ⟹ r(r - 1) = 0.
Les possibles solucions són r = 0 o r = 1. Però si r = 0, substituint a (1) es donaria c = 0, cosa que contradiu l'enunciat. Per tant, la solució comuna és r = 1. 
Substituint r = 1 a (1) obtenim:
  a + b + c = 0.
Així, la resposta certa és: a + b + c = 0.
