Raonament: Per determinar la base b, primer cal interpretar els nombres en base b. Així doncs, escrivim:
 14_b = 1·b + 4,
 25_b = 2·b + 5,
 416_b = 4·b² + 1·b + 6.
Llavors, l'equació de la multiplicació és:
 (b + 4)(2b + 5) = 4b² + b + 6.
Multiplicant el membre esquerre, obtenim:
 2b² + 13b + 20 = 4b² + b + 6.
Reordenant, tenim:
 0 = 4b² + b + 6 – (2b² + 13b + 20) = 2b² – 12b – 14.
Dividint per 2:
 b² – 6b – 7 = 0.
Resolent l’equació quadràtica:
 b = (6 ± √(36 + 28)) / 2 = (6 ± 8) / 2.
Obtenim dos valors: b = 7 i b = -1. Com que la base ha de ser un enter més gran que 6, la solució és b = 7.
