Raonament: Hem de trobar totes les ternes naturals (a, b, c) amb a ≤ b ≤ c i a + b + c = 21 que compleixin, a més de la desigualtat del triangle (a + b > c), la propietat que per cada parella d’elements, o són iguals o un divideix l’altre.

Comencem fixant a i expressant b i c. Observem el següent:

1. Amb a = 1, tenim b + c = 20 i la desigualtat del triangle: 1 + b > c. Com que b ≤ c, aquesta desigualtat implica que c = b (ja que si c fos més gran, 1 + b ≤ c). Així,
  1 + b + b = 21 ⟹ 2b = 20 ⟹ b = 10 i c = 10.
  Les parelles són (1,10) (on 1 divideix 10) i (10,10) (són iguals). ⇒ Triangle vàlid: (1,10,10).

2. Amb a = 3, tenim b + c = 18 i la desigualtat: 3 + b > c. Si b = c:
  3 + 2b = 21 ⟹ 2b = 18 ⟹ b = 9, c = 9.
  Les parelles: (3,9) amb 3 divideix 9, i (9,9) són iguals. ⇒ Triangle vàlid: (3,9,9).

3. Amb a = 7, tenim b + c = 14 i b ≥ 7. Si b = c:
  7 + 2b = 21 ⟹ 2b = 14 ⟹ b = 7 i c = 7.
  Les tres longituds són iguals, de manera que totes les parelles compleixen la condició. ⇒ Triangle vàlid: (7,7,7).

S’han considerat altres possibilitats (on les longituds no són totes iguals) per a altres valors d’a, però o bé no satisfaven la desigualtat del triangle o bé falten les propietats de divisibilitat en alguna parella (per exemple, en candidates com (4,8,9), (5,6,10) o (6,7,8) es verifica que alguna de les parelles no compleix que una divideixi a l’altra).

Per tant, només tenim 3 triangles que compleixen totes les condicions.

Resposta: D)
