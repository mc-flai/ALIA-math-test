Raonament: Primer, cal calcular cada costat de la igualtat. Tenim que a ◊ b = b – a. Llavors, (a ◊ b) ◊ c = c – (b – a) = c – b + a. D'altra banda, b ◊ c = c – b, i per tant, a ◊ (b ◊ c) = (c – b) – a = c – b – a. Perquè (a ◊ b) ◊ c = a ◊ (b ◊ c), hem de tenir: c – b + a = c – b – a, el que implica que a + a = 0, és a dir, 2a = 0. Així doncs, necessàriament, a = 0.
