Raonament: Sabem que el punt P(2, -1) pertany a la recta amb equació ax + by = c, la qual cosa implica que 2a + (-1)b = c, és a dir, c = 2a - b. Revisem cada opció:

A) a = −1, b = 1 → c = 2(−1) − 1 = −2 − 1 = −3, que coincideix amb c = −3.
B) a = 1, b = 0 → c = 2(1) − 0 = 2, que coincideix amb c = 2.
C) a = 0, b = 3 → c = 2(0) − 3 = −3, que coincideix amb c = −3.
D) a = 10, b = 15 → c = 2(10) − 15 = 20 − 15 = 5, que coincideix amb c = 5.
E) a = 1, b = 2 → c = 2(1) − 2 = 0, que NO coincideix amb c = 1.

Per tant, l'opció que no és possible és:

Resposta: E)
