Raonament: 
Observem que x² - y² es pot factoritzar com (x - y)(x + y) = 105. Poder escriure 105 com a producte de dos enters positius (x - y) i (x + y) implica que, si denotem a = x - y i b = x + y, tenim que a·b = 105, amb a < b i ambdues quantitats de la mateixa paritat. Com que la diferència b - a ha de ser parell (perquè x = (a + b)/2 i y = (b - a)/2 siguin enters) i 105 és senar, tant a com b han de ser senars. 

Els divisors senars positius de 105 són: 1, 3, 5, 7, 15, 21, 35 i 105. Els possibles parells (a, b) amb a·b = 105 i a < b són:
• (1, 105) → x = (1 + 105)/2 = 53, y = (105 - 1)/2 = 52.
• (3, 35) → x = (3 + 35)/2 = 19, y = (35 - 3)/2 = 16.
• (5, 21) → x = (5 + 21)/2 = 13, y = (21 - 5)/2 = 8.
• (7, 15) → x = (7 + 15)/2 = 11, y = (15 - 7)/2 = 4.

Per tant, hi ha 4 parelles ordenades (x, y) que satisfan x² - y² = 105.
