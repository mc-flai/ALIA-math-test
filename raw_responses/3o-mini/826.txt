Raonament: Sigui la llista de cinc nombres: 10, b, c, d, 130. 
1) La suma dels primers tres nombres és 100: 10 + b + c = 100 ⟹ b + c = 90.
2) La suma dels tres que estan al mig és 200: b + c + d = 200. Com que b + c = 90, llavors d = 200 − 90 = 110.
3) La suma dels tres últims nombres és 300: c + d + 130 = 300 ⟹ c + 110 + 130 = 300 ⟹ c + 240 = 300 ⟹ c = 60.
Per tant, el nombre del centre de la llista és 60.

Resposta: B)
