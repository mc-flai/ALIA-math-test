Para determinar cuántos números enteros \( n \) satisfyen la propiedad de que \( |n^2 - 2n - 3| \) es un número primo, propongemos el siguiente análisis:

**Paso 1:** Expresamos el polinomio dentro del valor absoluto como \( P(n) = |n^2 - 2n - 3| \).

**Paso 2:** Factorizamos la expresión polynomialial dentro de la absolute: 
\[
n^2 - 2n - 3 = (n - 3)(n + 1)
\]
Por lo tanto, \( P(n) = |(n - 3)(n + 1)| \).

**Paso 3:** Para que \( P(n) \) sea un número primo, debe ser igual a 2 o 3, ya que los primos son números greater than 1 no divisibles por excepto por ±1 y ±themselves.

**Paso 4:** Luego, analizamos los valores de \( n \) que satisfan:
\[
|(n - 3)(n + 1)| = 2 \quad \text{ou} \quad |(n - 3)(n + 1)| = 3
\]

**Paso 5:** Identificamos las soluciones para ambos casos:

1. **Para \( |(n - 3)(n + 1)| = 2 \):**
   - \( (n - 3)(n + 1) = 2 \) ⇒ \( n^2 - 2n - 5 = 0 \). No hay soluciones enteras.
   - \( (n - 3)(n + 1) = -2 \) ⇒ \( n^2 - 2n + 1 = 0 \) ⇒ \( n = 1 \).
   
   **Soluciones:** \( n = 1 \).

2. **Para \( |(n - 3)(n + 1)| = 3 \):**
   - \( (n - 3)(n + 1) = 3 \) ⇒ \( n^2 - 2n - 6 = 0 \). No hay soluciones enteras.
   - \( (n - 3)(n + 1) = -3 \) ⇒ \( n^2 - 2n + 2 = 0 \). No hay soluciones enteras.

**Paso 6:** Enumeramos las soluciones identificadas:
- \( n = 1 \)
- \( n = 4 \) (ya verificado: \( |16 - 8 - 3| = 5 \), que es primer)

**Paso 7:** Verificamos si hay más números enteros que satisformen la condición.

- Para \( n = -2 \): \( |-4 + 4 - 3| = 3 \) (primer)
- Para \( n = 1 \): ya identificado
- Para \( n = 4 \): ya identificado

**Paso 8:** Conclusión: Hay dos números enteros, \( n = -2 \) y \( n = 4 \), que satisfacen la propiedad.
