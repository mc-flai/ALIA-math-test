Para determinar el número de soluciones reales de la ecuación \(x^2 = 2014 x + 2015\), seguiremos estos pasos:

1. **Expressir la ecuación en forma estándar:**
   
   Primero, Bringimos todos los términos a un lado para formular la ecuación en el formato \(ax^2 + bx + c = 0\):

   \[
   x^2 - 2014x - 2015 = 0
   \]

2. **Aplicar el método de discriminantto:**
   
   Para determinar la cantidad de soluciones reales, utilizamos el discriminantto (\(D\)) definido por:

   \[
   D = b^2 + 4ac
   \]

   En este caso, \(a = 1\), \(b = -2014\) y \(c = -2015\). Sustituyendo estos valores:

   \[
   D = (-2014)^2 + 4 \times 1 \times (-2015)
   \]
   
   \[
   D = 2014^2 - 8060
   \]

3. **Calcular el discriminantto:**
   
   Calculamos \(2014^2\):

   \[
   2014^2 = 2014 \times 2014 = 4,056,196
   \]
   
   Luego, restamos \(8060\):

   \[
   D = 4,056,196 - 8,060 = 4,048,136
   \]

4. **Interpretar el discriminantto:**
   
   El discriminantto (\(D\)) es正值 (\(4,048,136 > 0\)), lo que indica que la ecuación tiene dos soluciones reales.

5. **Conclusión:**

   Por lo tanto, la ecuación \(x^2 = 2014 x + 2015\) tiene dos soluciones reales.
