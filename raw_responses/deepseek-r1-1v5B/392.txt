Para resolver l'equació \( n^4 - n^3 - n^2 + 8 = 2017 \) amb \( n \) un nombre natural, calculem cada opció d'alternativa:

- **A)** \( n = 5 \):
  \[
  5^4 - 5^3 - 5^2 + 8 = 625 - 125 - 25 + 8 = 483 \neq 2017
  \]
  
- **B)** \( n = 7 \):
  \[
  7^4 - 7^3 - 7^2 + 8 = 2401 - 343 - 49 + 8 = 1917 \neq 2017
  \]
  
- **C)** \( n = 9 \):
  \[
  9^4 - 9^3 - 9^2 + 8 = 6561 - 729 - 81 + 8 = 5759 \neq 2017
  \]
  
- **D)** \( n = 41 \):
  \[
  41^4 - 41^3 - 41^2 + 8 \text{ és un número més grand que } 2017
  \]
  
Així com a cada opció no satisfactoria, hi pot observar que **no existeix cap \( n \) natural que satisfa l'equació**.
