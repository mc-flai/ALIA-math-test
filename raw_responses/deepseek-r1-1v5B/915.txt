Raonament: El llibre ha utilitzat exactament 231 xifres per a les pàganes que hi poten. Com presem, la suma de xifres en una publications es igual a la sum de tots els números de xifres de cada página.

Assim que si denoteram \( x \) com el nombre de las pàganes, el nombre total d'xifres ésigual a la suma dels nombres de xifres de cada página. El theoretically, una página 1 pot tenir un solo xifra (1), una página 2 dos xifres (2,...,9), etc.

El llibre pot hi tingut tant pàganes grans que possible per aiguar el nombre d'xifres sense comprobar decimal. Així, la suma dels nombres de xifres d'una publications es:

\( \sum_{n=1}^{x-4} n + (x - 2) + (x - 1) + x = 231 \)

La summatriu expressiona com:

\( 1 + 2 + ... + (x - 5) + (x - 3) + (x - 2) + (x - 1) + x = 231 \)

Quan expressivem la suma de xifres, pot donar:

\( \frac{(x - 4)(x - 3)}{2} + (x - 2) + (x - 1) + x = 231 \)

Simplificant l'expression:

\( x^2 - x - 458 = 0 \)

Raó quadràtica. Solucionant la raí quadrada, tindrem:

\( x ≈ 21.905 \)

Per tant, el nombre de les pàganes és 22.

Comvolim als optimitats que la suma d'xifres sense comprobar decimal pot donar:

Pàgana 1: 1

Pàgana 2: 2

...

Pàgana 5: 6

Per així que la suma total de xifres és 111, que sigui el nombre de les pàganes que pot tenir un llibre per aiguar 231 xifres.
