**Problema:**
Judit y Susanna juguen tres sets en un partit a la millor. La primera jugador que guana dos sets guanya el partit. Sabemos que la probabilidad de Judit ganar un set a Susanna es 0,6. ¿Cuál es la probabilidad de Judit ganar el partit?

**Solución:**

1. **Análisis de cada set:**
   - Cada set tiene dos posibles resultados: gana o pierde.
   - La probabilidad de ganar un set por Judit es \( p = 0,6 \), y la de pierderlo es \( q = 1 - p = 0,4 \).

2. **Determine juntos los casos where Juditgan dos sets en ahorro:**
   - **Casos donde Judit gana el primer set:**
     - Peraldo gana el segundo set.
     - Probabilidad: \( p \times q = 0,6 \times 0,4 = 0,24 \).
   - **Casos donde Judit pierde el primer set y gana dos en ahorro:**
     - Gana el segundo y el tercero set.
     - Probabilidad: \( q \times p \times p = 0,4 \times 0,6 \times 0,6 = 0,144 \).

3. **Suma las probabilidades de ambos casos para obtener la probabilidad total de Judit ganar el partit:**
   \[
   P(\text{Judit gana el partit}) = 0,24 + 0,144 = 0,384
   \]

**Respuesta final:**

La probabilidad de Judit ganar el partit es **0,504**.
