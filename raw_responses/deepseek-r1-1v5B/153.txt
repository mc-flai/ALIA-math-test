To solve this problem, we need to find the sum of all positive integers from 1 to n. The solution should be efficient even for very large values of n, such as \(10^{18}\).

### Approach
The key insight here is that the units digit (i.e., the last digit) of each number cycles every 10 numbers. This means we can leverage this cyclical property to compute the sum efficiently.

1. **Full Cycles Contribution**: Each complete cycle of 10 consecutive numbers contributes a fixed sum of 45 (since \(1 + 2 + \ldots + 9 + 0 = 45\)). 
2. **Partial Cycle Contribution**: If n is not a multiple of 10, the remaining part after considering full cycles contributes an additional sum.

Using these insights, we can compute the sum as follows:
- Calculate the number of complete cycles by integer division \(n // 10\).
- Compute the contribution from complete cycles: \((n // 10) * 45\).
- For the partial cycle, if n modulo 10 is r (where \(r\) ranges from 0 to 9), sum the first r natural numbers.

### Solution Code
```python
n = int(input())
full_cycles = n // 10
partial_sum = (n % 10) * (n % 10 + 1) // 2
print(full_cycles * 45 + partial_sum)
```

### Explanation
- **Reading Input**: The code reads an integer n from the input.
- **Full Cycles Calculation**: `full_cycles` is computed as \(n // 10\), representing how many complete cycles of 10 numbers fit into n.
- **Partial Sum Calculation**: `partial_sum` is calculated using the formula for the sum of the first r natural numbers, where \(r = n \% 10\). This gives us the sum of the units digits from numbers beyond the last full cycle.
- **Total Sum**: The total sum is the sum of contributions from complete cycles and the partial cycle.

This approach ensures that we efficiently compute the sum without iterating through each number up to n, making it suitable for very large values of n.
