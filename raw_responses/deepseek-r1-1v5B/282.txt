**Solució:**

Quer triar una parella de cavallers que siguen amics, la quantitat de possibilitats es trobaria com el número de parells possible entre les cavallers que no són veírs. Si thereigem al rei Artur el numer del mateix (n-1) per a l'altira taurneta, la distància esdeu pot ser de 1 a n−1 per als posibles parells.

Raonem combinatorialment: quin és el nombre possible de parells (a, b) amb a < b? Es el que calculen la fórmula binomial C(n−1, 2), que equivalent a ((n−1)*(n−2))/2.

Per exemple:
- Si n = 3: posibles parells són C(2, 2) = 1.
- Si n = 4: posibles parells són C(3, 2) = 3.
- Si n = 5: posibles parells són C(4, 2) = 6.
- Si n = 6: posibles parells són C(5, 2) = 10.

Com per exemple, quan n = 7:
C(6, 2) = (6*5)/2 = 15 parells.
