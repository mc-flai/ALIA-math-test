## Raonament:

1. **Definim variables:**

*  `a`: representa la centena del número.
*  `b`: representa la decena del número.

2. **Planteamos la ecuación:**

El problema nos dice que el número es igual a la suma de los cubos de sus dígitos. Esto se traduce en la siguiente ecuación:

100a + 10b + c = a³ + b³ + c³

3. **Analizamos las opciones:**

Observamos que todas las opciones tienen la forma `a, b, c` donde `c` es siempre 0 o 1. Esto nos indica que la unidad del número es 0 o 1.

4. **Descartamos opciones:**

* Si `c = 0`, la ecuación se simplifica a: 100a + 10b = a³ + b³

* Si `c = 1`, la ecuación se simplifica a: 100a + 10b + 1 = a³ + b³ + 1

5. **Probamos con valores pequeños:**

Dado que `a` y `b` son dígitos, podemos probar con valores pequeños para ver si encontramos una solución.

* Si probamos con `a = 1`, la ecuación se vuelve compleja rápidamente.

* Si probamos con `a = 2`, encontramos que `b = 3` cumple la ecuación para `c = 0`.

6. **Verificamos la solución:**

2³ + 3³ + 0³ = 8 + 27 + 0 = 35

100(2) + 10(3) + 0 = 200 + 30 + 0 = 230

Como 35 no es igual a 230, descartamos esta solución.

7. **Continuamos probando:**

Podemos continuar probando con otros valores de `a` y `b` hasta encontrar una solución que cumpla la ecuación.
