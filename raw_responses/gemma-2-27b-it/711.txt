## Raonament:

1. **Expressem el problema matemàticament:**
   *  aaabbbb = 111000a + 111b
   *  a + a + a + b + b + b + b = 3a + 4b
   *  3a + 4b = ab

2. **Analitzem les possibles solucions:**

   *  Com que 'ab' és un nombre de dues xifres, 'a' ha de ser un dígit entre 1 i 9 (si fos 0, 'ab' seria un nombre d'una xifra).

   *  Proveu diferents valors per 'a' i mireu si trobeu un valor per 'b' que compleixi l'equació 3a + 4b = ab.

3. **Trobem la solució:**

   * Si a = 3, llavors 3 * 3 + 4b = 3b, que significa b = 3.

## Resposta:

**A) 8** (3 + 3 = 8)
