## Raonament:

1. **Analitzem el valor absolut:** La suma de dos valors absoluts serà igual a 3 només si les expressions dins dels valors absoluts tenen signes oposats i la suma dels seus valors absoluts és igual a 3.

2. **Considerem els casos:**

    * **Cas 1:** x - 2019 ≥ 0 i x - 2020 < 0. Això implica 2019 ≤ x < 2020. En aquest cas, l'equació es converteix en: (x - 2019) - (x - 2020) = 3, que no té solucions.

    * **Cas 2:** x - 2019 < 0 i x - 2020 ≥ 0. Això implica 2020 ≤ x < 2021. En aquest cas, l'equació es converteix en: -(x - 2019) + (x - 2020) = 3, que simplificant queda -1 = 3, el qual no té solucions.

3. **Conclusió:** No hi ha cap valor de x que satisfaci l'equació |x - 2019| + |x − 2020| = 3.
