## Raonament:

Podem resoldre aquest problema utilitzant un sistema d'equacions.

* Sigui **A** la quantitat de diners que porta Alba.
* Sigui **B** la quantitat de diners que porta Bernat.
* Sigui **C** la quantitat de diners que porta Cris.
* Sigui **D** la quantitat de diners que porta David.

Tenim la següent informació:

* A + B = 5
* C + D = 6
* A + C = 7

Volem trobar B + D.

Si sumem les tres equacions, obtenim:

2A + 2B + 2C + 2D = 18

Dividint ambdós costats per 2:

A + B + C + D = 9

Ara, podem aïllar B + D:

B + D = 9 - (A + C)

Sabem que A + C = 7, per tant:

B + D = 9 - 7 = 2

## Resposta:

**E) 4**
