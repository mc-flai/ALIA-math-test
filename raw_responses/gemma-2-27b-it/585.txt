## Raonament:

Per resoldre aquesta equació, hem de considerar dos casos:

**Cas 1: (x² - 4x + 5) = 1**

En aquest cas, tenim:
x² - 4x + 4 = 0
(x - 2)² = 0
x = 2

**Cas 2: (x² - 4x + 5)^(x²+x-30) = 1 i (x² - 4x + 5) ≠ 1**

Per a que una potència sigui igual a 1, l'exponent ha de ser 0. Per tant:
x² + x - 30 = 0
(x + 6)(x - 5) = 0
x = -6 o x = 5

**Verificació:**

Hem de verificar si les solucions trobades satisfan la condició (x² - 4x + 5) ≠ 1:

* Per x = 2, (x² - 4x + 5) = 1, per tant, no és una solució vàlida per aquest cas.
* Per x = -6 i x = 5, (x² - 4x + 5) ≠ 1, per tant, són solucions vàlides.
