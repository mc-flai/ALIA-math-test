## Raonament:

Podem observar que cada terme de \(b\) es pot expressar com la suma de 2 termes consecutius de \(a\):

*  \(\frac{3}{2} = \frac{1}{2} + \frac{2}{2}\)
*  \(\frac{5}{3} = \frac{1}{3} + \frac{4}{3}\)
*  \(\frac{7}{4} = \frac{1}{4} + \frac{6}{4}\)
*  ...
*  \(\frac{4033}{2017} = \frac{1}{2017} + \frac{4032}{2017}\)

Per tant, podem escriure \(b\) com:

\(b = (\frac{1}{2} + \frac{2}{2}) + (\frac{1}{3} + \frac{4}{3}) + (\frac{1}{4} + \frac{6}{4}) + ... + (\frac{1}{2017} + \frac{4032}{2017})\)

Reordenant els termes, obtenim:

\(b = (\frac{1}{2} + \frac{1}{3} + \frac{1}{4} + ... + \frac{1}{2017}) + ( \frac{2}{2} + \frac{4}{3} + \frac{6}{4} + ... + \frac{4032}{2017})\)

Observem que el primer terme és \(a\). El segon terme també es pot simplificar:

\( \frac{2}{2} + \frac{4}{3} + \frac{6}{4} + ... + \frac{4032}{2017} = 1 + \frac{4}{3} + \frac{6}{4} + ... + \frac{4032}{2017} = 1 + (2 \cdot \frac{1}{2} + 2 \cdot \frac{1}{3} + 2 \cdot \frac{1}{4} + ... + 2 \cdot \frac{1}{2017}) = 1 + 2 (\frac{1}{2} + \frac{1}{3} + \frac{1}{4} + ... + \frac{1}{2017}) = 1 + 2a\)

Per tant, \(b = a + 1 + 2a = 3a + 1\).

Finalment, \(a + b = a + (3a + 1) = 4a + 1\).

No podem calcular el valor exacte de \(a\) sense una calculadora, però sabem que \(a\) és un nombre positiu. Per tant, \(4a + 1\) serà un nombre major que 1.

D'entre les opcions de resposta, la única que compleix aquesta condició és la **B) 4034**.
