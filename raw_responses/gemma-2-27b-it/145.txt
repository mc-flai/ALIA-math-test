## Raonament:

Sigui **P** el nombre total de pomes.

* **Situació 1:** N xics es reparteixen les pomes: P / N = pomes per nen (sense sobrar)
* **Situació 2:** N - 2 xics es reparteixen les pomes: P / (N - 2) = pomes per nen + 1
* **Situació 3:** N - 3 xics es reparteixen les pomes: P / (N - 3) = pomes per nen + 2

A partir d'aquestes equacions, podem plantejar un sistema d'equacions per resoldre el valor de N.

1. **Des del enunciat, podem expressar les equacions de la següent manera:**

   * P = N * (Pomes per nen)
   * P = (N - 2) * (Pomes per nen + 1)
   * P = (N - 3) * (Pomes per nen + 2)

2. **Substituint la primera equació en les segones:**

   * N * (Pomes per nen) = (N - 2) * (Pomes per nen + 1)
   * N * (Pomes per nen) = (N - 3) * (Pomes per nen + 2)

3. **Simplificant les equacions:**

   * N * (Pomes per nen) = N * (Pomes per nen) + N - 2 * (Pomes per nen) - 2
   * N * (Pomes per nen) = N * (Pomes per nen) + 2N - 6 * (Pomes per nen) - 6

4. **Cancel·lant termes comuns:**

   * N - 2 * (Pomes per nen) - 2 = 0
   * 2N - 6 * (Pomes per nen) - 6 = 0

5. **Resolent el sistema d'equacions:**

   * De la primera equació, obtenim: N = 2 * (Pomes per nen) + 2
   * Substituint en la segona equació: 2 * (2 * (Pomes per nen) + 2) - 6 * (Pomes per nen) - 6 = 0
   * Simplificant: 4 * (Pomes per nen) + 4 - 6 * (Pomes per nen) - 6 = 0
   * -2 * (Pomes per nen) - 2 = 0
   * -2 * (Pomes per nen) = 2
   * (Pomes per nen) = -1

   Com que no podem tenir un nombre negatiu de pomes per nen, hem de revisar les nostres suposicions.
