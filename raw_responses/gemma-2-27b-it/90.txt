## Raonament:

1. **Reordenar l'equació:** Per facilitar la resolució, reordenem l'equació en forma quadràtica estàndard:
   x² - 2014x - 2015 = 0

2. **Discriminant:** Per determinar el nombre de solucions reals d'una equació quadràtica, calculem el discriminant (Δ):
   Δ = b² - 4ac
   On a = 1, b = -2014 i c = -2015

3. **Calcular el discriminant:**
   Δ = (-2014)² - 4 * 1 * (-2015) = 4056196 + 8060 = 4064256

4. **Interpretar el discriminant:**
   * Si Δ > 0, l'equació té dues solucions reals i diferents.
   * Si Δ = 0, l'equació té una solució real (doble).
   * Si Δ < 0, l'equació no té solucions reals.

   En aquest cas, Δ = 4064256, que és major que 0.
