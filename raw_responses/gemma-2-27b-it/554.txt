## Raonament:

1. **Manipulem l'equació 1/w + 1/x = 1:**
   - Trobem un denominador comú: (w*x)/(w*x)
   - L'equació es converteix en: (x + w)/(w*x) = 1
   - Multiplicant ambdós costats per (w*x) obtenim: x + w = w*x

2. **Substituïm w + x = 3:**
   - Sabem que w + x = 3, per tant podem substituir-ho a l'equació anterior: 3 = w*x

3. **Calculem x/w + w/x:**
   - Trobem un denominador comú: (w*x)/(w*x)
   - L'expressió es converteix en: (x² + w²)/(w*x)
   - Observem que (x + w)² = x² + 2xw + w²
   - Per tant, x² + w² = (x + w)² - 2xw
   - Substituïm x + w = 3 i w*x = 3: (3)² - 2(3) = 9 - 6 = 3

4. **Resultat:**
   - x/w + w/x = (x² + w²)/(w*x) = 3/3 = 1
