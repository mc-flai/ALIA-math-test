## Raonament:

1. **Definir variables:**

* Sigui  'x' la longitud d'una de les cordes.
* Llavors, la longitud de l'altra corda serà '40 - x'.

2. **Longitud del costat dels quadrats:**

* El costat del quadrat format per la corda de longitud 'x' serà 'x/4'.
* El costat del quadrat format per la corda de longitud '40 - x' serà '(40 - x)/4'.

3. **Àrees dels quadrats:**

* Àrea del primer quadrat: (x/4)² = x²/16
* Àrea del segon quadrat: ((40 - x)/4)² = (40 - x)²/16

4. **Equació:**

* Sabem que la suma de les àrees és 68 m²: x²/16 + (40 - x)²/16 = 68

5. **Simplificar i resoldre l'equació:**

* Multiplicar ambdós costats per 16: x² + (40 - x)² = 1088
* Expandir: x² + 1600 - 80x + x² = 1088
* Simplificar: 2x² - 80x + 512 = 0
* Dividir per 2: x² - 40x + 256 = 0
* Factoritzar: (x - 16)(x - 24) = 0
* Solucions: x = 16 o x = 24

6. **Trobar les àrees:**

* Si x = 16, les àrees dels quadrats són 16 m² i 64 m². La diferència és 48 m².
* Si x = 24, les àrees dels quadrats són 36 m² i 16 m². La diferència és 20 m².

7. **Resposta:**

La diferència entre les àrees dels dos quadrats pot ser 20 m² o 48 m².  **La resposta correcta és A) 20 m²**.
