## Raonament:

Per determinar si un punt pertany a una recta, podem substituir les coordenades del punt a l'equació de la recta. Si l'equació es compleix, el punt pertany a la recta.

En aquest cas, el punt $P(2, -1)$ ha de satisfer l'equació $ax + by = c$. Substituint les coordenades del punt, obtenim:

$a(2) + b(-1) = c$

$2a - b = c$

Ara, podem comprovar cada opció de resposta substituint els valors de $a$, $b$ i $c$ en l'equació anterior:

* **A) $a = −1, b = 1, c = −3$:**  2(-1) - 1 = -3. L'equació es compleix.
* **B) $a = 1, b = 0, c = 2$:** 2(1) - 0 = 2. L'equació es compleix.
* **C) $a = 0, b = 3, c = −3$:** 2(0) - 3 = -3. L'equació es compleix.
* **D) $a = 10, b = 15, c = 5$:** 2(10) - 15 = 5. L'equació es compleix.
* **E) $a = 1, b = 2, c = 1$:** 2(1) - 2 = 0. L'equació no es compleix.

## Resposta:

E)
