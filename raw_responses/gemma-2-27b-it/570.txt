## Raonament:

Un prisma té dues bases idèntiques i cares laterals rectangulars. 

* **Bases:** Les dues bases contribueixen amb 2 * n cares, on 'n' és el nombre de costats de cada base.
* **Cares Laterals:** Les cares laterals contribueixen amb n cares.

Per tant, el nombre total de cares d'un prisma és 2n + n = 3n.

Sabem que el prisma té 2018 cares, per tant: 3n = 2018.

Resolent per 'n', obtenim n = 672.

El nombre de vèrtexs d'un prisma es calcula com 2n.

Per tant, el prisma té 2 * 672 = 1344 vèrtexs.

## Resposta:

E) No pot tenir 2018 cares
