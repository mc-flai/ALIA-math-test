Per determinar quins punts pertanyen a la gràfica de la funció, hem de substituir les coordenades x i y de cada punt a l'equació y = bx + 1 i comprovar si la igualtat es compleix.

* **Opció A) (0,0) i (1,0):**
    * Per (0,0): 0 = b(0) + 1 => 0 = 1 (fals)
    * Per (1,0): 0 = b(1) + 1 => -1 = b (possible si b = -1)
* **Opció B) (0,b) i (1,0):**
    * Per (0,b): b = b(0) + 1 => b = 1 (possible si b = 1)
    * Per (1,0): 0 = b(1) + 1 => -1 = b (possible si b = -1)
* **Opció C) (0, 1) i (b, 0):**
    * Per (0, 1): 1 = b(0) + 1 => 0 = 0 (cert)
    * Per (b, 0): 0 = b(b) + 1 => -1 = b² (no possible per b real)
* **Opció D) (0,1) i (-1,0):**
    * Per (0,1): 1 = b(0) + 1 => 0 = 0 (cert)
    * Per (-1,0): 0 = b(-1) + 1 => 1 = b (possible si b = 1)
* **Opció E) (0,-) i (1,0):**
