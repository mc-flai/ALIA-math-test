## Raonament:

1. **Trobar la taxa de cada collidor:** Per saber quanta part d'una caixa omple cada collidor per minut, dividim 1 (caixa completa) pel temps que triga:
    * Joan: 1 caixa / 30 minuts = 1/30 caixa per minut
    * Jordi: 1 caixa / 45 minuts = 1/45 caixa per minut
    * Josep: 1 caixa / 36 minuts = 1/36 caixa per minut

2. **Sumar les taxes:** Per saber la taxa combinada dels tres collidors, sumem les seves taxes individuals:
    * 1/30 + 1/45 + 1/36 = 12/360 + 8/360 + 10/360 = 30/360 = 1/12 caixa per minut

3. **Calcular el temps total:** Per saber quant de temps triguen a omplir tres caixes, dividim el nombre total de caixes (3) per la taxa combinada (1/12 caixa per minut):
    * 3 caixes / (1/12 caixa per minut) = 36 minuts

## Resposta: B) 36 minuts
