## Raonament:

1. **Manipulem l'equació donada:**

   Comencem amb l'equació a² + b² = 6ab.  Podem reordenar-la per obtenir:

   a² - 6ab + b² = 0

2. **Observem que es tracta d'un trinomi quadrat:**

   La equació anterior té la forma d'un trinomi quadrat en 'a'.

3. **Apliquem la fórmula quadràtica:**

   Per trobar les solucions per 'a', podem aplicar la fórmula quadràtica:

   a = (-b ± √(b² - 4ac)) / 2c

   On a = 1, b = -6b, i c = b².

4. **Simplifiquem la fórmula:**

   Substituint els valors de a, b i c a la fórmula quadràtica, obtenim:

   a = (6b ± √((-6b)² - 4 * 1 * b²)) / (2 * 1)

   a = (6b ± √(36b² - 4b²)) / 2

   a = (6b ± √(32b²)) / 2

   a = (6b ± 4√2 * b) / 2

   a = 3b ± 2√2 * b

5. **Considerem la condició 0 < b < a:**

   Sabem que 0 < b < a. Per tant, la solució a = 3b - 2√2 * b no és vàlida, ja que resultaria en a < b.

   Per tant, la solució correcta és:

   a = 3b + 2√2 * b

   a = b(3 + 2√2)

6. **Calculem (a + b) / (a - b):**

   Substituint el valor de 'a' que hem trobat:

   (a + b) / (a - b) = (b(3 + 2√2) + b) / (b(3 + 2√2) - b)

   (a + b) / (a - b) = b(4 + 2√2) / b(2 + 2√2)

   (a + b) / (a - b) = (4 + 2√2) / (2 + 2√2)

7. **Simplifiquem la fracció:**

   Multiplicant el numerador i el denominador per (2 - 2√2), obtenim:

   (a + b) / (a - b) = ((4 + 2√2)(2 - 2√2)) / ((2 + 2√2)(2 - 2√2))

   (a + b) / (a - b) = (8 - 8√2 + 4√2 - 8) / (4 - 8)

   (a + b) / (a - b) = (-4√2) / (-4)

   (a + b) / (a - b) = √2
