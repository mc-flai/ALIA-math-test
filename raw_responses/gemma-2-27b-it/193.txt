## Raonament:

1. **Factorització:** Observem que la primera equació (ac + ad + bc + bd = 68) pot ser factoritzada:
   ac + ad + bc + bd = (a + b)(c + d)

2. **Substitució:** Sabem que c + d = 4. Substituïm aquest valor a l'equació factoritzada:
   (a + b)(4) = 68

3. **Simplificació:** Dividim ambdós costats per 4:
   a + b = 17

4. **Suma total:** Finalment, sumem a + b amb c + d:
   a + b + c + d = 17 + 4 = 21

## Resposta: C) 21
