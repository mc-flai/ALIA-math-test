## Raonament:

1. **Manipulem les equacions:**

   Tenim el sistema d'equacions:

   * 2017 + x = y²
   * 2017 + y = x²

   Podem aïllar x en la primera equació:

   * x = y² - 2017

   I substituir aquest valor de x en la segona equació:

   * 2017 + y = (y² - 2017)²

2. **Simplifiquem i resolguem per y:**

   * 2017 + y = y⁴ - 4034y² + 2017²
   * 0 = y⁴ - 4034y² + 2017² - y - 2017
   * 0 = y⁴ - 4034y² + 2017(2017 - 1) - y

   Aquesta és una equació de quart grau que pot ser difícil de resoldre directament. No obstant això, podem notar que si y = 2017, l'equació es compleix.

3. **Trobem x:**

   Si y = 2017, podem substituir aquest valor en qualsevol de les equacions originals per trobar x. Utilitzant la primera equació:

   * 2017 + x = 2017²
   * x = 2017² - 2017
   * x = 2017(2017 - 1)

4. **Calculem xy:**

   * xy = 2017(2017 - 1) * 2017
   * xy = 2017³ - 2017²
   * xy = 2017²(2017 - 1)
   * xy = 2017² * 2016
   * xy = **-2016**
