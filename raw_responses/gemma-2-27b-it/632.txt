## Raonament:

1. **Definim variables:**
    * J = Nombre de problemes resolts per Joan
    * P = Nombre de problemes resolts per Pau
    * C = Nombre de problemes resolts per Clara
    * T = Nombre de problemes resolts per Tomàs

2. **Tradueix les informacions a equacions:**
    * P = J + 8  (Pau ha resolt 8 més que Joan)
    * P = C + 11 (Pau ha resolt 11 més que Clara)
    * T = J + 3 (Tomàs ha resolt 3 més que Joan)

3. **Troba el valor de J (problemes resolts per Joan):**
    * Com que P = J + 8 i P = C + 11, podem igualar les dues expressions: J + 8 = C + 11
    * Despejem J: J = C + 3

4. **Substitueix J en l'equació de T:**
    * T = (C + 3) + 3
    * T = C + 6

5. **Calcula la diferència entre T i C:**
    * T - C = (C + 6) - C = 6
