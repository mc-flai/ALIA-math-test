## Raonament:

1. **Divisibilitat per 5:** Un nombre és divisible per 5 si la seva última xifra és 0 o 5. Per tant, Y ha de ser 0 o 5.

2. **Divisibilitat per 4:** Un nombre és divisible per 4 si les dues últimes xifres formen un nombre divisible per 4. Si Y = 0, les dues últimes xifres serien 80, que és divisible per 4. Si Y = 5, les dues últimes xifres serien 85, que no és divisible per 4. Per tant, Y = 0.

3. **Divisibilitat per 9:** Un nombre és divisible per 9 si la suma de les seves xifres és divisible per 9. Tenim 2 + 4 + X + 8 + 0 = 14 + X. Per trobar un valor de X que faci que la suma sigui divisible per 9, X ha de ser 4 (14 + 4 = 18, divisible per 9).

4. **Suma X + Y:** X = 4 i Y = 0, per tant X + Y = 4 + 0 = 4.
