## Raonament:

Els anys del segle XXI van del 2001 al 2100.  Necessitem trobar quants d'aquests anys tenen la suma de dígits igual a 4.

* **Unitats:** Els dígits de les unitats que sumen 4 amb els altres dígits possibles són: 0, 1, 2, 3, 4.

* **Desenes:** Per a cada dígit de les unitats, podem calcular quins dígits de les desenes fan que la suma sigui 4.

* **Centenes:** Els dígits de les centenes sempre seran 2, ja que estem parlant del segle XXI.

* **Mils:** El dígit de les milers sempre serà 2.

Analitzem les combinacions possibles:

* **Dígit de les unitats 0:**  Dígit de les desenes 4 (2040)
* **Dígit de les unitats 1:**  Dígit de les desenes 3 (2031)
* **Dígit de les unitats 2:**  Dígit de les desenes 2 (2022)
* **Dígit de les unitats 3:**  Dígit de les desenes 1 (2013)
* **Dígit de les unitats 4:**  Dígit de les desenes 0 (2004)

## Resposta:

E) 6
