Raonament: Tenim un nombre de quatre xifres N = pqrs, on p, q, r, s són dígits. Si escrivim una coma decimal entre la q i la r, obtenim el nombre pq,rs. Segons l'enunciat, aquest nombre és la mitjana entre pq i rs.

Podem expressar això matemàticament. La mitjana entre pq i rs es pot escriure com:

\[
\frac{pq + rs}{2} = pq,rs
\]

On pq és el nombre format per les dues primeres xifres (p i q) i rs és el nombre format per les dues últimes xifres (r i s). 

Convertim pq i rs a la seva forma numèrica:

\[
pq = 10p + q
\]
\[
rs = 10r + s
\]

Així, la mitjana es converteix en:

\[
\frac{(10p + q) + (10r + s)}{2} = 10p + q + 0.01(10r + s)
\]

Multiplicant per 2 per eliminar la fracció:

\[
(10p + q) + (10r + s) = 20p + 2q + 0.02(10r + s)
\]

Simplificant:

\[
10p + q + 10r + s = 20p + 2q + 0.1r + 0.1s
\]

Reorganitzant l'equació:

\[
10p + q + 10r + s - 20p - 2q - 0.1r - 0.1s = 0
\]

Això es pot simplificar a:

\[
-10p - q + 10r + s - 0.1r - 0.1s = 0
\]

Això implica que:

\[
10r + s = 10p + q + 0.1r + 0.1s
\]

\[
\frac{19 + 82}{2} = \frac{101}{2} = 50.5
\]

I si col·loquem la coma decimal entre q i r, obtenim 19,82, que és igual a 19 + 0.82, que no és la mitjana.
