Raonament: Busquem nombres enters de tres xifres (entre 100 i 999) on la suma de les seves tres xifres sigui igual a 3. Les xifres d'un nombre de tres xifres es poden representar com \(a\), \(b\) i \(c\), on \(a\) és la xifra de les centenes, \(b\) és la xifra de les desenes i \(c\) és la xifra de les unitats. 

Com que \(a\) ha de ser almenys 1 (perquè el nombre ha de ser de tres xifres), podem escriure l'equació:

\[ a + b + c = 3 \]

Amb la condició que \(1 \leq a \leq 3\) (ja que si \(a\) fos més gran que 3, la suma no podria ser 3). 

Analitzem les possibilitats per a \(a\):

1. **Si \(a = 1\)**:
   \[ 1 + b + c = 3 \]
   \[ b + c = 2 \]
   Les combinacions possibles per a \(b\) i \(c\) són:
   - \(b = 0, c = 2\) → 102
   - \(b = 1, c = 1\) → 111
   - \(b = 2, c = 0\) → 120

   Així que tenim 3 nombres: 102, 111, 120.

2. **Si \(a = 2\)**:
   \[ 2 + b + c = 3 \]
   \[ b + c = 1 \]
   Les combinacions possibles per a \(b\) i \(c\) són:
   - \(b = 0, c = 1\) → 201
   - \(b = 1, c = 0\) → 210

   Així que tenim 2 nombres: 201, 210.

3. **Si \(a = 3\)**:
   \[ 3 + b + c = 3 \]
   \[ b + c = 0 \]
   La única combinació possible és:
   - \(b = 0, c = 0\) → 300

   Així que tenim 1 nombre: 300.

Ara sumem tots els nombres que hem trobat:
- De \(a = 1\): 3 nombres (102, 111, 120)
- De \(a = 2\): 2 nombres (201, 210)
- De \(a = 3\): 1 nombre (300)

En total, tenim \(3 + 2 + 1 = 6\) nombres enters de tres xifres que compleixen la condició.

Resposta: D) 6
