Raonament: Tenim dues equacions: 

1. \( ac + ad + bc + bd = 68 \)
2. \( c + d = 4 \)

Podem reescriure la primera equació agrupant termes:

\[
a(c + d) + b(c + d) = 68
\]

Substituïm \( c + d \) per 4 (de la segona equació):

\[
a(4) + b(4) = 68
\]

Això es pot simplificar a:

\[
4a + 4b = 68
\]

Dividim tota l'equació per 4:

\[
a + b = 17
\]

Ara tenim dues equacions:

1. \( a + b = 17 \)
2. \( c + d = 4 \)

Per trobar \( a + b + c + d \), simplement sumem les dues equacions:

\[
a + b + c + d = (a + b) + (c + d) = 17 + 4 = 21
\]

Per tant, el valor de \( a + b + c + d \) és 21.

Resposta: C)
