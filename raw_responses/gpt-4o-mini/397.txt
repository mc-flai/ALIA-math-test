Raonament: Comencem amb l'equació donada:

\[
\tan x + \cot x = \pi
\]

Recordem que \(\tan x = \frac{\sin x}{\cos x}\) i \(\cot x = \frac{\cos x}{\sin x}\). Per tant, podem reescriure l'equació com:

\[
\frac{\sin x}{\cos x} + \frac{\cos x}{\sin x} = \pi
\]

Això es pot simplificar a un denominador comú:

\[
\frac{\sin^2 x + \cos^2 x}{\sin x \cos x} = \pi
\]

Sabem que \(\sin^2 x + \cos^2 x = 1\), així que substituïm:

\[
\frac{1}{\sin x \cos x} = \pi
\]

Ara, podem invertir l'equació:

\[
\sin x \cos x = \frac{1}{\pi}
\]

Sabem que \(\sin x \cos x\) es pot expressar com \(\frac{1}{2} \sin(2x)\), però en aquest cas, no necessitem aquesta identitat. Simplement hem trobat que:

\[
\sin x \cos x = \frac{1}{\pi}
\]
