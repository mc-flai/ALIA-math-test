1. **Cas 1: x < 2019**
   En aquest cas, tant |x - 2019| com |x - 2020| es poden escriure sense el valor absolut:
   \[
   |x - 2019| = 2019 - x \quad \text{i} \quad |x - 2020| = 2020 - x
   \]
   Així, l'equació es converteix en:
   \[
   (2019 - x) + (2020 - x) = 3 \implies 4039 - 2x = 3 \implies 2x = 4036 \implies x = 2018
   \]

   \[
   |x - 2019| = x - 2019 \quad \text{i} \quad |x - 2020| = 2020 - x
   \]
   L'equació es converteix en:
   \[
   (x - 2019) + (2020 - x) = 3 \implies 1 = 3
   \]

   \[

   \]
   L'equació es converteix en:
   \[
   (x - 2019) + (x - 2020) = 3 \implies 2x - 4039 = 3 \implies 2x = 4042 \implies x = 2021
   \]
