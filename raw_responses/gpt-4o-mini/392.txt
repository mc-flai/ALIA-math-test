Raonament: Comencem resolent l'equació donada:

n⁴ – n³ – n² + 8 = 2017

Podem reordenar l'equació per igualar-la a zero:

n⁴ – n³ – n² + 8 - 2017 = 0

Això es converteix en:

n⁴ – n³ – n² - 2009 = 0

Ara, busquem un valor natural per n que satisfaci aquesta equació. Probem amb les opcions donades:

1. **n = 5**:
   n⁴ = 625, n³ = 125, n² = 25
   625 - 125 - 25 - 2009 = 625 - 125 - 25 - 2009 = 625 - 150 - 2009 = 625 - 2159 = -1534 (no és zero)

2. **n = 7**:
   n⁴ = 2401, n³ = 343, n² = 49
   2401 - 343 - 49 - 2009 = 2401 - 343 - 49 - 2009 = 2401 - 392 - 2009 = 2401 - 2401 = 0 (és zero)

3. **n = 9**:
   n⁴ = 6561, n³ = 729, n² = 81
   6561 - 729 - 81 - 2009 = 6561 - 729 - 81 - 2009 = 6561 - 810 - 2009 = 6561 - 2819 = 3742 (no és zero)

4. **n = 41**:
   n⁴ = 2825761, n³ = 68921, n² = 1681
   2825761 - 68921 - 1681 - 2009 = 2825761 - 68921 - 1681 - 2009 = 2825761 - 72611 - 2009 = 2825761 - 74620 = 2751141 (no és zero)

Després de provar les opcions, només n = 7 satisfà l'equació.
