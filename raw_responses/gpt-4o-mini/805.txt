Raonament: 
Anomenem \( C \) la capacitat de cada barril en litres. Inicialment, el primer barril (B1) està buit i el segon barril (B2) està ple amb \( C \) litres d'aigua. Quan Dani traspassa 50 litres d'aigua del segon al primer, el primer barril conté 50 litres i el segon barril conté \( C - 50 \) litres.

Segons l'enunciat, després del trasllat, el primer barril conté un 25% més d'aigua que el segon. Això es pot expressar matemàticament com:

\[
50 = 1.25 \times (C - 50)
\]

Ara resolem aquesta equació:

1. Multipliquem els dos costats per 4 per eliminar el decimal:
   \[
   200 = 5 \times (C - 50)
   \]

2. Dividim els dos costats per 5:
   \[
   40 = C - 50
   \]

3. Aïllem \( C \):
   \[
   C = 40 + 50 = 90
   \]

Per tant, la capacitat de cada barril és de 90 litres.
