Raonament: Comencem simplificant l'equació donada. Tenim 9ⁿ sumat 9 vegades, el que es pot escriure com:

9ⁿ + 9ⁿ + 9ⁿ + 9ⁿ + 9ⁿ + 9ⁿ + 9ⁿ + 9ⁿ + 9ⁿ = 9 * 9ⁿ = 9¹ * 9ⁿ = 9^(n+1).

Així que podem reescriure l'equació com:

9^(n+1) = 3²⁰¹⁶.

Ara, recordem que 9 es pot expressar com 3², per tant:

(3²)^(n+1) = 3²⁰¹⁶.

Això es pot simplificar a:

3^(2(n+1)) = 3²⁰¹⁶.

Com que les bases són iguals, podem igualar els exponents:

2(n + 1) = 2016.

Ara resolem per n:

n + 1 = 2016 / 2,
n + 1 = 1008,
n = 1008 - 1,
n = 1007.

Per tant, el valor de n és 1007.
