Raonament: Per comparar les fraccions, podem calcular el valor de cada una d'elles en funció de p i q, tenint en compte que p < q. Una manera de fer-ho és expressar cada fracció en termes de q, ja que és el nombre més gran. 

1. **Fracció A**: \((p + 3q)/4 = (p/4) + (3q/4)\)
2. **Fracció B**: \((p + 2q)/3 = (p/3) + (2q/3)\)
3. **Fracció C**: \((p + q)/2 = (p/2) + (q/2)\)
4. **Fracció D**: \((2p + q)/3 = (2p/3) + (q/3)\)
5. **Fracció E**: \((3p + q)/4 = (3p/4) + (q/4)\)

Ara, per comparar les fraccions, podem substituir p per un valor que sigui menor que q. Per exemple, si considerem p = 1 i q = 2, podem calcular cada fracció:

- A: \((1 + 3*2)/4 = (1 + 6)/4 = 7/4 = 1.75\)
- B: \((1 + 2*2)/3 = (1 + 4)/3 = 5/3 \approx 1.67\)
- C: \((1 + 2)/2 = 3/2 = 1.5\)
- D: \((2*1 + 2)/3 = (2 + 2)/3 = 4/3 \approx 1.33\)
- E: \((3*1 + 2)/4 = (3 + 2)/4 = 5/4 = 1.25\)

Comparant els resultats:
- A = 1.75
- B ≈ 1.67
- C = 1.5
- D ≈ 1.33
- E = 1.25

La fracció A és la més gran.
