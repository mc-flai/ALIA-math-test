Raonament: Per determinar quina funció talla l'eix X exactament dues vegades, hem de buscar les funcions que tinguin dues solucions reals per a l'equació f(x) = 0. 

A) f(x) = sin x − 1: Aquesta funció talla l'eix X quan sin x = 1, que ocorre en infinites solucions (x = π/2 + 2kπ, on k és un enter). Per tant, no talla l'eix X exactament dues vegades.

B) f(x) = x² - 1: Aquesta és una funció quadràtica que talla l'eix X en els punts on x² - 1 = 0, és a dir, x² = 1. Això dóna dues solucions: x = 1 i x = -1. Per tant, talla l'eix X exactament dues vegades.

C) f(x) = e^x - 1: Aquesta funció talla l'eix X quan e^x = 1, que ocorre només quan x = 0. Per tant, talla l'eix X una sola vegada.

D) f(x) = ln x − 1: Aquesta funció talla l'eix X quan ln x = 1, és a dir, x = e. Això significa que talla l'eix X una sola vegada.

E) f(x) = x - 1: Aquesta funció talla l'eix X quan x - 1 = 0, és a dir, x = 1. Això significa que talla l'eix X una sola vegada.

Després d'analitzar totes les opcions, només la funció B) f(x) = x² - 1 talla l'eix X exactament dues vegades.

Resposta: B)
