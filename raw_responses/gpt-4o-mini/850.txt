Raonament: Anomenem les quantitats de diners que porta cada persona de la següent manera:
- A = diners que porta Alba
- B = diners que porta Bernat
- C = diners que porta Cris
- D = diners que porta David

Segons les dades proporcionades, tenim les següents equacions:
1. A + B = 5 € (Alba i Bernat)
2. C + D = 6 € (Cris i David)
3. A + C = 7 € (Alba i Cris)

A partir de la tercera equació, podem expressar A en funció de C:
A = 7 - C

Substituïm A en la primera equació:
(7 - C) + B = 5
B = 5 - 7 + C
B = C - 2

Ara tenim B en funció de C. Substituïm B en la segona equació:
C + D = 6
C + (C - 2) = 6
2C - 2 = 6
2C = 8
C = 4

Ara que tenim C, podem trobar B:
B = C - 2 = 4 - 2 = 2

I també podem trobar A:
A = 7 - C = 7 - 4 = 3

Finalment, podem trobar D a partir de la segona equació:
C + D = 6
4 + D = 6
D = 2

Ara sabem que:
- A = 3 €
- B = 2 €
- C = 4 €
- D = 2 €

Per tant, la quantitat de diners que porten entre Bernat i David és:
B + D = 2 + 2 = 4 €
