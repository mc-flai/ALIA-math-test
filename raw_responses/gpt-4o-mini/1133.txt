Raonament: Comencem analitzant la relació donada: \( p(x + 1) = x^2 - x + 2 \cdot p(6) \). Aquesta equació ens indica que el polinomi \( p \) es pot expressar en funció de \( x \) i d'un valor constant \( p(6) \).

1. **Identifiquem el grau del polinomi**: Observem que el terme del costat dret, \( x^2 - x + 2 \cdot p(6) \), és un polinomi de grau 2. Això implica que \( p(x) \) ha de ser un polinomi de grau 2 o menor, ja que la substitució de \( x + 1 \) no pot augmentar el grau del polinomi.

2. **Suposem la forma de \( p(x) \)**: Suposem que \( p(x) = ax^2 + bx + c \), on \( a, b, c \) són constants que hem de determinar.

3. **Substituïm \( x + 1 \) a \( p(x) \)**:
   \[
   p(x + 1) = a(x + 1)^2 + b(x + 1) + c = a(x^2 + 2x + 1) + b(x + 1) + c = ax^2 + (2a + b)x + (a + b + c)
   \]

4. **Igualem amb el costat dret**:
   \[
   ax^2 + (2a + b)x + (a + b + c) = x^2 - x + 2p(6)
   \]
   Això ens dóna les següents equacions per igualar coeficients:
   - \( a = 1 \) (coeficient de \( x^2 \))
   - \( 2a + b = -1 \) (coeficient de \( x \))
   - \( a + b + c = 2p(6) \) (terme independent)

5. **Resolvem les equacions**:
   - De \( a = 1 \), substituïm a la segona equació:
     \[
     2(1) + b = -1 \implies 2 + b = -1 \implies b = -3
     \]
   - Ara substituïm \( a \) i \( b \) a la tercera equació:
     \[
     1 - 3 + c = 2p(6) \implies -2 + c = 2p(6) \implies c = 2p(6) + 2
     \]

6. **Trobar \( p(6) \)**: Ara substituïm \( x = 5 \) a la relació original:
   \[
   p(6) = 5^2 - 5 + 2p(6) \implies p(6) = 25 - 5 + 2p(6) \implies p(6) - 2p(6) = 20 \implies -p(6) = 20 \implies p(6) = -20
   \]

7. **Substituïm \( p(6) \) a la fórmula de \( c \)**:
   \[
   c = 2(-20) + 2 = -40 + 2 = -38
   \]

   \[
   p(x) = x^2 - 3x - 38
   \]

   \[
