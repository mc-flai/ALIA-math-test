## Raonament:

1. **Definir les variables:**
   *  Per a un triangle rectangle, els angles són:
      *  Angle major:  x
      *  Angle menor: y
      *  Angle mitjà: (x + y) / 2

2. **Utilitzar la relació entre els angles:**
   *  L'angle major és el triple del menor: x = 3y

3. **Escriure una equació amb les mesures dels angles:**
   *  La suma de tots els angles d'un triangle és 180°.  
   *  x + y + (x + y) / 2 = 180°

4. **Substituir la relació entre x i y:**
   *  3y + y + (3y + y) / 2 = 180°
   *  3y + y + 4y / 2 = 180°
   *  3y + y + 2y = 180°
   *  6y = 180°

5. **Encontrar el valor de y:**
   *  y = 180° / 6
   *  y = 30°

6. **Encontrar el valor de x:**
   *  x = 3y
   *  x = 3 * 30°
   *  x = 90°

7. **Encontrar el valor de l'angle mitjà:**
   *  (x + y) / 2 = (90° + 30°) / 2
   *  (90° + 30°) / 2 = 120° / 2
   *  120° / 2 = 60°

## Resposta: C) 60°
