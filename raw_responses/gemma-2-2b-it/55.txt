## Raonament:

1. **Simplificar la equació:**  Comencem per simplificar l'equació  `a² + b² = 6ab`.  
   *  Reordenem la equació per a obtenir: `a² - 6ab + b² = 0`
   *  Fem un canvi de variable per a simplificar: `(a - 3b)² = 9b²`
   *  Aquesta equació ens indica que `a - 3b` és igual a `3b` o `-3b`.

2. **Analitzar les possibles solucions:**
   * Si `a - 3b = 3b`, llavors `a = 6b`.
   * Si `a - 3b = -3b`, llavors `a = 0`.

3. **Analitzar les condicions:**
   *  Amb `a = 6b` i `0 < b < a`, la solució `a = 6b` no és compatible amb la condició `0 < b < a`.
   *  Amb `a = 0` i `0 < b < a`, la solució `a = 0` és compatible amb la condició `0 < b < a`.

4. **Encontrar la relació (a+b)/(a-b):**
   *  Si `a = 0`, llavors `(a+b)/(a-b) = (0+b)/(0-b) = -b/b = -1`.

5. **Analitzar les opcions de resposta:**
   *  La resposta correcta és **C) 1/(√2-1)**.


## Resposta: C) 1/(√2-1)
