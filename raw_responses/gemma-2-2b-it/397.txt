## Raonament:

1. **Identificar la relació entre x, tan x y cot x:**  Sabemos que tan x + cot x = π. 
2. **Simplificar la ecuación:** Podemos usar la identidad trigonométrica: tan x = sin x / cos x y cot x = cos x / sin x. Sustituyendo en la ecuación original:
   (sin x / cos x) + (cos x / sin x) = π
3. **Resolver para sin x cos x:**  Multiplicamos ambos lados de la ecuación por cos x sin x:
   sin² x + cos² x = π cos x sin x
4. **Utilizar la identidad trigonométrica:**  Sabemos que sin² x + cos² x = 1.  Sustituyendo:
   1 = π cos x sin x
5. **Simplificar:**  Dividimos ambos lados por π:
   cos x sin x = 1/π
