2. **Definim les variables:**
    *  **n:** Nombre de cubs menuts.
    *  **x:** Nombre de cubs menuts amb una sola cara pintada.
    *  **y:** Nombre de cubs menuts sense cap cara pintada.

3. **Construim la relació:**
    *  **x + y = n** (tot el nombre de cubs menuts)
    *  **x = y** (els cubs menuts amb una sola cara pintada són iguals als sense)

4. **Resol la equació:**
    *  **x + y = n**
    *  **x = y**
    *  **2x = n**

5. **Analitzem les opcions:**
    *  **Opció A) 4:** Si n = 4, la relació entre els cubs menuts amb una sola cara pintada i els sense és 2.
    *  **Opció B) 6:** Si n = 6, la relació entre els cubs menuts amb una sola cara pintada i els sense és 2.
    *  **Opció C) 7:** Si n = 7, la relació entre els cubs menuts amb una sola cara pintada i els sense és 2.
    *  **Opció D) 8:** Si n = 8, la relació entre els cubs menuts amb una sola cara pintada i els sense és 2.
    *  **Opció E) 10:** Si n = 10, la relació entre els cubs menuts amb una sola cara pintada i els sense és 2.

6. **Conclusió:** La única opció que s'adapta a la relació entre els cubs menuts amb una sola cara pintada i els sense és **Opció A) 4**.
