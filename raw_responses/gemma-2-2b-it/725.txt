2. **Crear l'equació:**
   - La suma dels tres pesos és 97 kg, per tant: x + (x + 1) + (x + 2) = 97

3. **Resolució de l'equació:**
   - Combinem els termes amb x: 3x + 3 = 97
   - Subtraiem 3 de tots dos costats: 3x = 94
   - Dividim tots dos costats per 3: x = 31.33

4. **Pes del cangur més lleuger:**
   -  El pes del cangur més lleuger és 31.33 kg. 

5. **Resposta:**
   -  Per tant, el pes màxim del cangur més lleuger és 31 kg.
