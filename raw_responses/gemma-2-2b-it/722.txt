## Raonament:

* **Cada tirada de dados tiene 6 caras.**
* **Si lanzamos tres dados simultáneamente, podemos obtener 6^3 = 216 combinaciones posibles.**
* **Para cada combinación, podemos obtener una suma diferente.**
* **Para encontrar el número de sumas diferentes, debemos considerar que cada dado puede ser un número de 1 a 6.**

## Resposta:

**C) 16** 


**Explicación:**

Para obtener una suma diferente, se pueden obtener 6 resultados diferentes para cada dado. 

* **Dado 1:** 1, 2, 3, 4, 5, 6
* **Dado 2:** 1, 2, 3, 4, 5, 6
* **Dado 3:** 1, 2, 3, 4, 5, 6

Si se combinan los resultados de los tres dados, se pueden obtener 6^3 = 216 combinaciones posibles.
