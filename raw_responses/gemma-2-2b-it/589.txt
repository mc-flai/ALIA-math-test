## Raonament:

1. **Definim les variables:**
   -  Deixa's  `x`  el primer nombre real.
   -  Deixa's  `y`  el segon nombre real.

2. **Escriu l'equació:**
   -  "La suma de dos nombres reals és el triple que la seua diferència" es pot expressar com l'equació:  `x + y = 3(x - y)`

3. **Resol l'equació per a una de les variables:**
   -  Simplifiquem l'equació: `x + y = 3x - 3y`
   -  Reordenem per a `y`: `4y = 2x`
   -  Dividim per 4: `y = (1/2)x`

4. **Escriu la suma dels quadrats:**
   -  `x² + y² = (x² + (1/2)x * (1/2)x)`

5. **Escriu el producte:**
   -  `x² + y² = (x² + (1/4)x²)`

6. **Dividim la suma dels quadrats pel producte:**
   -  `(x² + (1/4)x²) / (xy)`

7. **Simplifiquem l'equació:**
   -  `(5/4)x² / (xy)`

8. **Simplifiquem l'equació:**
   -  `(5/4)x² / (xy) = (5/4)x / y`

9. **Substituïm el valor de y:**
   -  `(5/4)x / ((1/2)x)`

10. **Simplifiquem l'equació:**
   -  `(5/4)x / ((1/2)x) = (5/2)`
