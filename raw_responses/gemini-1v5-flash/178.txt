Raonament:

Tenim les desigualtats |a + b| ≤ 1 i |a - 3b| ≤ 2.  Aquestes desigualtats es poden reescriure com:

-1 ≤ a + b ≤ 1  (1)
-2 ≤ a - 3b ≤ 2  (2)

De (1), tenim -1 - a ≤ b ≤ 1 - a.

Substituint en (2):

-2 ≤ a - 3(1 - a) ≤ 2  (cas superior de b)
-2 ≤ a - 3 + 3a ≤ 2
-2 ≤ 4a - 3 ≤ 2
1 ≤ 4a ≤ 5
1/4 ≤ a ≤ 5/4

-2 ≤ a - 3(-1 - a) ≤ 2 (cas inferior de b)
-2 ≤ a + 3 + 3a ≤ 2
-2 ≤ 4a + 3 ≤ 2
-5 ≤ 4a ≤ -1
-5/4 ≤ a ≤ -1/4

Com que volem que existeixi *algun* valor de b que satisfaci les desigualtats, ens interessa la unió dels intervals trobats.  Per tant, l'interval que conté tots els valors possibles de 'a' és [-5/4, 5/4].  Observem que l'extrem superior 5/4 està inclòs, mentre que l'extrem inferior -5/4 també està inclòs.

Per tant, la resposta correcta és la que inclou l'interval [-5/4, 5/4].  Les opcions A i B són les que s'aproximen més, però només la A inclou correctament el -5/4.  La B exclou valors que sí que permeten trobar un b que compleixi les desigualtats.

Resposta: A)
