Tenim que a + b + c = 100 i 1/(a+b) + 1/(b+c) + 1/(a+c) = 0.1.  Volem trobar el valor de c/(a+b) + a/(b+c) + b/(c+a).

Observem que podem reescriure l'equació donada com:

1/(a+b) + 1/(b+c) + 1/(a+c) = 1/10

Multiplicant ambdues parts per 10, obtenim:

10/(a+b) + 10/(b+c) + 10/(a+c) = 1

Ara, suposem que  x = a+b, y = b+c, z = a+c.  Llavors, a+b+c = (x+y+z)/2 = 100, per tant x+y+z = 200.

L'expressió que volem calcular és:

c/(a+b) + a/(b+c) + b/(c+a) = c/x + a/y + b/z

No podem substituir directament.  No obstant, observem que:

c = (x+y+z)/2 - x = (y+z-x)/2
a = (x+z-y)/2
b = (x+y-z)/2

Substituint a l'expressió que volem calcular:

[(y+z-x)/2]/x + [(x+z-y)/2]/y + [(x+y-z)/2]/z = (y+z-x)/(2x) + (x+z-y)/(2y) + (x+y-z)/(2z)
