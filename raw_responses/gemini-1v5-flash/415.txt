Raonament:

Tenim el sistema d'equacions:

1) 2017 + x = y²
2) 2017 + y = x²

Restem l'equació (1) de l'equació (2):

(2017 + y) - (2017 + x) = x² - y²

y - x = x² - y²

y - x = (x - y)(x + y)

Si x ≠ y (com s'indica al problema), podem dividir per (x - y):

-1 = x + y

Per tant, x + y = -1.

Ara, sumem les dues equacions originals:

(2017 + x) + (2017 + y) = y² + x²

4034 + x + y = x² + y²

Substituïm x + y = -1:

4034 + (-1) = x² + y²

4033 = x² + y²

Sabem que (x + y)² = x² + 2xy + y²

(-1)² = x² + y² + 2xy

1 = 4033 + 2xy

2xy = 1 - 4033

2xy = -4032

xy = -2016

Resposta: B)
