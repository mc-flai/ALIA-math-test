Raonament:  Siguem V l'edat de Vicent, D l'edat de Dolors i R l'edat de Rafael.  Tenim el següent sistema d'equacions:

* V + D = 105
* D + R = 96
* V + R = 117

Sumem les tres equacions:

2V + 2D + 2R = 105 + 96 + 117 = 318

Dividim per 2:

V + D + R = 159

Ara, podem restar cada una de les equacions originals d'aquesta suma per trobar l'edat de cada persona:

* (V + D + R) - (V + D) = R  => 159 - 105 = 54
* (V + D + R) - (D + R) = V  => 159 - 96 = 63
* (V + D + R) - (V + R) = D  => 159 - 117 = 42

Per tant, l'edat de Rafael (R) és 54 anys.
