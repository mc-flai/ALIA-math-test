L'equació és cúbica, per tant té tres solucions.  Si una de les solucions és 2 - √3, i els coeficients de l'equació són reals, llavors una altra solució ha de ser el conjugat, 2 + √3.  Siguin les tres solucions α, β, i γ.  Per la relació entre les arrels i els coeficients d'una equació cúbica de la forma ax³ + bx² + cx + d = 0, tenim:

* α + β + γ = -b/a
* αβ + αγ + βγ = c/a
* αβγ = -d/a

En el nostre cas, a = 1, b = -5, c = 5, d = -1.  Per tant:

* α + β + γ = -(-5)/1 = 5

Ja sabem que α = 2 - √3 i β = 2 + √3.  Per tant, podem trobar γ:

* (2 - √3) + (2 + √3) + γ = 5
* 4 + γ = 5
* γ = 1

La suma de les altres dues solucions és β + γ = (2 + √3) + 1 = 3 + √3
