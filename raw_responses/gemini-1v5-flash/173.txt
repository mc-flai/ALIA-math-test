Raonament:

Aquest problema es pot resoldre utilitzant el principi d'inclusió-exclusió.  Tenim el nombre total de llaunes (36) i el nombre de llaunes amb cada color:

* Blanc (B): 25
* Blau (A): 28
* Verd (V): 20

També sabem que 5 llaunes tenen els tres colors (B ∩ A ∩ V = 5).

El principi d'inclusió-exclusió per a tres conjunts és:

|B ∪ A ∪ V| = |B| + |A| + |V| - |B ∩ A| - |B ∩ V| - |A ∩ V| + |B ∩ A ∩ V|

Sabem que |B ∪ A ∪ V| = 36 (el nombre total de llaunes).  Substituint els valors coneguts:

36 = 25 + 28 + 20 - |B ∩ A| - |B ∩ V| - |A ∩ V| + 5

Simplificant:

36 = 78 - |B ∩ A| - |B ∩ V| - |A ∩ V|

|B ∩ A| + |B ∩ V| + |A ∩ V| = 78 - 36 = 42

Ara, per trobar el nombre de llaunes amb un sol color, necessitem restar les llaunes amb dos o més colors del total.  Per fer-ho, podem utilitzar la següent fórmula:

Llaunes amb un sol color = Total - (Llaunes amb dos colors + Llaunes amb tres colors)

Primer, trobem el nombre de llaunes amb almenys dos colors:

Llaunes amb almenys dos colors = |B ∩ A| + |B ∩ V| + |A ∩ V| - 2 * |B ∩ A ∩ V| = 42 - 2 * 5 = 32

Llaunes amb un sol color = 36 - 32 = 4

Resposta: B)
