Raonament:

Siguin les distàncies entre els punts:
AB = x
BC = y
CD = z
DE = w
EF = v

Tenim que AD = CF i BD = DF.

AD = AB + BC + CD = x + y + z
CF = CD + DE + EF = z + w + v

Com AD = CF, llavors x + y + z = z + w + v  => x + y = w + v  (1)

BD = BC + CD = y + z
DF = DE + EF = w + v

Com BD = DF, llavors y + z = w + v  (2)

De (1) i (2), tenim que x + y = y + z, per tant x = z.  Això significa que AB = CD.
