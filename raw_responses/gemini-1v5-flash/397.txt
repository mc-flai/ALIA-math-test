Raonament:

Tenim que tan x + cot x = π.  Sabem que tan x = sin x / cos x i cot x = cos x / sin x.  Per tant, podem reescriure l'equació com:

sin x / cos x + cos x / sin x = π

Per a simplificar, trobem un denominador comú:

(sin²x + cos²x) / (sin x · cos x) = π

Recordem la identitat trigonomètrica fonamental: sin²x + cos²x = 1.  Substituint-la a l'equació anterior:

1 / (sin x · cos x) = π

Ara, aïllem sin x · cos x:

sin x · cos x = 1 / π
