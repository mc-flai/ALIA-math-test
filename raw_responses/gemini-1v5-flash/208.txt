Tenim el sistema d'equacions:

1) a + b = 4
2) a² + b² = 6

Volem trobar a³ + b³.  Podem utilitzar la identitat:

(a + b)³ = a³ + 3a²b + 3ab² + b³ = a³ + b³ + 3ab(a + b)

Despejant a³ + b³:

a³ + b³ = (a + b)³ - 3ab(a + b)

Ja coneixem (a + b) = 4.  Necessitem trobar el valor de ab.  Ho podem fer utilitzant la identitat:

(a + b)² = a² + 2ab + b²

Substituint els valors coneguts:

4² = 6 + 2ab
16 = 6 + 2ab
2ab = 10
ab = 5

Ara podem substituir els valors de (a + b) i ab a l'equació de a³ + b³:

a³ + b³ = (4)³ - 3(5)(4) = 64 - 60 = 4
