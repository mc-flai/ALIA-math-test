Raonament:

Siguin els tres angles del triangle A, B i C.  Suposem que A és l'angle més petit, C és l'angle més gran, i B és l'angle mitjà.  Segons l'enunciat:

* C = 2A  (l'angle major és el doble del menor)
* B = (A + C) / 2 (l'altre angle és la mitjana dels dos anteriors)

Sabem que la suma dels angles d'un triangle és 180°. Per tant:

A + B + C = 180°

Substituïm B i C amb les expressions anteriors:

A + (A + C) / 2 + 2A = 180°

Substituïm C = 2A:

A + (A + 2A) / 2 + 2A = 180°

A + 3A / 2 + 2A = 180°

Multiplicant per 2 per eliminar la fracció:

2A + 3A + 4A = 360°

9A = 360°

A = 360° / 9 = 40°

Ara podem trobar C:

C = 2A = 2 * 40° = 80°

I finalment B:

B = (A + C) / 2 = (40° + 80°) / 2 = 60°

Per tant, l'angle més gran del triangle és 80°.
