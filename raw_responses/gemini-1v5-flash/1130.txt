Raonament: Siguin x₁ i x₂ les solucions de l'equació ax² + bx + c = 0, i siguin x₃ i x₄ les solucions de l'equació bx² + ax + c = 0.  Suposem que tenen una solució en comú, diguem x.  Llavors:

* ax² + bx + c = 0
* bx² + ax + c = 0

Restant les dues equacions, obtenim:

ax² + bx + c - (bx² + ax + c) = 0
ax² + bx + c - bx² - ax - c = 0
ax² - bx² + bx - ax = 0
x²(a - b) + x(b - a) = 0
x²(a - b) - x(a - b) = 0
x(a - b)(x - 1) = 0

Això implica que x = 0 o x = 1.

Si x = 0, substituint a qualsevol de les equacions originals, obtenim c = 0, però el problema diu que c no és zero. Per tant, x = 0 no és una solució vàlida.

Si x = 1, substituint a les equacions originals:

a(1)² + b(1) + c = 0  =>  a + b + c = 0
b(1)² + a(1) + c = 0  =>  a + b + c = 0

Ambdues equacions donen el mateix resultat: a + b + c = 0.  Aquesta condició es compleix sempre que hi hagi una solució comuna.  Les altres opcions no es compleixen necessàriament.

Resposta: E)
