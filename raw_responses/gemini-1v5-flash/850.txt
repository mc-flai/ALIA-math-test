Raonament:

Siguem A, B, C i D les quantitats de diners que porten Alba, Bernat, Cris i David respectivament.  Tenim les següents equacions:

* A + B = 5
* C + D = 6
* A + C = 7

Volem trobar B + D.  Sumem les tres equacions:

(A + B) + (C + D) + (A + C) = 5 + 6 + 7
2A + B + C + D = 18

Ara, restem l'equació (A + B = 5) de la suma anterior:

(2A + B + C + D) - (A + B) = 18 - 5
A + C + D = 13

Finalment, restem l'equació (A + C = 7) de l'equació anterior:

(A + C + D) - (A + C) = 13 - 7
D = 6

Ara que sabem que D = 6, podem substituir-ho a l'equació (C + D = 6):

C + 6 = 6
C = 0

I substituint C = 0 a l'equació (A + C = 7):

A + 0 = 7
A = 7

Finalment, substituint A = 7 a l'equació (A + B = 5):

7 + B = 5
B = -2

Això significa que Bernat deu diners.  Ara podem calcular B + D:

B + D = -2 + 6 = 4
