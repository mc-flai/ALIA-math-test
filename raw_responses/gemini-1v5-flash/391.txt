Raonament:  Perquè un triangle existeixi, la suma de les longituds de dos costats qualssevol ha de ser major que la longitud del tercer costat (desigualtat triangular).  El perímetre és 12.  Siguin a, b i c les longituds dels costats, amb a ≤ b ≤ c.  Aleshores a + b + c = 12.  A més, a + b > c.

Comencem a explorar les possibilitats, tenint en compte que a ≤ b ≤ c i a + b > c:

* **Si a = 1:**  1 + b + c = 12,  b + c = 11.  Però a + b > c implica 1 + b > c, o b > c - 1.  Com que b + c = 11,  b > 11 - b - 1,  2b > 10, b > 5.  Les possibilitats són (1, 6, 5) que compleix la desigualtat triangular.
* **Si a = 2:** 2 + b + c = 12, b + c = 10.  2 + b > c,  b > c - 2.  Com que b + c = 10, b > 10 - b - 2, 2b > 8, b > 4.  Les possibilitats són (2, 5, 5), (2, 4, 6) (aquesta no compleix la desigualtat triangular).
* **Si a = 3:** 3 + b + c = 12, b + c = 9.  3 + b > c, b > c - 3.  Com que b + c = 9, b > 9 - b - 3, 2b > 6, b > 3.  Les possibilitats són (3, 3, 6), (3, 4, 5).
* **Si a = 4:** 4 + b + c = 12, b + c = 8.  4 + b > c, b > c - 4.  Com que b + c = 8, b > 8 - b - 4, 2b > 4, b > 2.  Les possibilitats són (4, 4, 4).

Per tant, els triangles possibles són: (1, 5, 6), (2, 5, 5), (3, 3, 6), (3, 4, 5), (4, 4, 4).  Hi ha 5 triangles.  No obstant això, hem de considerar que l'ordre dels costats no importa.  Per tant, (1, 5, 6) és el mateix que (1, 6, 5), etc.  Així que tenim 5 triangles.  Hi ha un error en el raonament anterior.  Hem de considerar que a, b i c són nombres naturals.
