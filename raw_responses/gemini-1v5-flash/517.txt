Raonament:
Tenim el sistema d'equacions:
1) a * b = 6
2) b * c = 15
3) a * c = 10

Multiplicant les tres equacions:
(a * b) * (b * c) * (a * c) = 6 * 15 * 10
a² * b² * c² = 900
(a * b * c)² = 900
a * b * c = ±√900 = ±30

Com que a, b i c són nombres positius, a * b * c = 30.

Ara podem trobar a, b i c:
De 1) a = 6/b
Substituint a la 3): (6/b) * c = 10  => 6c = 10b => 3c = 5b
De 2) b = 15/c
Substituint a 3c = 5b: 3c = 5(15/c) => 3c² = 75 => c² = 25 => c = 5 (ja que c és positiu)

Substituint c = 5 a b = 15/c: b = 15/5 = 3
Substituint b = 3 a a = 6/b: a = 6/3 = 2

Per tant, a = 2, b = 3, c = 5.
La suma a + b + c = 2 + 3 + 5 = 10
