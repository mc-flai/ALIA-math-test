Raonament:

L'equació donada és ac + ad + bc + bd = 68.  Podem factoritzar aquesta equació de la següent manera:

a(c + d) + b(c + d) = 68

Observem que (c + d) és un factor comú.  Podem factoritzar-lo:

(a + b)(c + d) = 68

Sabem que c + d = 4.  Substituïm aquest valor a l'equació:

(a + b)(4) = 68

Dividim ambdues parts de l'equació per 4:

a + b = 17

Ara, volem trobar el valor de a + b + c + d.  Ja sabem que a + b = 17 i c + d = 4.  Per tant:

a + b + c + d = 17 + 4 = 21
