Raonament:

Tenim el sistema d'equacions:

1) w + x = 3
2) 1/w + 1/x = 1

De la segona equació, podem trobar un denominador comú:

(x + w) / (wx) = 1

Com que w + x = 3 (de l'equació 1), substituïm:

3 / (wx) = 1

Això implica que wx = 3.

Ara volem calcular x/w + w/x.  Podem trobar un denominador comú:

(x² + w²) / (wx)

Sabem que wx = 3.  També sabem que (w + x)² = w² + 2wx + x².  Per tant, w² + x² = (w + x)² - 2wx.

Substituint els valors que coneixem:

w² + x² = (3)² - 2(3) = 9 - 6 = 3

Per tant:

(x² + w²) / (wx) = 3 / 3 = 1
