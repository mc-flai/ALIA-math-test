Raonament:

Primer, factoritzem l'expressió dins del valor absolut:

n² – 2n – 3 = (n – 3)(n + 1)

Per tant, |n² – 2n – 3| = |(n – 3)(n + 1)|

Perquè |(n – 3)(n + 1)| sigui un nombre primer, un dels factors ha de ser ±1 i l'altre ha de ser un nombre primer (o el seu oposat).

Cas 1: n – 3 = ±1

* Si n – 3 = 1, llavors n = 4.  |(4 – 3)(4 + 1)| = |1 * 5| = 5, que és primer.
* Si n – 3 = -1, llavors n = 2.  |(2 – 3)(2 + 1)| = |-1 * 3| = 3, que és primer.

Cas 2: n + 1 = ±1

* Si n + 1 = 1, llavors n = 0.  |(0 – 3)(0 + 1)| = |-3 * 1| = 3, que és primer.
* Si n + 1 = -1, llavors n = -2.  |(-2 – 3)(-2 + 1)| = |-5 * -1| = 5, que és primer.

Per tant, hi ha 4 valors de n que compleixen la condició: n = -2, 0, 2, 4.
