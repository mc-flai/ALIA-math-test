Raonament:

Siguen *x* i *y* els dos nombres reals.  La suma és x + y, i la diferència és x - y (assumint x > y, si no, la diferència seria y - x, però el resultat serà el mateix).

Segons l'enunciat: x + y = 3(x - y)

Desenvolupant l'equació:
x + y = 3x - 3y
4y = 2x
2y = x

Volem calcular (x² + y²) / (xy).  Substituint x = 2y:

( (2y)² + y² ) / ( (2y)y ) = (4y² + y²) / (2y²) = 5y² / 2y² = 5/2

Per tant, el resultat de dividir la suma dels quadrats d'aquests dos nombres pel seu producte és 5/2.
