Raonament:

Un polígon regular de *n* costats té *n* vèrtexs.  El nombre de diagonals d'un polígon de *n* costats es calcula amb la fórmula:  D = n(n-3)/2

El problema ens diu que la suma del nombre de costats (n) i el nombre de diagonals (D) és 28.  Per tant, podem plantejar l'equació:

n + n(n-3)/2 = 28

Multiplicant per 2 per eliminar la fracció:

2n + n(n-3) = 56

2n + n² - 3n = 56

n² - n - 56 = 0

Aquesta és una equació quadràtica.  Podem resoldre-la factoritzant:

(n - 8)(n + 7) = 0

Les solucions són n = 8 i n = -7.  Com que el nombre de costats d'un polígon no pot ser negatiu, la solució vàlida és n = 8.

Per tant, el polígon té 8 costats i 8 vèrtexs.

Resposta: B)
