Raonament:

Comencem amb l'equació donada:

(3x + 4y) / (5x - 2y) = 4

Multiplicant ambdós costats per (5x - 2y), obtenim:

3x + 4y = 4(5x - 2y)
3x + 4y = 20x - 8y
12y = 17x
x = (12/17)y

Ara substituïm aquest valor de x a l'expressió que volem calcular:

(2x + 5y) / (4x + 3y) = (2(12/17)y + 5y) / (4(12/17)y + 3y)

Simplificant:

= (24y/17 + 5y) / (48y/17 + 3y)
= (24y + 85y)/17 / (48y + 51y)/17
= (109y)/17 / (99y)/17
= (109y)/17 * 17/(99y)
= 109y / 99y
= 109/99

Per tant, el valor de (2x + 5y) / (4x + 3y) és 109/99.
