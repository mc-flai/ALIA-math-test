Raonament:
Sabem que tan x = sin x / cos x i cot x = cos x / sin x. Per tant, l'equació donada es pot reescriure com:

sin x / cos x + cos x / sin x = π

Per sumar les fraccions, necessitem un denominador comú, que és sin x · cos x. Així, tenim:

(sin² x + cos² x) / (sin x · cos x) = π

Sabem que sin² x + cos² x = 1, per la identitat trigonomètrica fonamental. Per tant, l'equació es simplifica a:

1 / (sin x · cos x) = π

Ara, per trobar el valor de sin x · cos x, podem aïllar-lo:

sin x · cos x = 1 / π
