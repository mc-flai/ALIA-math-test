Raonament:
Sigui 'n' el nombre de costats (i també de vèrtexs) d'un polígon regular. El nombre de diagonals d'un polígon de 'n' costats es calcula amb la fórmula n(n-3)/2. Segons l'enunciat, la suma del nombre de costats i el nombre de diagonals és 28. Per tant, podem escriure l'equació:

n + n(n-3)/2 = 28

Multipliquem tota l'equació per 2 per eliminar el denominador:

2n + n(n-3) = 56
2n + n² - 3n = 56
n² - n = 56
n² - n - 56 = 0

Ara tenim una equació de segon grau que podem resoldre. Factoritzem l'equació:

(n - 8)(n + 7) = 0

Les solucions per a 'n' són n = 8 i n = -7. Com que el nombre de costats no pot ser negatiu, la solució vàlida és n = 8. Per tant, el polígon té 8 vèrtexs.

Resposta: B)
