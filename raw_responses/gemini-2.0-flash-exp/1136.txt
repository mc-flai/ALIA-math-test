Raonament:
La condició f(20 - x) = f(22 + x) ens indica que la funció f(x) té una simetria respecte a un punt. Per trobar aquest punt, podem igualar els arguments de la funció:
20 - x = 22 + x
-2 = 2x
x = -1
Això no ens dona el punt de simetria, sinó que ens indica que la funció té un eix de simetria. Per trobar l'eix de simetria, hem de trobar el punt mig entre 20-x i 22+x.
El punt mig és:
((20 - x) + (22 + x)) / 2 = (20 + 22) / 2 = 42 / 2 = 21
Per tant, la funció f(x) és simètrica respecte a la recta vertical x = 21.

Si l'equació f(x) = 0 té exactament dues solucions, diguem-les x1 i x2, i la funció és simètrica respecte a x = 21, llavors el punt mig entre x1 i x2 ha de ser 21. Per tant:
(x1 + x2) / 2 = 21
x1 + x2 = 2 * 21
x1 + x2 = 42

La suma de les dues solucions és 42. Cap de les opcions donades és 42.
