Raonament:
Siguin els cinc nombres de la llista a, b, c, d i e. Sabem que:
1. a = 10
2. e = 130
3. a + b + c = 100
4. b + c + d = 200
5. c + d + e = 300

Substituint el valor de a a l'equació 3, tenim:
10 + b + c = 100
b + c = 90

Substituint el valor de e a l'equació 5, tenim:
c + d + 130 = 300
c + d = 170

Ara tenim:
b + c = 90
c + d = 170
b + c + d = 200

Si restem l'equació b + c = 90 de l'equació b + c + d = 200, obtenim:
(b + c + d) - (b + c) = 200 - 90
d = 110

Ara que sabem que d = 110, podem trobar c:
c + d = 170
c + 110 = 170
c = 60

El nombre que es troba al centre de la llista és c, que és 60.

Resposta: B)
