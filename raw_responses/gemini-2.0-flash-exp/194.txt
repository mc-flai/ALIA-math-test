Raonament:
Sigui k^2 un nombre enter quadrat perfecte, on k és un enter. L'equació que hem de resoldre és:
n / (20 - n) = k^2
Multiplicant ambdós costats per (20 - n), obtenim:
n = k^2 * (20 - n)
n = 20k^2 - nk^2
n + nk^2 = 20k^2
n(1 + k^2) = 20k^2
n = 20k^2 / (1 + k^2)

Com que n ha de ser un enter, (1 + k^2) ha de ser un divisor de 20k^2.
També sabem que n ha de ser un enter positiu, per tant, 20 - n > 0, o sigui, n < 20.
Analitzem alguns valors de k:
- Si k = 0, n = 0. Però n/(20-n) = 0, que és un quadrat perfecte (0^2). Per tant, n=0 és una solució.
- Si k = 1, n = 20(1)^2 / (1 + 1^2) = 20 / 2 = 10. n/(20-n) = 10/10 = 1 = 1^2. Per tant, n=10 és una solució.
- Si k = 2, n = 20(2)^2 / (1 + 2^2) = 80 / 5 = 16. n/(20-n) = 16/4 = 4 = 2^2. Per tant, n=16 és una solució.
- Si k = 3, n = 20(3)^2 / (1 + 3^2) = 180 / 10 = 18. n/(20-n) = 18/2 = 9 = 3^2. Per tant, n=18 és una solució.
- Si k = 4, n = 20(4)^2 / (1 + 4^2) = 320 / 17. No és un enter.
- Si k = 5, n = 20(5)^2 / (1 + 5^2) = 500 / 26. No és un enter.
- Si k augmenta, el valor de n s'aproxima a 20, però mai l'assoleix.

Per tant, els valors enters de n que compleixen la condició són 0, 10, 16 i 18. Hi ha 4 solucions.
