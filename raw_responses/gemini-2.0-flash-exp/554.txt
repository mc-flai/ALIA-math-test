Raonament:
Tenim dues equacions:
1) w + x = 3
2) 1/w + 1/x = 1

De la segona equació, podem trobar un denominador comú i simplificar:
(x + w) / (wx) = 1
Com que w + x = 3, podem substituir-ho:
3 / (wx) = 1
Per tant, wx = 3

Ara volem trobar el valor de x/w + w/x. Podem trobar un denominador comú:
(x^2 + w^2) / (wx)

Sabem que (w + x)^2 = w^2 + 2wx + x^2. Per tant, w^2 + x^2 = (w + x)^2 - 2wx.
Substituint els valors que coneixem:
w^2 + x^2 = (3)^2 - 2(3) = 9 - 6 = 3

Ara podem substituir aquest valor a l'expressió que volem calcular:
(x^2 + w^2) / (wx) = 3 / 3 = 1
