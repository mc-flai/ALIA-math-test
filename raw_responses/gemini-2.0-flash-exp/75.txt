Raonament:
Perquè el punt $P(2, -1)$ pertanyi a la recta $ax + by = c$, les coordenades del punt han de satisfer l'equació de la recta. És a dir, si substituïm $x=2$ i $y=-1$ a l'equació, la igualtat ha de ser certa. Per tant, hem de comprovar cada opció per veure quina no compleix aquesta condició.

A) $a = -1, b = 1, c = -3$:
   $(-1)(2) + (1)(-1) = -2 - 1 = -3$. La igualtat es compleix.

B) $a = 1, b = 0, c = 2$:
   $(1)(2) + (0)(-1) = 2 + 0 = 2$. La igualtat es compleix.

C) $a = 0, b = 3, c = -3$:
   $(0)(2) + (3)(-1) = 0 - 3 = -3$. La igualtat es compleix.

D) $a = 10, b = 15, c = 5$:
   $(10)(2) + (15)(-1) = 20 - 15 = 5$. La igualtat es compleix.

E) $a = 1, b = 2, c = 1$:
   $(1)(2) + (2)(-1) = 2 - 2 = 0$. La igualtat $0=1$ no es compleix.

Per tant, l'opció E no és possible.

Resposta: E)
