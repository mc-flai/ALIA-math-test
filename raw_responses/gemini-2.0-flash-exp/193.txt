Raonament:
L'equació donada ac + ad + bc + bd es pot factoritzar per agrupació. Podem agrupar els termes que contenen 'a' i els termes que contenen 'b':
ac + ad + bc + bd = a(c + d) + b(c + d)
Ara, podem factoritzar (c + d) de l'expressió:
a(c + d) + b(c + d) = (a + b)(c + d)
Se'ns diu que ac + ad + bc + bd = 68 i c + d = 4. Per tant, podem substituir aquests valors a l'equació factoritzada:
(a + b)(c + d) = 68
(a + b)(4) = 68
Ara, podem resoldre per a + b:
a + b = 68 / 4
a + b = 17
Se'ns demana trobar el valor de a + b + c + d. Ja sabem que a + b = 17 i c + d = 4. Per tant, podem sumar aquests dos valors:
a + b + c + d = 17 + 4
a + b + c + d = 21
