Raonament:
L'equació donada és A · B = 10 + A. Podem reescriure aquesta equació per aïllar B:
B = (10 + A) / A
B = 10/A + A/A
B = 10/A + 1

Com que A i B són nombres d'un sol dígit, A pot prendre valors entre 1 i 9, i B també. Hem de trobar els valors d'A per als quals B és un nombre enter d'un sol dígit.

Si A = 1, B = 10/1 + 1 = 11 (no vàlid, ja que B ha de ser d'un sol dígit)
Si A = 2, B = 10/2 + 1 = 5 + 1 = 6 (vàlid)
Si A = 3, B = 10/3 + 1 = 3.33 + 1 = 4.33 (no vàlid, B no és enter)
Si A = 4, B = 10/4 + 1 = 2.5 + 1 = 3.5 (no vàlid, B no és enter)
Si A = 5, B = 10/5 + 1 = 2 + 1 = 3 (vàlid)
Si A = 6, B = 10/6 + 1 = 1.66 + 1 = 2.66 (no vàlid, B no és enter)
Si A = 7, B = 10/7 + 1 = 1.42 + 1 = 2.42 (no vàlid, B no és enter)
Si A = 8, B = 10/8 + 1 = 1.25 + 1 = 2.25 (no vàlid, B no és enter)
Si A = 9, B = 10/9 + 1 = 1.11 + 1 = 2.11 (no vàlid, B no és enter)

Els valors vàlids per a A són 2 i 5. Quan A = 2, B = 6. Quan A = 5, B = 3.
Per tant, hi ha dos valors possibles per a B (6 i 3).
