Raonament:
1. **Visualització:** Imaginem els 6 punts en una recta, A-B-C-D-E-F, d'esquerra a dreta.
2. **Informació donada:**
   - AD = CF
   - BD = DF
3. **Anàlisi de les igualtats:**
   - AD = AB + BC + CD
   - CF = CD + DE + EF
   - BD = BC + CD
   - DF = DE + EF
4. **Substitució:**
   - Com que AD = CF, tenim AB + BC + CD = CD + DE + EF. Si restem CD a ambdós costats, obtenim AB + BC = DE + EF.
   - Com que BD = DF, tenim BC + CD = DE + EF.
5. **Comparació:**
   - Ara tenim dues equacions:
     - AB + BC = DE + EF
     - BC + CD = DE + EF
   - Si igualem les dues parts dretes de les equacions, obtenim AB + BC = BC + CD. Si restem BC a ambdós costats, obtenim AB = CD.
6. **Anàlisi de les opcions:**
   - A) AB = BC: No podem assegurar-ho.
   - B) BC = DE: No podem assegurar-ho.
   - C) BD = EF: No podem assegurar-ho.
   - D) AB = CD: Hem demostrat que aquesta igualtat és certa.
   - E) CD = EF: No podem assegurar-ho.

Resposta: D)
