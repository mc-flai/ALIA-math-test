Raonament:
La calculadora respecta la jerarquia d'operacions, per tant, primer fa la divisió i després la suma. Així, les equacions que Sara introdueix són:
1) a + (b/c) = 11
2) b + (a/c) = 14

Multipliquem ambdues equacions per c per eliminar les divisions:
1) ac + b = 11c
2) bc + a = 14c

Sumem les dues equacions:
ac + b + bc + a = 11c + 14c
ac + bc + a + b = 25c
c(a+b) + (a+b) = 25c
(a+b)(c+1) = 25c

Volem trobar el valor de (a+b)/c. Anomenem x = (a+b)/c. Llavors, a+b = xc. Substituïm a l'equació anterior:
xc(c+1) = 25c
Dividim per c (sabem que c és un enter positiu, per tant, no és 0):
x(c+1) = 25
x = 25/(c+1)

Com que a, b i c són enters positius, x també ha de ser un nombre racional positiu. Perquè x sigui un enter, c+1 ha de ser un divisor de 25. Els divisors de 25 són 1, 5 i 25.
Si c+1 = 1, llavors c=0, però c ha de ser positiu, així que descartem aquesta opció.
Si c+1 = 5, llavors c=4 i x = 25/5 = 5.
Si c+1 = 25, llavors c=24 i x = 25/25 = 1.

Ara hem de comprovar si amb x=5 i x=1 podem trobar valors enters positius per a, b i c que compleixin les equacions originals.
Si x=5, llavors (a+b)/c = 5, per tant a+b = 5c. Si c=4, a+b=20.
