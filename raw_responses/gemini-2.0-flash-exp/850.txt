Raonament:
Anomenem A, B, C i D la quantitat de diners que porten Alba, Bernat, Cris i David respectivament.
Tenim les següents equacions:
1) A + B = 5
2) C + D = 6
3) A + C = 7

Volem trobar B + D.
Si sumem les equacions 1 i 2, obtenim:
A + B + C + D = 5 + 6 = 11

Ara, si restem l'equació 3 de la suma anterior, obtenim:
(A + B + C + D) - (A + C) = 11 - 7
A + B + C + D - A - C = 4
B + D = 4

Per tant, entre Bernat i David porten 4 €.

Resposta: E)
