Raonament:
1. Partim de la igualtat donada: a² + b² = 6ab.
2. Volem trobar el valor de (a+b)/(a-b). Per fer-ho, intentarem relacionar la igualtat donada amb l'expressió que volem calcular.
3. Dividim tota l'equació a² + b² = 6ab per ab: (a²/ab) + (b²/ab) = 6ab/ab, que simplifica a a/b + b/a = 6.
4. Fem un canvi de variable: x = a/b. Llavors, l'equació anterior es converteix en x + 1/x = 6.
5. Multipliquem tota l'equació per x: x² + 1 = 6x, que es pot reescriure com x² - 6x + 1 = 0.
6. Resolem aquesta equació quadràtica per x utilitzant la fórmula quadràtica: x = (-(-6) ± √((-6)² - 4*1*1)) / (2*1) = (6 ± √(36 - 4)) / 2 = (6 ± √32) / 2 = (6 ± 4√2) / 2 = 3 ± 2√2.
7. Com que 0 < b < a, tenim que a/b > 1, per tant, x > 1. Dels dos valors de x, 3 + 2√2 i 3 - 2√2, només 3 + 2√2 és major que 1. Per tant, x = a/b = 3 + 2√2.
8. Ara, considerem l'expressió que volem calcular: (a+b)/(a-b). Dividim tant el numerador com el denominador per b: (a/b + 1) / (a/b - 1).
9. Substituïm a/b per x: (x + 1) / (x - 1).
10. Substituïm x per 3 + 2√2: (3 + 2√2 + 1) / (3 + 2√2 - 1) = (4 + 2√2) / (2 + 2√2).
11. Simplifiquem la fracció dividint tant el numerador com el denominador per 2: (2 + √2) / (1 + √2).
12. Racionalitzem el denominador multiplicant tant el numerador com el denominador per (1 - √2): ((2 + √2)(1 - √2)) / ((1 + √2)(1 - √2)) = (2 - 2√2 + √2 - 2) / (1 - 2) = -√2 / -1 = √2.
