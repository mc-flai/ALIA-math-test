Raonament:
Volem trobar l'interval de valors de 'a' per als quals existeix algun 'b' que satisfà les desigualtats |a + b| ≤ 1 i |a - 3b| ≤ 2.

La primera desigualtat implica que -1 ≤ a + b ≤ 1, que podem reescriure com -1 - a ≤ b ≤ 1 - a.
La segona desigualtat implica que -2 ≤ a - 3b ≤ 2, que podem reescriure com a - 2 ≤ 3b ≤ a + 2, i dividint per 3, obtenim (a - 2)/3 ≤ b ≤ (a + 2)/3.

Perquè existeixi un valor de 'b' que satisfaci ambdues desigualtats, els intervals per a 'b' han de solapar-se. Això significa que el límit inferior del primer interval ha de ser menor o igual que el límit superior del segon interval, i el límit inferior del segon interval ha de ser menor o igual que el límit superior del primer interval. Per tant, hem de tenir:

1) -1 - a ≤ (a + 2)/3
2) (a - 2)/3 ≤ 1 - a

Resolem la primera desigualtat:
-3 - 3a ≤ a + 2
-5 ≤ 4a
a ≥ -5/4

Resolem la segona desigualtat:
a - 2 ≤ 3 - 3a
4a ≤ 5
a ≤ 5/4

Combinant les dues desigualtats, obtenim que -5/4 ≤ a ≤ 5/4.

Resposta: A)
