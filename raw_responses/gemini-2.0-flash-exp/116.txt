Raonament:
L'expressió donada és una suma alternada de quadrats. Podem agrupar els termes de dos en dos i utilitzar la identitat algebraica a² - b² = (a+b)(a-b).

L'expressió es pot reescriure com:
(2015² - 2014²) + (2013² - 2012²) + ... + (3² - 2²) + 1²

Aplicant la identitat a² - b² = (a+b)(a-b) a cada parella de termes:
(2015+2014)(2015-2014) + (2013+2012)(2013-2012) + ... + (3+2)(3-2) + 1²
= (2015+2014)(1) + (2013+2012)(1) + ... + (3+2)(1) + 1
= 2015 + 2014 + 2013 + 2012 + ... + 3 + 2 + 1

Aquesta és la suma dels primers 2015 nombres naturals. La suma dels primers n nombres naturals és n(n+1)/2. En aquest cas, n = 2015.
Suma = 2015(2015+1)/2 = 2015(2016)/2 = 2015 * 1008 = 2031120

Per tant, el valor de l'expressió és 2031120.
