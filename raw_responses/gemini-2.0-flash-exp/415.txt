Raonament:
Restem les dues equacions:
(2017 + x) - (2017 + y) = y² - x²
x - y = y² - x²
x - y = (y - x)(y + x)
x - y + (x - y)(x + y) = 0
(x - y)(1 + x + y) = 0

Com que x i y són diferents, x - y ≠ 0. Per tant, 1 + x + y = 0, o bé x + y = -1.

Ara sumem les dues equacions originals:
(2017 + x) + (2017 + y) = y² + x²
4034 + x + y = x² + y²
4034 - 1 = x² + y²
4033 = x² + y²

(-1)² = x² + 2xy + y²
1 = x² + y² + 2xy
1 = 4033 + 2xy
