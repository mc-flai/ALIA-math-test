Raonament:
Tenim les següents igualtats:
1) a = b + 1
2) a = c + 2
3) a = d + 3
4) a = a + b + c + d + 4

De les igualtats 1, 2 i 3, podem expressar b, c i d en termes de a:
b = a - 1
c = a - 2
d = a - 3

Substituïm aquestes expressions a la igualtat 4:
a = a + (a - 1) + (a - 2) + (a - 3) + 4
a = a + a - 1 + a - 2 + a - 3 + 4
a = 4a - 2
Restem a a ambdós costats:
0 = 3a - 2
Sumem 2 a ambdós costats:
2 = 3a
Dividim per 3:
a = 2/3

Ara podem trobar b, c i d:
b = a - 1 = 2/3 - 1 = 2/3 - 3/3 = -1/3
c = a - 2 = 2/3 - 2 = 2/3 - 6/3 = -4/3
d = a - 3 = 2/3 - 3 = 2/3 - 9/3 = -7/3

Finalment, calculem a + b + c + d:
a + b + c + d = 2/3 + (-1/3) + (-4/3) + (-7/3) = (2 - 1 - 4 - 7)/3 = -10/3
