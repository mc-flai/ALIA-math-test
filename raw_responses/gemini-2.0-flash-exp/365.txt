Raonament:
Sigui `l` la longitud del rectangle i `a` l'amplada del rectangle. El perímetre d'un rectangle és 2l + 2a.
Si sumem tres costats, tenim dues opcions:
1) l + l + a = 2l + a = 20
2) l + a + a = l + 2a = 20
3) l + l + a = 2l + a = 22
4) l + a + a = l + 2a = 22

Si tenim 2l + a = 20 i l + 2a = 22, podem resoldre el sistema d'equacions. Multipliquem la segona equació per 2:
2l + 4a = 44
Restem la primera equació de la nova equació:
(2l + 4a) - (2l + a) = 44 - 20
3a = 24
a = 8
Substituïm a en la primera equació:
2l + 8 = 20
2l = 12
l = 6
El perímetre seria 2l + 2a = 2(6) + 2(8) = 12 + 16 = 28

Si tenim 2l + a = 22 i l + 2a = 20, podem resoldre el sistema d'equacions. Multipliquem la segona equació per 2:
2l + 4a = 40
Restem la primera equació de la nova equació:
(2l + 4a) - (2l + a) = 40 - 22
3a = 18
a = 6
Substituïm a en la primera equació:
2l + 6 = 22
2l = 16
l = 8
El perímetre seria 2l + 2a = 2(8) + 2(6) = 16 + 12 = 28

En ambdós casos, el perímetre és 28.
