La suma donada és una suma de termes de la forma k/(n-k+1), on k va des de 1 fins a n. Podem reescriure la suma com:
S = 1/n + 2/(n-1) + 3/(n-2) + ... + (n-1)/2 + n/1

Si n=1, la suma seria 1/1 = 1.
Si n=2, la suma seria 1/2 + 2/1 = 2.5
Si n=3, la suma seria 1/3 + 2/2 + 3/1 = 1/3 + 1 + 3 = 4 + 1/3 = 13/3 ≈ 4.33
Si n=4, la suma seria 1/4 + 2/3 + 3/2 + 4/1 = 0.25 + 0.666... + 1.5 + 4 = 6.416...
Si n=5, la suma seria 1/5 + 2/4 + 3/3 + 4/2 + 5/1 = 0.2 + 0.5 + 1 + 2 + 5 = 8.7
Si n=6, la suma seria 1/6 + 2/5 + 3/4 + 4/3 + 5/2 + 6/1 = 0.166... + 0.4 + 0.75 + 1.333... + 2.5 + 6 = 11.15
Si n=7, la suma seria 1/7 + 2/6 + 3/5 + 4/4 + 5/3 + 6/2 + 7/1 = 0.142... + 0.333... + 0.6 + 1 + 1.666... + 3 + 7 = 13.742...

La suma donada és igual a 11.15. Per tant, el valor de n que fa que la suma sigui aproximadament 11.15 és n=6.
