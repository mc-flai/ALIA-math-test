Raonament:
Hem de trobar tots els nombres de tres xifres (abc) on a, b i c són dígits entre 0 i 9, i a més a + b + c = 3. Com que és un nombre de tres xifres, 'a' no pot ser 0. Per tant, 'a' pot ser 1, 2 o 3. Analitzem cada cas:

*   Si a = 1, llavors b + c = 2. Les possibles combinacions per (b, c) són (0, 2), (1, 1) i (2, 0). Això ens dona els nombres 102, 111 i 120.
*   Si a = 2, llavors b + c = 1. Les possibles combinacions per (b, c) són (0, 1) i (1, 0). Això ens dona els nombres 201 i 210.
*   Si a = 3, llavors b + c = 0. L'única combinació possible per (b, c) és (0, 0). Això ens dona el nombre 300.

En total, tenim 3 + 2 + 1 = 6 nombres que compleixen la condició.

Resposta: D)
