Raonament:
Com que *a* i *b* són les solucions de l'equació x² + x - 7 = 0, sabem que:
1. a² + a - 7 = 0, per tant, a² = 7 - a
2. b² + b - 7 = 0, per tant, b² = 7 - b

Ara, volem trobar el valor de 3a² + 4b² + 2a + 3b + 1. Substituïm a² i b² amb les expressions que hem trobat:
3(7 - a) + 4(7 - b) + 2a + 3b + 1
= 21 - 3a + 28 - 4b + 2a + 3b + 1
= 21 + 28 + 1 - 3a + 2a - 4b + 3b
= 50 - a - b

Per les propietats de les equacions quadràtiques, sabem que la suma de les arrels (a + b) és igual a -b/a, on a i b són els coeficients de l'equació quadràtica ax² + bx + c = 0. En aquest cas, a = 1, b = 1 i c = -7. Per tant, a + b = -1/1 = -1.

Ara podem substituir a + b = -1 a l'expressió que hem trobat:
50 - (a + b) = 50 - (-1) = 50 + 1 = 51
