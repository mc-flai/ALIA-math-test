Raonament:
Sigui el nombre de cinc xifres representat com ABCDE, on A, B, C, D i E són dígits entre 0 i 9. El nombre de tres xifres format per les tres primeres xifres és 100A + 10B + C, i el nombre de dues xifres format per les dues últimes xifres és 10D + E. Segons l'enunciat, tenim la relació:

100A + 10B + C = 4(10D + E)

A més, sabem que el nombre de cinc xifres ha de ser més gran o igual que 10000 i més petit que 26320. Això implica que A pot ser 1 o 2.

Si A = 1, llavors 100 + 10B + C = 4(10D + E). El nombre de cinc xifres és 1BCDE. Com que el nombre ha de ser menor que 26320, el valor màxim de B és 9.
Si A = 2, llavors 200 + 10B + C = 4(10D + E). El nombre de cinc xifres és 2BCDE. Com que el nombre ha de ser menor que 26320, el valor màxim de B és 6.

Analitzem els casos:

Cas A=1:
100 + 10B + C = 4(10D + E)
El valor màxim de 10D+E és 99, per tant el valor màxim de 4(10D+E) és 396.
El valor mínim de 100+10B+C és 100 (quan B=0 i C=0) i el màxim és 199 (quan B=9 i C=9).
Per tant, 100 <= 4(10D+E) <= 199. Això implica que 25 <= 10D+E <= 49.
Ara hem de trobar els valors de B i C que compleixen la condició per cada valor de 10D+E entre 25 i 49.
- Si 10D+E = 25, 4(25) = 100. 100+10B+C = 100, B=0, C=0. Nombre: 10025
- Si 10D+E = 26, 4(26) = 104. 100+10B+C = 104, B=0, C=4. Nombre: 10426
- Si 10D+E = 27, 4(27) = 108. 100+10B+C = 108, B=0, C=8. Nombre: 10827
...
- Si 10D+E = 49, 4(49) = 196. 100+10B+C = 196, B=9, C=6. Nombre: 19649
Per cada valor de 10D+E entre 25 i 49, hi ha una única solució per B i C. Hi ha 49-25+1 = 25 solucions.
