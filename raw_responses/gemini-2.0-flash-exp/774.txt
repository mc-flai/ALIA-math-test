Raonament:
Primer, factoritzem l'expressió dins del valor absolut:
|n² - 2n - 3| = |(n - 3)(n + 1)|

Perquè aquesta expressió sigui un nombre primer, un dels factors dins del valor absolut ha de ser igual a ±1 i l'altre factor ha de ser igual a ±p, on p és un nombre primer.

Cas 1: n - 3 = 1
Si n - 3 = 1, llavors n = 4. En aquest cas, n + 1 = 5, i |(1)(5)| = 5, que és un nombre primer.

Cas 2: n - 3 = -1
Si n - 3 = -1, llavors n = 2. En aquest cas, n + 1 = 3, i |(-1)(3)| = 3, que és un nombre primer.

Cas 3: n + 1 = 1
Si n + 1 = 1, llavors n = 0. En aquest cas, n - 3 = -3, i |(-3)(1)| = 3, que és un nombre primer.

Cas 4: n + 1 = -1
Si n + 1 = -1, llavors n = -2. En aquest cas, n - 3 = -5, i |(-5)(-1)| = 5, que és un nombre primer.

Ara, hem de comprovar si hi ha altres casos on |(n-3)(n+1)| és un nombre primer. Si |n-3| > 1 i |n+1| > 1, llavors el producte serà un nombre compost, no un nombre primer. Per tant, els casos que hem trobat són els únics que compleixen la condició.

Hem trobat quatre valors de n que fan que |n² - 2n - 3| sigui un nombre primer: n = 4, n = 2, n = 0 i n = -2.
