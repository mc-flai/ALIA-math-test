Una recta que passa per l'origen té la forma y = mx, on m és el pendent. Per trobar els punts d'intersecció entre aquesta recta i la paràbola y = x² - 2, igualem les dues equacions:
mx = x² - 2
x² - mx - 2 = 0

Aquesta és una equació quadràtica en x. Les seves solucions, x1 i x2, representen les coordenades x dels punts d'intersecció de la recta amb la paràbola. El producte de les arrels d'una equació quadràtica ax² + bx + c = 0 és c/a. En aquest cas, el producte de les arrels és (-2)/1 = -2.

Com que tenim quatre rectes diferents, cada una d'elles donarà lloc a dues solucions per a x. Siguin x1, x2 les solucions per a la primera recta, x3, x4 per a la segona, x5, x6 per a la tercera i x7, x8 per a la quarta. El producte de les arrels per a cada recta és -2. Per tant, el producte de les vuit coordenades x serà el producte dels productes de cada parella:
(x1 * x2) * (x3 * x4) * (x5 * x6) * (x7 * x8) = (-2) * (-2) * (-2) * (-2) = 16
