Raonament:
L'equació donada és a²ˣ – b²ˣ – 2(ab)ˣ = 0.
Podem reescriure l'equació com (aˣ)² - (bˣ)² - 2(aˣ)(bˣ) = 0.
Aquesta equació es pot reescriure com (aˣ)² - 2(aˣ)(bˣ) + (bˣ)² - 2(bˣ)² = 0.
Això es pot simplificar a (aˣ - bˣ)² = 2(bˣ)².
Prenent l'arrel quadrada de cada costat, obtenim aˣ - bˣ = ±√2 bˣ.
Això ens dona dues equacions:
1) aˣ - bˣ = √2 bˣ, que implica aˣ = (1 + √2)bˣ, o (a/b)ˣ = 1 + √2.
2) aˣ - bˣ = -√2 bˣ, que implica aˣ = (1 - √2)bˣ, o (a/b)ˣ = 1 - √2.
Com que a > 1 i b > 1, a/b > 0. Per tant, (a/b)ˣ > 0.
Com que 1 - √2 < 0, la segona equació no té solució real per a x.
Per tant, considerem només la primera equació: (a/b)ˣ = 1 + √2.
Prenent el logaritme natural de cada costat, obtenim x ln(a/b) = ln(1 + √2).
Aïllant x, obtenim x = ln(1 + √2) / ln(a/b).
Aquesta resposta no coincideix amb cap de les opcions donades.
Però, si multipliquem el numerador i el denominador per (√2 - 1), obtenim:
x = ln(1 + √2) / ln(a/b) = ln(1 + √2) * (ln(√2 - 1) / ln(√2 - 1)) / ln(a/b)
x = ln((1 + √2)(√2 - 1)) / (ln(a/b) * ln(√2 - 1))
x = ln(2 - 1) / (ln(a/b) * ln(√2 - 1))
x = ln(1) / (ln(a/b) * ln(√2 - 1))
x = 0 / (ln(a/b) * ln(√2 - 1))
Això no és correcte.
Tornem a l'equació (a/b)ˣ = 1 + √2.
Prenent el logaritme natural de cada costat, obtenim x ln(a/b) = ln(1 + √2).
Aïllant x, obtenim x = ln(1 + √2) / ln(a/b).
Aquesta resposta coincideix amb l'opció D.
