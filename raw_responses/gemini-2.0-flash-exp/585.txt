Raonament:
L'equació donada és (x² - 4x + 5)^(x²+x-30) = 1. Perquè una expressió de la forma a^b = 1, hi ha tres casos possibles:

1. **La base és 1:** Si x² - 4x + 5 = 1, llavors l'equació es compleix independentment del valor de l'exponent. Resolem x² - 4x + 5 = 1, que és equivalent a x² - 4x + 4 = 0. Factoritzant, obtenim (x - 2)² = 0, per tant, x = 2. Aquesta és una solució real.

2. **L'exponent és 0 i la base és diferent de 0:** Si x² + x - 30 = 0, llavors l'equació es compleix sempre que la base no sigui 0. Resolem x² + x - 30 = 0. Factoritzant, obtenim (x + 6)(x - 5) = 0, per tant, x = -6 o x = 5.
    - Si x = -6, la base és (-6)² - 4(-6) + 5 = 36 + 24 + 5 = 65, que és diferent de 0. Per tant, x = -6 és una solució.
    - Si x = 5, la base és (5)² - 4(5) + 5 = 25 - 20 + 5 = 10, que és diferent de 0. Per tant, x = 5 és una solució.

3. **La base és -1 i l'exponent és un nombre parell:** Si x² - 4x + 5 = -1, llavors x² - 4x + 6 = 0. El discriminant d'aquesta equació és (-4)² - 4(1)(6) = 16 - 24 = -8, que és negatiu. Per tant, no hi ha solucions reals per a aquesta equació.

Per tant, les solucions reals distintes són x = 2, x = -6 i x = 5. Hi ha 3 solucions reals distintes.

Resposta: B)
