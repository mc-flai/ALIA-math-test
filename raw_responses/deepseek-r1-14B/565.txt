**Raonament:**

1. **Trovem les solucions de l'equació x² + x − 7 = 0:**
   
   L'equació general d'un polinomi quadràtic és de la forma ax² + bx + c = 0. En aquest cas, els coeficients són:
   - a = 1
   - b = 1
   - c = -7

2. **Aplicam la fórmula de les raíces:**
   
   Les solucions s'obtenen mitjançant:
   \[
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   \]
   
   Substituïm els valors:
   \[
   x = \frac{-1 \pm \sqrt{(1)^2 - 4(1)(-7)}}{2(1)} = \frac{-1 \pm \sqrt{1 + 28}}{2} = \frac{-1 \pm \sqrt{29}}{2}
   \]
   
   Així, les solucions són:
   - \( a = \frac{-1 + \sqrt{29}}{2} \)
   - \( b = \frac{-1 - \sqrt{29}}{2} \)

3. **Calculam 3a² + 4b² + 2a + 3b + 1:**

   Per simplificar, utilitzarem les propietats dels polinomis i les sumes/productes de les raíces.

   - Suma de les raíces (\( a + b \)):
     \[
     a + b = \frac{-1 + \sqrt{29}}{2} + \frac{-1 - \sqrt{29}}{2} = \frac{-2}{2} = -1
     \]
     
   - Producte de les raíces (\( ab \)):
     \[
     ab = \left(\frac{-1 + \sqrt{29}}{2}\right)\left(\frac{-1 - \sqrt{29}}{2}\right) = \frac{(-1)^2 - (\sqrt{29})^2}{4} = \frac{1 - 29}{4} = \frac{-28}{4} = -7
     \]
     
   - Expressió simplificada:
     \[
     3a² + 4b² + 2a + 3b + 1 = (3a² + 4b²) + (2a + 3b) + 1
     \]

     \[
     a^2 + b^2 = (-1)^2 - 2(-7) = 1 + 14 = 15
     \]
     
     Per tant:
     \[
     3a² + 4b² = 3(a^2 + b^2) + b^2 = 3(15) + b^2
     \]
