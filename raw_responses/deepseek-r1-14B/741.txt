To solve this problem, we need to count the number of times the substring "111" appears in the concatenated string formed by sequentially appending numbers from 1 to N. The solution involves checking both internal and cross occurrences of the substring.

### Approach
1. **Internal Occurrences**: For each number converted to a string, check how many times "111" appears within that string itself.
2. **Cross Occurrences**: When appending a new string (converted from a number), check if the last two characters of the current concatenated string and the first character of the new string form "111".

The solution processes each number sequentially, updating the count for both internal and cross occurrences efficiently.

### Solution Code
```python
def count_triples(n):
    count = 0
    prev = ""
    for i in range(1, n + 1):
        current_str = str(i)
        # Check for cross triplet between prev and current_str
        if len(prev) >= 2:
            last_two_prev = prev[-2:]
            if last_two_prev == '11' and current_str[0] == '1':
                count += 1
        # Check internal triplets in current_str
        for j in range(len(current_str) - 2):
            if current_str[j:j+3] == '111':
                count += 1
        prev += current_str
    return count

# Example usage:
n = int(input("Enter a number N: "))
print(count_triples(n))
```

### Explanation
- **Initialization**: Start with `count` set to 0 and an empty string `prev`.
- **Loop through each number**: Convert the number to a string (`current_str`).
- **Cross Check**: If the length of `prev` is at least 2, check if the last two characters of `prev` are "11" and the first character of `current_str` is "1". If true, increment the count.
- **Internal Check**: For each position in `current_str`, check if a substring starting at that position is "111".
- **Update `prev`**: Append `current_str` to `prev`.

This approach ensures that both internal and cross occurrences of "111" are efficiently counted, providing the correct total for any given N.
