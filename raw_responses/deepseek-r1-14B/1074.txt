1. **Primer pot**: El nombre de caramels aquí és igual al nombre de pots que tenen un caramel.

3. **Tercer pot**: El nombre de caramels aquí és igual al nombre de pots que tenen tres caramels.
4. **Quart pot**: El nombre de caramels aquí és igual al nombre de pots que no tenen cap caramel.

Definim variables per a cada pot:
- \( x_1 \): Caramels en el primer pot.
- \( x_2 \): Caramels en el segon pot.
- \( x_3 \): Caramels en el tercer pot.
- \( x_4 \): Caramels en el quart pot.

Condicions:
1. \( x_1 = \) Número de pots amb 1 caramel.
2. \( x_2 = \) Número de pots amb 2 caramels.
3. \( x_3 = \) Número de pots amb 3 caramels.
4. \( x_4 = \) Número de pots sense caramels.

Sabiendo que hi ha 4 pots, sumem les cantitats:
- Pots sense caramels: \( a \)
- Pots amb 1 caramel: \( b \)
- Pots amb 2 caramels: \( c \)
- Pots amb 3 caramels: \( d \)

Per tant:
\( a + b + c + d = 4 \)

Igualant als pots i caramels:
- \( x_1 = b \) (pots amb 1 caramel)
- \( x_2 = c \) (pots amb 2 caramels)
- \( x_3 = d \) (pots amb 3 caramels)
- \( x_4 = a \) (pots sense caramels)

Sumant tots els caramels:
Total = \( x_1 + x_2 + x_3 + x_4 = b + c + d + a \)

Substituïnt \( a = 4 - b - c - d \):
Total = \( (b) + (c) + (d) + (4 - b - c - d) = 4 \)
