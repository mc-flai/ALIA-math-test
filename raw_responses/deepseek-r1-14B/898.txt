Raonament:  
El problema consiste en calcular las diferentes maneras en que Pere puede subir una escalera de 8 peldaños, donde puede subir dos peldaños a la vez o uno solo. Este tipo de problemas se resuelve utilizando una secuencia similar a la de Fibonacci, ya que cada paso depende de los pasos anteriores.

La fórmula para calcular el número de maneras es:  
F(n) = F(n-1) + F(n-2),  
donde F(1) = 1 y F(2) = 2.

Calculando los valores necesarios:
- F(3) = F(2) + F(1) = 2 + 1 = 3
- F(4) = F(3) + F(2) = 3 + 2 = 5
- F(5) = F(4) + F(3) = 5 + 3 = 8
- F(6) = F(5) + F(4) = 8 + 5 = 13
- F(7) = F(6) + F(5) = 13 + 8 = 21
- F(8) = F(7) + F(6) = 21 + 13 = 34

Por lo tanto, el número de maneras diferentes en que Pere puede subir la escalera es **34**.
