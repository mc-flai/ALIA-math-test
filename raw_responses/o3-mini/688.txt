Raonament: Sigui x₁, x₂, …, x₁₈ el nombre de passatgers en cada vagó. Se’ns diu que qualsevol bloc de cinc vagons adjacents té 199 passatgers, per tant, per a tota posició v: xᵥ + xᵥ₊₁ + xᵥ₊₂ + xᵥ₊₃ + xᵥ₊₄ = 199 (per v = 1 fins a 14). Restar dues d’aquestes sumes consecutives ens dóna x₍ᵥ₊₅₎ - xᵥ = 0, per tant, x₍ᵥ₊₅₎ = xᵥ. Així, els passatgers es distribueixen de manera periòdica amb període 5.

Definim:
  a = x₁, b = x₂, c = x₃, d = x₄, e = x₅.

Llavors els vagons es repeteixen:
  x₁ = a, x₂ = b, x₃ = c, x₄ = d, x₅ = e,
  x₆ = a, x₇ = b, x₈ = c, x₉ = d, x₁₀ = e,
  x₁₁ = a, x₁₂ = b, x₁₃ = c, x₁₄ = d, x₁₅ = e,
  x₁₆ = a, x₁₇ = b, x₁₈ = c.

L’equació donada per cada bloc de cinc és:
  a + b + c + d + e = 199.

El total de passatgers en els 18 vagons és:
  4a + 4b + 4c + 3d + 3e = 700,
ja que a, b i c apareixen 4 vegades i d i e 3 vegades.

Multiplicant l’equació del grup per 3:
  3a + 3b + 3c + 3d + 3e = 597.

Restem aquesta equació de la suma total:
  (4a + 4b + 4c + 3d + 3e) – (3a + 3b + 3c + 3d + 3e) = 700 – 597,
  a + b + c = 103.

D’altra banda, de l’equació a + b + c + d + e = 199, tenim que:
  d + e = 199 – 103 = 96.

Els dos vagons del mig del tren (en un tren de 18, els vagons 9 i 10 són els centrals) corresponen a d i e (ja que x₉ = d i x₁₀ = e). Per tant, el total de passatgers als dos vagons del mig és 96.

Resposta: D)
