Raonament: Sigui X la capacitat de cada barril en litres. Inicialment el primer barril està buit i el segon ple, per tant té X litres. Després de traslladar 50 litres, el primer conté 50 litres i el segon queda amb X - 50 litres. Segons l'enunciat, el primer conté un 25% més d'aigua que el segon, és a dir: 50 = 1,25 · (X - 50). Resolem l'equació: X - 50 = 50 / 1,25 = 40, per tant X = 90 litres.
