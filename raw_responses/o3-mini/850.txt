Raonament: Sigui A, B, C, D els diners que porten Alba, Bernat, Cris i David respectivament. Tenim:
  1) A + B = 5.
  2) C + D = 6.
  3) A + C = 7.
Utilitzem la tercera equació per expressar C: C = 7 − A.
Substituïm C a la segona equació:
  (7 − A) + D = 6 ⟹ D = A − 1.
Ara, la quantitat que porten Bernat i David és:
  B + D = (5 − A) + (A − 1) = 4.
Per tant, l’opció correcta és la resposta que indica 4.
