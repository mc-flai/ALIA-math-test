Raonament: Denotem amb X₁, X₂, X₃ i X₄ el nombre de caramels en els pots 1, 2, 3 i 4, respectivament. Així tenim les següents condicions:
1) X₁ és igual al nombre de pots que tenen exactament 1 caramel.
2) X₂ és igual al nombre de pots que tenen exactament 2 caramels.
3) X₃ és igual al nombre de pots que tenen exactament 3 caramels.
4) X₄ és igual al nombre de pots que tenen 0 caramels.

Proposem la solució:
• Posem X₁ = 2, X₂ = 1, X₃ = 0 i X₄ = 1.
Comprovem:
– Nombre de pots amb 1 caramel: els pots 2 i 4 són 1, per tant, 2 pots. Aquesta quantitat coincideix amb X₁ = 2.
– Nombre de pots amb 2 caramels: només el pot 1 té 2, doncs hi ha 1 pot. Això coincideix amb X₂ = 1.
– Nombre de pots amb 3 caramels: cap pot té 3, per tant, 0 pots. Això coincideix amb X₃ = 0.
– Nombre de pots amb 0 caramels: només el pot 3 té 0, per tant, 1 pot. Això coincideix amb X₄ = 1.

La quantitat total de caramels és: 2 + 1 + 0 + 1 = 4.

Resposta: C)
