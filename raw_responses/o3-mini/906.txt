Raonament: Primer, reconeixem que la multiplicació de potències amb la mateixa base es pot simplificar sumant-ne els exponents. Així:

1) 2^(2²) = 2⁴, perquè 2² = 4.
2) 2^(2^(2²)) = 2^(2⁴) = 2¹⁶.

La multiplicació del numerador dóna: 2⁴ · 2¹⁶ = 2^(4+16) = 2²⁰.

Ara, el denominador és ((2²)²)². Realitzem les potències pas a pas:
- Primer, 2² = 4.
- Després, (4)² = 16.
- Finalment, (16)² = 256, i recordem que 256 = 2⁸.

Per tant, l'operació completa és: 2²⁰ : 2⁸ = 2^(20−8) = 2¹².
