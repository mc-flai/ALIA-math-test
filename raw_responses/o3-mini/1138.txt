Raonament: Pensant que abcd representa un nombre enter de quatre dígits (és a dir, abcd = 1000·a + 100·b + 10·c + d) que compleix l’equació

  1000·a + 100·b + 10·c + d = a³ + b³ + c³ + d³,

podem observar el següent. Sigui “S” la suma de cubs: 
  S = a³ + b³ + c³ + d³ ≤ a³ + 3·9³ = a³ + 2187.
D’altra banda, com abcd és de quatre dígits, tenim que abcd ≥ 1000·a.
Així doncs, cal que
  1000·a ≤ a³ + 2187.
Si provem amb diferents valors de a (quèa és la primera xifra del nombre):

  • Si a = 1, aleshores 1000 ≤ 1 + 2187 = 2188 (condició complerta).
  • Si a = 2, aleshores 2000 ≤ 8 + 2187 = 2195 (encara és possible).
  • Si a = 3, aleshores 3000 ≤ 27 + 2187 = 2214, cosa que no es compleix, i per valors majors tampoc.

Per tant, únicament els valors possibles de a serien 1 o 2. Atès que entre les opcions donades no hi ha el 1, hem d’escollir l’altra possibilitat: a = 2.
