Raonament: Denotem les xifres del nombre de tres xifres com a, b i c, amb a ≠ 0. Volem que a + b + c = 3. Considerem els casos possibles per a:

• Si a = 1, aleshores b + c = 2. Les possibles parelles (b, c) són (0, 2), (1, 1) i (2, 0) → 3 formes.
• Si a = 2, aleshores b + c = 1. Les possibles parelles són (0, 1) i (1, 0) → 2 formes.
• Si a = 3, aleshores b + c = 0. La única possibilitat és (0, 0) → 1 forma.

Sumant: 3 + 2 + 1 = 6 nombres.
