Raonament: Sigui k el valor comú tant per a = k, per a b+1 = k, per a c+2 = k, i per a d+3 = k. Així, podem expressar:
  a = k,
  b = k - 1,
  c = k - 2,
  d = k - 3.
El problema també ens diu que a + b + c + d + 4 = k. Sumem a, b, c i d:
  a + b + c + d = k + (k - 1) + (k - 2) + (k - 3) = 4k - 6.
Substituïm en l'equació donada:
  (4k - 6) + 4 = k ⟹ 4k - 2 = k.
Despejant k:
  4k - k = 2 ⟹ 3k = 2 ⟹ k = 2/3.
Per tant,
  a + b + c + d = 4k - 6 = 4*(2/3) - 6 = 8/3 - 6 = (8 - 18)/3 = -10/3.
