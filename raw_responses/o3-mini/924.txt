Raonament: Per comptar els triangles amb costats naturals i perímetre 20, hem de buscar totes les triplets (a, b, c) amb 1 ≤ a ≤ b ≤ c tals que a + b + c = 20 i, a més, es compleixi la desigualtat triangular (a + b > c). Com que amb l’ordenació a ≤ b ≤ c, només és necessari verificar que a + b > c (ja que les altres desigualtats es compleixen automàticament), s’ha dividit el problema en casos segons el valor de a:

1. a = 1: 
   - c = 20 – 1 – b = 19 – b. 
   - La condició b ≤ c implica b ≤ 19 – b → 2b ≤ 19 → b ≤ 9.
   - La desigualtat a + b > c dona: 1 + b > 19 – b → 2b > 18 → b > 9.
   - No existeix b que satisfaci b ≤ 9 i b > 9, per tant, no hi ha solució.

2. a = 2:
   - c = 20 – 2 – b = 18 – b.
   - b ∈ [2,9] (ja que b ≤ c → b ≤ 18 – b → 2b ≤ 18).
   - La desigualtat 2 + b > 18 – b → 2b > 16 → b > 8, per tant, només b = 9.
   - Solució: (2, 9, 9).

3. a = 3:
   - c = 20 – 3 – b = 17 – b.
   - b ∈ [3,8] (per b ≤ c → 2b ≤ 17 → b ≤ 8.5).
   - La desigualtat 3 + b > 17 – b → 2b > 14 → b > 7, per tant, b = 8.
   - Solució: (3, 8, 9).

4. a = 4:
   - c = 20 – 4 – b = 16 – b.
   - b ∈ [4,8] (ja que b ≤ 16 – b → 2b ≤ 16).
   - La desigualtat 4 + b > 16 – b → 2b > 12 → b > 6, així b = 7 i 8.
   - Solucions:
     • b = 7 → c = 16 – 7 = 9 → (4, 7, 9).
     • b = 8 → c = 16 – 8 = 8 → (4, 8, 8).

5. a = 5:
   - c = 20 – 5 – b = 15 – b.
   - b ∈ [5,7] (per b ≤ c → 2b ≤ 15 → b ≤ 7.5).
   - La desigualtat 5 + b > 15 – b → 2b > 10 → b > 5, de manera que b = 6 i 7.
   - Solucions:
     • b = 6 → c = 15 – 6 = 9 → (5, 6, 9).
     • b = 7 → c = 15 – 7 = 8 → (5, 7, 8).

6. a = 6:
   - c = 20 – 6 – b = 14 – b.
   - b ∈ [6,7] (per b ≤ c → 2b ≤ 14 → b ≤ 7).
   - La desigualtat 6 + b > 14 – b → 2b > 8, que es compleix per b ≥ 6.
   - Solucions:
     • b = 6 → c = 14 – 6 = 8 → (6, 6, 8).
     • b = 7 → c = 14 – 7 = 7 → (6, 7, 7).

7. a ≥ 7:
   - No hi ha solució, ja que per a = 7 el mínim de b és 7 i aleshores c = 20 – 7 – 7 = 6, i no es compleix b ≤ c.

• (4, 8, 8)
• (5, 6, 9)
• (5, 7, 8)

En total hi ha 8 triangles diferents.
