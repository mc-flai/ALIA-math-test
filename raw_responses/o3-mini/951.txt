Raonament: Considerem l'equació |x| + |y| = 1, que defineix el contorn d’un rombe, i l’equació x² − y² = 1, que representa una hipèrbola. Per resoldre el sistema, analitzem els diferents casos en funció dels signes de x i y.

1) Si x ≥ 0 i y ≥ 0, llavors |x| = x i |y| = y, per tant l’equació es reduïx a x + y = 1. També podem escriure x² − y² = (x − y)(x + y) = (x − y)·1 = 1, així que obtenim x − y = 1. Resolent el sistema:
  x + y = 1
  x − y = 1
  Sumant: 2x = 2, per tant x = 1 i, substituint, y = 0.

2) Si x < 0 i y ≥ 0, aleshores |x| = −x i |y| = y, i l’equació de la suma d’absolute ens dóna: (−x) + y = 1, és a dir, y − x = 1. La hipèrbola segueix sent x² − y² = 1 i, factoritzant, tenim (x − y)(x + y) = 1. Com que de la primera obtindrem les relacions similars, podem comprovar que també trobarem la solució x = −1 i y = 0, que compleix |−1| + |0| = 1.

3) Els altres dos casos (quan y < 0) donen, després de resoldre, la mateixa solució (considerant que y = 0 pertany a l’una de les regions). Així, les úniques solucions reals que satisfan el sistema són (1, 0) i (−1, 0).

Resposta: B)
