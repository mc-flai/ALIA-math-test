Raonament: Comencem notant que, sent a i b les arrels de x² + x − 7 = 0, compleixen les fórmules de Viète: a + b = −1 i ab = −7. També observem que cada arrel satisfà l'equació, per tant, tenim a² = −a + 7 i b² = −b + 7. Substituïm aquestes expressions en 3a² + 4b² + 2a + 3b + 1:

  3a² = 3(−a + 7) = −3a + 21  
  4b² = 4(−b + 7) = −4b + 28

Així, l'expressió es converteix en:
  (−3a + 21) + (−4b + 28) + 2a + 3b + 1 = (−3a + 2a) + (−4b + 3b) + (21 + 28 + 1)
                 = −a − b + 50
                 = −(a + b) + 50

Sabem que a + b = −1, per tant:
  −(−1) + 50 = 1 + 50 = 51.
