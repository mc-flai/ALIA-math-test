Raonament: Sigui x el nombre de llaunes pintades d’un sol color, y y el nombre de llaunes pintades amb dos colors. Sabem que Maria té 36 llaunes, i que 5 d’aquestes tenen els 3 colors, així que:
  x + y + 5 = 36 ⟹ x + y = 31.

Cada llauna aporta tants “aparellaments de color” com colors té. Per tant, la suma total de colors entre totes les llaunes és:
  1·x + 2·y + 3·5 = x + 2y + 15.

Però també sabem que 25 llaunes tenen blanc, 28 tenen blau i 20 tenen verd, així que la suma de les aparicions dels colors és:
  25 + 28 + 20 = 73.

Així, tenim:
  x + 2y + 15 = 73  ⟹  x + 2y = 58.

Ara tenim el sistema:
  (1) x + y = 31
  (2) x + 2y = 58

Restem (1) de (2): (x + 2y) − (x + y) = 58 − 31, obtenint:
  y = 27.

Substituint-ho a (1): x + 27 = 31 ⟹ x = 4.

Per tant, Maria té 4 llaunes pintades d’un sol color.

Resposta: B)
