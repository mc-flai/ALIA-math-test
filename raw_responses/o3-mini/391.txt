Raonament: Considerem triangles amb costats a, b, c, nombres naturals, amb a ≤ b ≤ c i on a + b + c = 12. A més, han de complir la desigualtat triangular: a + b > c.
 • Si a = 1, aleshores b + c = 11. Probarem els possibles valors de b (amb b ≥ 1) i c = 11 – b; cap d’aquests compleix a + b > c.
 • Si a = 2, aleshores b + c = 10, amb b ≥ 2 i c ≥ b:
  – Si b = 5, c = 5 i es compleix 2 + 5 > 5; per tant, tenim el triangle (2, 5, 5).
 • Si a = 3, aleshores b + c = 9, amb b ≥ 3:
  – Si b = 4, c = 5 i 3 + 4 > 5; obtenim el triangle (3, 4, 5).
 • Si a = 4, aleshores b + c = 8, amb b ≥ 4:
  – Si b = 4, c = 4 i 4 + 4 > 4; aquest triangle és (4, 4, 4).
No es troben altres triades amb a ≤ b ≤ c que compleixin aquestes condicions.
