Raonament: Cal analitzar quantes vegades es talla l'eix X, és a dir, quantes solucions té l'equació f(x)=0 per a cadascuna de les funcions proposades. 
• f(x) = sinx − 1: Es té sinx = 1, que es compleix per x = π/2 + 2πk, amb k enter, donant infinites solucions.
• f(x) = x² − 1: Es té x² = 1, amb solucions x = 1 i x = −1, donant exactament dues interseccions.
• f(x) = eˣ − 1: Solucionant eˣ = 1, obtenim x = 0, només una intersecció.
• f(x) = lnx − 1: Solucionant lnx = 1, n'hi ha una sola solució, x = e.
• f(x) = x⁻¹: Com f(x)=1/x, mai f(x) = 0, per tant la gràfica mai talla l'eix X.
