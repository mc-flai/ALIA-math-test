Raonament: Els anys del segle XXI són els que van de 2001 a 2100. Considerem aquells de la forma “20ab” (on a i b són dígits). La suma de dígits d’un any d’aquest format és 2 + 0 + a + b. Volem que la suma sigui 4, per tant: 2 + a + b = 4, és a dir, a + b = 2. Les solucions amb a i b dígits (0–9) que compleixen a + b = 2 són:
 • a = 0, b = 2 → any 2002.
 • a = 1, b = 1 → any 2011.
 • a = 2, b = 0 → any 2020.
Així, hi ha 3 anys.

Resposta: C)
