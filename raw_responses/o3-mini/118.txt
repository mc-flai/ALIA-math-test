Raonament: Sigui A, B, C i D els nombres de membres dels equips. Segons l'enunciat tenim:
1) A + B = 7.
2) A + D = 9, per tant D = 9 − A.
3) La suma total és A + B + C + D = 15. Substituïm B i D per obtenir:
  A + B + C + (9 − A) = B + C + 9 = 15 ⟹ B + C = 6.
Com que cada equip té almenys 2 membres i els nombres són diferents, provem les possibilitats:
 - Si A = 3, aleshores B = 7 − 3 = 4, D = 9 − 3 = 6, i de B + C = 6 obtenim C = 6 − 4 = 2. Els equips són: 3, 4, 2, 6 (tots diferents i amb mínim 2 membres).
 - Si provéssim altres valors, es trobarien contradiccions (per exemple, A = 2 donaria C = 1, que no és vàlid).

D’aquesta manera, l’equip C té 2 membres.
