Raonament: Hem de trobar una parella de nombres per als quals, si escrivim les seves xifres, així com les xifres del seu suma i la seua diferència, apareguin totes les xifres del 0 al 9, cadascuna una única vegada. Probarem les opcions:

Opció A) 157 i 93  
– Suma: 157 + 93 = 250  
– Diferència: 157 – 93 = 64  
• Xifres: de 157 → 1, 5, 7; de 93 → 9, 3; de 250 → 2, 5, 0; de 64 → 6, 4.  
Observem que el 5 apareix dues vegades i falten altres xifres (per exemple, el 8).

Opció B) 148 i 56  
– Suma: 148 + 56 = 204  
– Diferència: 148 – 56 = 92  
• Xifres: de 148 → 1, 4, 8; de 56 → 5, 6; de 204 → 2, 0, 4; de 92 → 9, 2.  
Aquí es repeteixen els dígits 4 i 2, no obtenint així totes les xifres del 0 al 9 una vegada.

Opció C) 139 i 68  
– Suma: 139 + 68 = 207  
– Diferència: 139 – 68 = 71  
• Xifres: de 139 → 1, 3, 9; de 68 → 6, 8; de 207 → 2, 0, 7; de 71 → 7, 1.  
En aquest cas, els dígits 1 i 7 apareixen dues vegades, i falten altres.

Opció D) 146 i 57  
– Suma: 146 + 57 = 203  
– Diferència: 146 – 57 = 89  
• Xifres: de 146 → 1, 4, 6; de 57 → 5, 7; de 203 → 2, 0, 3; de 89 → 8, 9.  
En conjunt, les xifres són: 1, 4, 6, 5, 7, 2, 0, 3, 8, 9.  
Observem que apareixen totes les xifres del 0 al 9, cadascuna una única vegada.

Opció E) 172 i 39  
– Suma: 172 + 39 = 211  
– Diferència: 172 – 39 = 133  
• Xifres: de 172 → 1, 7, 2; de 39 → 3, 9; de 211 → 2, 1, 1; de 133 → 1, 3, 3.  
Aquí es repeteixen moltes xifres.

Per tant, la parella que compleix la propietat és la de l'opció D).

Resposta: D)
