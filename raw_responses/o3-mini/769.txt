Raonament: Observem primer que 1024 = 2¹⁰, per tant els seus divisors positius són 2⁰, 2¹, 2², …, 2¹⁰.
 • La suma dels divisors a és: 
  a = 2⁰ + 2¹ + … + 2¹⁰ = (2¹¹ − 1)/(2 − 1) = 2¹¹ − 1 = 2048 − 1 = 2047.
 • El producte dels divisors b es pot obtenir utilitzant la fórmula:
  b = 1024^(n/2), on n és el nombre de divisors. Com que n = 10 + 1 = 11, tenim:
  b = 1024^(11/2) = (2¹⁰)^(11/2) = 2^(10·11/2) = 2⁵⁵.
 • Ara, observeu que:
  (a + 1)⁵ = (2047 + 1)⁵ = (2048)⁵ = (2¹¹)⁵ = 2^(11·5) = 2⁵⁵, que és exactament igual a b.
Per tant, la igualtat correcta és (a + 1)⁵ = b.
