 – Opció A: (p + 3q)/4 = q·(x + 3)/4
 – Opció B: (p + 2q)/3 = q·(x + 2)/3
 – Opció C: (p + q)/2 = q·(x + 1)/2
 – Opció D: (2p + q)/3 = q·(2x + 1)/3
 – Opció E: (3p + q)/4 = q·(3x + 1)/4

Comparant cada funció, en particular comparem l'opció A, f(x) = (x + 3)/4, amb les altres:
 • Amb l’opció B: f(x) – [(x + 2)/3] = (3(x + 3) – 4(x + 2))⁄12 = (–x + 1)/12, que és positiu per a x < 1.
 • Amb l’opció C: (x + 3)/4 – (x + 1)/2 = (1 – x)/4, positiu per a x < 1.
 • Amb l’opció D: (x + 3)/4 – (2x + 1)/3 = (5(1 – x))/12, positiu per a x < 1.
 • Amb l’opció E: (x + 3)/4 – (3x + 1)/4 = (1 – x)/2, també positiu per a x < 1.

Per tant, en tots els casos, l’opció A dóna un valor més gran sempre que p < q.
