  3a² + 4b² + 2a + 3b + 1 = 3(–a + 7) + 4(–b + 7) + 2a + 3b + 1

           = (–3a + 2a) + (–4b + 3b) + (21 + 28 + 1)

  –(a + b) + 50 = –(–1) + 50 = 1 + 50 = 51.
