Raonament:

* **Definim variables:**
    *  A = nombre d'alumnes a la primera classe
    *  B = nombre d'alumnes a la segona classe
    *  C = nombre d'alumnes a la tercera classe
    *  D = nombre d'alumnes a la quarta classe

* **Plantejem les equacions:**
    *  (A + B + C) / 3 = 28  (Mitjana d'alumnes en les tres primeres classes)
    *  (A + B + C + D) / 4 = 26 (Mitjana d'alumnes en les quatre classes)

* **Simplificem les equacions:**
    *  A + B + C = 84 
    *  A + B + C + D = 104

* **Despejam D:**
    *  D = (A + B + C + D) - (A + B + C)
    *  D = 104 - 84
    *  D = 20

Resposta: A) 20
