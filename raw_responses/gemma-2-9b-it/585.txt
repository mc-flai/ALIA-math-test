Raonament:

Per a que una potència iguali a 1, la base ha de ser 1 o el seu exponent ha de ser 0. 

* **Cas 1: Base = 1**

   (x² - 4x + 5)^(x²+x-30) = 1 implica que x² - 4x + 5 = 1. 
   Resolent aquesta equació quadràtica, obtenim:
   x² - 4x + 4 = 0
   (x - 2)² = 0
   x = 2 (solució doble)

* **Cas 2: Exponent = 0**

   (x² - 4x + 5)^(x²+x-30) = 1 implica que x² + x - 30 = 0.
   Resolent aquesta equació quadràtica, obtenim:
   (x + 6)(x - 5) = 0
   x = -6 o x = 5

Resposta: B) 3 


L'equació té tres solucions reals distintes: x = 2, x = -6 i x = 5.
