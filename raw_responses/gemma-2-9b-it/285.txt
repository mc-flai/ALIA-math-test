Raonament:

Observem que cada terme de la suma de *b* es pot escriure com la suma de dos termes de la suma de *a*:

*  \(\frac{3}{2} = \frac{1}{2} + 1\)
*  \(\frac{5}{3} = \frac{1}{3} + \frac{2}{3}\)
*  \(\frac{7}{4} = \frac{1}{4} + \frac{3}{4}\)
* ...
*  \(\frac{4033}{2017} = \frac{1}{2017} + \frac{4032}{2017}\)

Si agafem la suma de *b* i la reescrivim, obtenim:

\(b = (\frac{1}{2} + \frac{1}{3} + \frac{1}{4} +... + \frac{1}{2017}) + (1 + \frac{2}{3} + \frac{3}{4} +... + \frac{4032}{2017})\)

Observem que la primera part de la suma és *a*. Per tant:

\(b = a + (1 + \frac{2}{3} + \frac{3}{4} +... + \frac{4032}{2017})\)

I finalment:

\(a + b = a + a + (1 + \frac{2}{3} + \frac{3}{4} +... + \frac{4032}{2017})\)

\(a + b = 2a + (1 + \frac{2}{3} + \frac{3}{4} +... + \frac{4032}{2017})\)

Resposta: No podem determinar el valor exacte de \(a + b\) amb les dades proporcionades.
