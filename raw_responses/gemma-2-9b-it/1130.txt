Raonament:

Si les dues equacions tenen una solució en comú, significa que la x que satisfa una equació també satisfa l'altra.  Podem anomenar aquesta solució en comú "x₀".

Substituint "x₀" en les dues equacions, obtenim:

*  ax₀² + bx₀ + c = 0
*  bx₀² + ax₀ + c = 0

Restant la segona equació de la primera, obtenim:

(a - b)x₀² + (b - a)x₀ = 0

Factoritzant, obtenim:

(a - b)x₀(x₀ - 1) = 0

Això implica que:

* x₀ = 0  o
* x₀ = 1

Per tant, la solució en comú ha de ser 0 o 1.

**Resposta: A)**
