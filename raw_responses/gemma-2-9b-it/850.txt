    * A = diners d'Alba
    * B = diners de Bernat
    * C = diners de Cris
    * D = diners de David

2. **Escrivim les equacions segons la informació del problema:**
    * A + B = 5 
    * C + D = 6
    * A + C = 7

3. **Aïllem una variable en una de les equacions:**
    * Des de A + B = 5, podem obtenir A = 5 - B

4. **Substituïm la variable aïllada en una altra equació:**
    * Substituïm A = 5 - B en A + C = 7:
      (5 - B) + C = 7
      5 - B + C = 7
      C - B = 2

5. **Resolvim per a B + D:**
    * No podem obtenir directament B + D, però podem sumar les equacions C + D = 6 i C - B = 2. Això ens dona:
      (C + D) + (C - B) = 6 + 2
      2C + D - B = 8
      D - B = 8 - 2C
