Raonament:

1. **Definim la variable:** Sigui 'a' la xifra de les centenes, 'b' la xifra de les desenes i 'c' la xifra de les unitats.

2. **Formulació de l'equació:** El problema indica que el nombre (100a + 10b + c) és igual a la suma dels cubs de les seves xifres:
   100a + 10b + c = a³ + b³ + c³

3. **Anàlisi de les opcions:** Observam les opcions i busquem alguna que ens permeti simplificar l'equació. 

   *  **Opció A) a, 0, b:** Si la xifra de les unitats és 0, l'equació esdevindria: 100a + 10b = a³ + b³.  Aquesta equació és difícil de resoldre per prova i error.

   *  **Opció B) a − 1, b, 0:** Si la xifra de les unitats és 0, l'equació esdevindria: 100a + 10b = (a-1)³ + b³.  Aquesta equació tampoc és fàcil de resoldre.

   *  **Opció C) a, b − 1, 0:** Si la xifra de les unitats és 0, l'equació esdevindria: 100a + 10(b-1) = a³ + b³.  Aquesta equació tampoc és fàcil de resoldre.

   *  **Opció D) a, b, 1:** Si la xifra de les unitats és 1, l'equació esdevindria: 100a + 10b + 1 = a³ + b³ + 1.  Aquesta equació es pot simplificar a: 100a + 10b = a³ + b³.

   *  **Opció E) a, 1, b:** Si la xifra de les desenes és 1, l'equació esdevindria: 100a + 10 + b = a³ + 1³ + b³.  Aquesta equació tampoc és fàcil de resoldre.

4. **Simplificació i prova:** L'opció D) (a, b, 1) sembla la més prometedora.  Podem intentar provar amb alguns valors de 'a' i 'b' per veure si trobem una solució.

Resposta: D)
