## Raonament:

Per resoldre aquest problema, hem de considerar les desigualtats i trobar el conjunt de valors de 'a' que satisfacin ambdues.

   *  |a + b| ≤ 1  implica que -1 ≤ a + b ≤ 1
   *  |a - 3b| ≤ 2 implica que -2 ≤ a - 3b ≤ 2

2. **Sistema d'inequacions:**

   Ara tenim un sistema d'inequacions:

   * -1 ≤ a + b ≤ 1
   * -2 ≤ a - 3b ≤ 2

3. **Isolar 'a' en les inequacions:**

   *  a ≥ -1 - b  (de la primera inequació)
   *  a ≤ 2 + 3b (de la segona inequació)

4. **Combinar les solucions:**

   Perquè les desigualtats siguin verades simultàniament, 'a' ha de estar entre els límits establerts per ambdues inequacions:

   -1 - b ≤ a ≤ 2 + 3b

5. **Analitzar el resultat:**

   Observant la desigualtat, no podem determinar un interval exacte per 'a' sense més informació sobre 'b'.  La solució depèn del valor de 'b'.
