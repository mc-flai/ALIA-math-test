Raonament:

1. **Substituïm la definició de l'operació ◊:**
   Tenim que  x◊y = y - x.  Per tant, podem substituir-ho en l'equació donada:
   (a > b) ◇ c = a - (b ◇ c)

2. **Substituïm ◊ de nou:**
   Sabem que (b ◇ c) = c - b. Substituint-ho en l'equació anterior:
   (a > b) ◇ c = a - (c - b)

3. **Simplificació:**
   Simplificant l'expressió:
   (a > b) ◇ c = a - c + b

4. **Analitzem l'equació:**
   L'equació ara és: (a > b) ◇ c = a - c + b.  Aquesta equació no ens permet determinar directament quina relació entre a, b i c és necessàriament certa. 

5. **Considerem les opcions:**
   * A) a = b: No és necessàriament cert.
   * B) b = c: No és necessàriament cert.
   * C) a = c: No és necessàriament cert.
   * D) a = 0: No és necessàriament cert.
   * E) c = 0: No és necessàriament cert.

**Resposta:** Ninguna de les opcions és necessàriament certa. 


La informació proporcionada no és suficient per determinar una relació certa entre a, b i c.
