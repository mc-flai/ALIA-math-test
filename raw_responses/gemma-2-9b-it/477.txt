Per trobar el nombre de divisors naturals d'un nombre, primer cal factoritzar el nombre en els seus factors primers. 

* **Factoritzem 4242:** 4242 = 2 x 3 x 707 = 2 x 3 x 7 x 101

* **Exponentes dels factors primers:** Els exponents dels factors primers són 1, 1, 1 i 1.

* **Calcul del nombre de divisors:** Per calcular el nombre de divisors, suma 1 a cada exponent i multiplica els resultats: (1+1) x (1+1) x (1+1) x (1+1) = 2 x 2 x 2 x 2 = 16
