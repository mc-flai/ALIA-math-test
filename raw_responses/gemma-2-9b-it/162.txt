Raonament: 

Un nombre compost és un nombre que té més de dos factors (o divisors). Un nombre primer només té dos factors: 1 i ell mateix. 

Per escriure un nombre com el producte d'un nombre primer per dos nombres compostos, necessitem que un dels factors sigui primer i els altres dos siguin compostos. 

Analitzem cada opció:

* **A) 25:** 25 = 5 x 5.  No es pot escriure com el producte d'un nombre primer per dos compostos.
* **B) 2·3·4·5:** 2·3·4·5 = 2 x 3 x 2 x 2 x 5.  Es pot escriure com 2 x (2 x 2 x 3 x 5)
* **C) 2·3²·5:** 2·3²·5 = 2 x (3 x 3 x 5). Es pot escriure com 2 x (3 x 3 x 5)
* **D) 6·12:** 6·12 = 6 x 12 = 2 x 3 x 2 x 2 x 3. Es pot escriure com 2 x (2 x 2 x 3 x 3)
* **E) 1000:** 1000 = 2 x 2 x 2 x 5 x 5 x 5. Es pot escriure com 2 x (2 x 2 x 5 x 5 x 5)

 
Resposta: A)
