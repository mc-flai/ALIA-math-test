Raonament:

1. **Definim les variables:**
    *  Sigui 'b' la longitud original de la base del rectangle.
    *  Sigui 'h' l'alçada original del rectangle.

2. **Calcularem l'àrea original:**
    *  Àrea original = base * alçada = b * h

3. **Calcularem les noves dimensions:**
    *  Nova base = b + (20/100)*b = 1.2b
    *  Nova alçada = h - (20/100)*h = 0.8h

4. **Calcularem l'àrea nova:**
    *  Àrea nova = nova base * nova alçada = 1.2b * 0.8h = 0.96bh

5. **Comparamos les àrees:**
    *  L'àrea nova (0.96bh) és menor que l'àrea original (bh).

6. **Calcularem la variació percentual:**
    *  Variació = (Àrea original - Àrea nova) / Àrea original * 100
    *  Variació = (bh - 0.96bh) / bh * 100 = 4%

Resposta: C) L'àrea decreix un 4%.
