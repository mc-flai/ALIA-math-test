Raonament:

1. **Definim variables:**
    *  A = Nombre de membres de l'equip A
    *  B = Nombre de membres de l'equip B
    *  C = Nombre de membres de l'equip C
    *  D = Nombre de membres de l'equip D

2. **Plantejem les equacions:**
    * Sabem que A + B = 7
    * Sabem que A + D = 9
    * Sabem que A, B, C i D són els nombres de membres de cada equip i que la suma de tots els membres és 15: A + B + C + D = 15

3. **Resolvim el sistema d'equacions:**
    * Despejemos A de la primera equació: A = 7 - B
    * Sustituimos A en la segona equació: (7 - B) + D = 9  =>  D = 2 + B
    * Sustituimos A y D en la tercera equació: (7 - B) + B + C + (2 + B) = 15  =>  C + 9 = 15  =>  C = 6
