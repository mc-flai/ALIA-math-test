## Raonament:

Observaràs que cada terme de la suma té la forma  1/(√n + √(n-1)).  Podem racionalitzar el denominador de cada terme per simplificar-lo:

1. **Racionalitzem el denominador:**

   Multiplicam el numerador i el denominador per la conjugada del denominador (√n - √(n-1)):

   ```
   1/(√n + √(n-1)) * (√n - √(n-1))/(√n - √(n-1)) 
   = (√n - √(n-1)) / (n - (n-1))
   = (√n - √(n-1)) / 1
   = √n - √(n-1)
   ```

2. **Simplificació de la suma:**

   Substituint cada terme racionalitzat, la suma original es transforma en:

   ```
   (√2 - √1) + (√3 - √2) + (√4 - √3) +... + (√2016 - √2015)
   ```

   Observaràs que molts termes es cancel·len:

   ```
   √2 - √1 + √3 - √2 + √4 - √3 +... + √2016 - √2015
   = √2016 - √1
   ```

3. **Resposta final:**

   Simplificant √1 = 1, obtenim la resposta final:

   ```
   √2016 - 1
   ```
