Raonament:

Un punt pertany a una recta si i només si les coordenades del punt satisfac l'equació de la recta. Això vol dir que si substituïm les coordenades del punt $P(2,-1)$ en l'equació $ax + by = c$, hauria de ser una igualtat. 

Analitzem cada opció:

* **A) $a = −1, b = 1, c = −3$**:  
   -1(2) + 1(-1) = -2 - 1 = -3. La igualtat es compleix.
* **B) $a = 1, b = 0, c = 2$**: 
   1(2) + 0(-1) = 2. La igualtat no es compleix.
* **C) $a = 0, b = 3, c = −3$**: 
   0(2) + 3(-1) = -3. La igualtat es compleix.
* **D) $a = 10, b = 15, c = 5$**: 
   10(2) + 15(-1) = 20 - 15 = 5. La igualtat es compleix.
* **E) $a = 1, b = 2, c = 1$**: 
   1(2) + 2(-1) = 2 - 2 = 0. La igualtat no es compleix.

Resposta: B) i E)
