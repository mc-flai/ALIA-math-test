Raonament:

1. **Definim variables:**
    *  A = nombre de xiquets al primer autobús
    *  B = nombre de xiquets al segon autobús
    *  C = nombre de xiquets al tercer autobús

2. **Plantejem les equacions:**
    * Sabem que A + B + C = 99 (total de xiquets)
    *  També sabem que A - 3 = B = C (si tres xiquets del primer autobús passen al tercer, tots tres autobusos tindrien el mateix nombre de xiquets)

3. **Resolvim el sistema d'equacions:**
    * Des de la segona equació, podem deduir que A = B + 3 = C + 3
    * Substituïm A en la primera equació: (B + 3) + B + C = 99
    * Simplificem: 2B + C = 96
    * Com que A = B + 3, podem expressar C com C = A - 3
    * Substituïm C en la equació anterior: 2B + (A - 3) = 96
    * Simplificem: 2B + A = 99
    * Substituïm A per (B + 3): 2B + (B + 3) = 99
    * Simplificem: 3B + 3 = 99
    * 3B = 96
    * B = 32
    * A = B + 3 = 35

Resposta: C) 35
