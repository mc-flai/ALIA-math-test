Per trobar les solucions d'una equació quadràtica, podem utilitzar la fórmula quadràtica:

x = (-b ± √(b² - 4ac)) / 2a

En aquest cas, la nostra equació és x² = 2014x + 2015, que podem reescriure com x² - 2014x - 2015 = 0.  

Identifiquem els coeficients:
* a = 1
* b = -2014
* c = -2015

Substituïm els valors a la fórmula quadràtica:

x = (2014 ± √((-2014)² - 4 * 1 * -2015)) / (2 * 1)

x = (2014 ± √(4056196 + 8060)) / 2

x = (2014 ± √(4064256)) / 2

x = (2014 ± 2016) / 2

Això ens dona dues solucions:

* x₁ = (2014 + 2016) / 2 = 2015
* x₂ = (2014 - 2016) / 2 = -1
