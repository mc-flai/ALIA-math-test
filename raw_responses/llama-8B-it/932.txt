Raonament: Per determinar quin dels punts pertany a la gràfica de la funció y = bx + 1, amb b ≠ 0, podem substituir els valors de x en la funció per veure quin punt satisfaça la condició.

- Per al punt (0,0), si x = 0, llavors y = b(0) + 1 = 1. Això no és igual a 0, per tant, el punt (0,0) no pertany a la gràfica.
- Per al punt (1,0), si x = 1, llavors y = b(1) + 1 = b + 1. Això no és igual a 0, per tant, el punt (1,0) no pertany a la gràfica.
- Per al punt (0,1), si x = 0, llavors y = b(0) + 1 = 1. Això és igual a 1, per tant, el punt (0,1) pertany a la gràfica.
- Per al punt (b,0), si x = b, llavors y = b(b) + 1 = b^2 + 1. Això no és igual a 0, per tant, el punt (b,0) no pertany a la gràfica.
- Per al punt (1,-1), si x = 1, llavors y = b(1) + 1 = b + 1. Això no és igual a -1, per tant, el punt (1,-1) no pertany a la gràfica.
- Per al punt (0,-1), si x = 0, llavors y = b(0) + 1 = 1. Això no és igual a -1, per tant, el punt (0,-1) no pertany a la gràfica.

Per tant, només el punt (0,1) satisfaça la condició de pertànyer a la gràfica de la funció y = bx + 1, amb b ≠ 0.
