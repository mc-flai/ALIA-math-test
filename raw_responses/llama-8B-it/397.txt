Comencem per analitzar l'equació donada: tan x + cot x = π. 

Sabem que tan x = sen x / cos x i cot x = cos x / sen x. 

Podem reescriure l'equació com:

sen x / cos x + cos x / sen x = π

Per simplificar, podem multiplicar per sen x cos x:

sen^2 x + cos^2 x = π sen x cos x

Sabem que sen^2 x + cos^2 x = 1 (identitat de Pitagóres). 

Per tant, podem reescriure l'equació com:

1 = π sen x cos x

Per resoldre sen x cos x, podem dividir per π:

sen x cos x = 1/π
