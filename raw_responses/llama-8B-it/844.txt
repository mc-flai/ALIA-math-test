Anem a anomenar els tres angles del triangle A, B i C, on A és l'angle més gran, B és l'angle més petit i C és l'angle mitjà. 

Segons la informació donada, A és el doble de B, per tant A = 2B. 

També sabem que C és la mitjana dels dos angles anteriors, per tant C = (A + B) / 2. 

A més, els tres angles d'un triangle sumen 180°, per tant A + B + C = 180°. 

Podem substituir les expressions per A i C en aquesta equació:

2B + B + (2B + B) / 2 = 180°

Combina els termes:

3B + (3B) / 2 = 180°

Multiplica per 2 per eliminar la fracció:

6B + 3B = 360°

Combina els termes:

9B = 360°

Dividi per 9:

B = 40°

Ara que sabem la mesura de B, podem trobar la mesura de A:

A = 2B
= 2(40°)
= 80°
