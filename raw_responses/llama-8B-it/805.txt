Anem a anomenar la capacitat dels dos barrils "x" litres. 

Com que el primer barril està totalment buit i el segon està completament ple, quan Dani passa 50 litres d'aigua del segon al primer, el primer barril té 50 litres d'aigua i el segon barril té x - 50 litres d'aigua.

Segons la informació donada, el primer conté un 25% més d'aigua que el segon. Això significa que el primer barril té 125% de l'aigua que té el segon barril. 

Podem expressar això com una equació:

50 = (125/100) * (x - 50)

Per resoldre x, podem multiplicar per 100 i dividir per 125:

50 * 100 = 125 * (x - 50)
5000 = 125x - 6250
5000 + 6250 = 125x
11250 = 125x
x = 11250 / 125
x = 90

Per tant, la capacitat dels dos barrils és de 90 litres cadascun.
