3. Per saber el nombre de persones assegudes en els bancs ocupats, sabem que en cada banc ocupat hi ha 2 persones. Això significa que si tenim el nombre de bancs ocupats, podem multiplicar-lo per 2 per obtenir el nombre de persones assegudes en aquests bancs.
4. Per trobar el nombre de bancs ocupats, podem utilitzar la informació que el nombre de bancs lliures és 18 més que el nombre de bancs ocupats. Si tenim el nombre total de bancs (64) i sabem que el nombre de bancs lliures és 18 més que el nombre de bancs ocupats, podem establir una equació per resoldre el nombre de bancs ocupats.
5. Si representem el nombre de bancs ocupats amb la variable "x", podem escriure l'equació: x + (x + 18) = 64. Aquesta equació representa que el nombre de bancs ocupats (x) més el nombre de bancs lliures (x + 18) és igual al nombre total de bancs (64).
6. Resolent l'equació, obtenim: 2x + 18 = 64. Restant 18 de tots dos costats, obtenim: 2x = 46. Dividint per 2, obtenim: x = 23.
7. Això significa que hi ha 23 bancs ocupats.
8. Per saber el nombre de persones assegudes en aquests bancs, podem multiplicar el nombre de bancs ocupats (23) per 2 (perquè en cada banc ocupat hi ha 2 persones). Això ens dona: 23 x 2 = 46.
