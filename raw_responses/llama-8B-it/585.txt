Per a qualsevol valor real de x, el valor de (x² - 4x + 5) és sempre positiu, ja que és una expressió quadràtica amb un terme quadràtic positiu i un terme lineal amb coeficient negatiu. Això significa que el valor de (x² - 4x + 5)^(x²+x-30) només pot ser igual a 1 si (x² - 4x + 5) = 1.

Resolent l'equació (x² - 4x + 5) = 1, obtenim x² - 4x + 4 = 0, que es pot factoritzar com a (x - 2)² = 0. Això significa que x = 2 és la única solució possible per a aquesta equació.

Però, hem de tenir en compte que (x² - 4x + 5) = -1 també és una possibilitat, ja que el valor de (x² - 4x + 5) pot ser negatiu. En aquest cas, (x² - 4x + 5) = -1 té dues solucions reals, x = 2 ± √6.

A més, hem de considerar el cas en què (x²+x-30) = 0, ja que això també podria fer que (x² - 4x + 5)^(x²+x-30) = 1. Resolent l'equació (x²+x-30) = 0, obtenim x² + x - 30 = 0, que es pot factoritzar com a (x + 6)(x - 5) = 0. Això significa que x = -6 o x = 5 són les dues solucions possibles per a aquesta equació.

Per tant, tenim quatre solucions possibles per a l'equació original: x = 2, x = 2 + √6, x = 2 - √6, x = -6 i x = 5.
