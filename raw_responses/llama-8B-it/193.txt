Comencem per analitzar les equacions donades:

1. ac + ad + bc + bd = 68
2. c + d = 4

Volem trobar el valor de a + b + c + d. Per fer-ho, podem intentar relacionar les dues equacions.

Observem que si multiplicamos la segona equació per (a + b), obtenim:

(a + b)(c + d) = (a + b)(4)

Aquesta expressió també es pot escriure com:

ac + ad + bc + bd = 4(a + b)

Però sabem que ac + ad + bc + bd = 68, per tant:

68 = 4(a + b)

Per resoldre a + b, podem dividir ambdós costats per 4:

a + b = 68/4
a + b = 17

Ara, per trobar el valor de a + b + c + d, podem sumar c + d a a + b:

a + b + c + d = (a + b) + (c + d)
= 17 + 4
= 21
