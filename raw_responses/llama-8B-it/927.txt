Raonament: Per trobar el valor de x per al qual a²ˣ – b²ˣ – 2(ab)ˣ = 0, podem començar per simplificar l'equació. Podem factoritzar el terme comú (ab)ˣ:

a²ˣ – b²ˣ – 2(ab)ˣ = (a²ˣ - (ab)ˣ) - (b²ˣ - (ab)ˣ)

A continuació, podem simplificar cada terme:

(a²ˣ - (ab)ˣ) = a²ˣ(1 - (b/a)ˣ)
(b²ˣ - (ab)ˣ) = b²ˣ(1 - (a/b)ˣ)

Això ens dona:

a²ˣ(1 - (b/a)ˣ) - b²ˣ(1 - (a/b)ˣ) = 0

Podem expandir i simplificar l'equació:

a²ˣ - a²ˣ(b/a)ˣ - b²ˣ + b²ˣ(a/b)ˣ = 0

A continuació, podem simplificar els termes:

a²ˣ(1 - (b/a)ˣ) - b²ˣ(1 - (a/b)ˣ) = 0

Podem factoritzar el terme comú (1 - (b/a)ˣ):

(a²ˣ - b²ˣ)(1 - (b/a)ˣ) = 0

Això ens dona dues possibles solucions:

1. a²ˣ - b²ˣ = 0
2. 1 - (b/a)ˣ = 0

Per a la primera solució, podem dividir per a²ˣ:

1 - (b/a)ˣ = 0

Podem resoldre per x:

(b/a)ˣ = 1

x = ln(b)/ln(a)

Per a la segona solució, podem resoldre per x:

1 - (b/a)ˣ = 0

(b/a)ˣ = 1

x = ln(a)/ln(b)

Però aquesta solució no és vàlida perquè a > b. Per tant, la primera solució és la correcta.
