El problema estableix que la suma de les set xifres del nombre aaabbbb és igual al nombre de dues xifres ab. Això significa que podem escriure l'equació:

3a + 4b = 10b + a

Per simplificar l'equació, podem reorganitzar els termes per obtenir:

2a - 6b = 0

A continuació, podem dividir tots els termes per 2 per obtenir:

a - 3b = 0

Ara, podem afegir 3b a ambdues parts de l'equació per obtenir:

a = 3b

Això significa que a és igual a 3 vegades b. Per trobar el valor de a + b, podem substituir a = 3b en l'expressió:

a + b = 3b + b
= 4b

Per trobar el valor de b, podem intentar les opcions de resposta. Si b = 1, a = 3b = 3. Això donaria a + b = 4, que no és una de les opcions de resposta. Si b = 2, a = 3b = 6. Això donaria a + b = 8, que és una de les opcions de resposta.
