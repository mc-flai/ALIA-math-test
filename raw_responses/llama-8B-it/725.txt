Per resoldre aquest problema, podem utilitzar un mètode de prova i error. 

Suposem que el pes màxim del cangur més lleuger és x kg. 

Segons la informació donada, la suma dels tres pesos és 97 kg. 

Podem escriure una desigualtat per representar aquesta situació:

x + (x + 1) + (x + 2) ≤ 97

Aquesta desigualtat representa el fet que el pes màxim del cangur més lleuger és x kg, i els altres dos cangurs pesen un quilogram més que x kg.

Simplificant la desigualtat, obtenim:

3x + 3 ≤ 97

Restant 3 de tots dos costats, obtenim:

3x ≤ 94

Dividint tots dos costats per 3, obtenim:

x ≤ 31,33

Com que x ha de ser un nombre enter, el valor màxim possible de x és 31.
