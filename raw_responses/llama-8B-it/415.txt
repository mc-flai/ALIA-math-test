Per resoldre aquest problema, podem començar per observar les dues equacions donades:

1. 2017 + x = y²
2. 2017 + y = x²

Podem restar la segona equació de la primera per obtenir:

x² - y² = y - x

Aquesta expressió es pot simplificar utilitzant la fórmula de diferència de quadrats:

(x + y)(x - y) = y - x

Dividint per (x - y), obtenim:

x + y = -1

Ara, podem substituir aquesta expressió per x + y en les dues equacions originals:

1. 2017 + x = y²
2. 2017 + y = (-1 - y)²

Simplificant la segona equació, obtenim:

2017 + y = 1 + 2y + y²

Restant 2017 de totes dues parts, obtenim:

y = 2y + y²

Reordenant els termes, obtenim:

y² + y - 2y = 0

y² - y = 0

Factoritzant, obtenim:

y(y - 1) = 0

Això significa que y = 0 o y = 1. Però si y = 0, llavors x = -2017 (segons la primera equació). Això no és possible, ja que x i y són diferents. Per tant, y = 1.

Ara, podem substituir y = 1 en la primera equació per obtenir:

2017 + x = 1²

x = -2016

Ara que sabem els valors de x i y, podem calcular el producte xy:

xy = (-2016)(1) = -2016
