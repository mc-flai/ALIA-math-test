Per resoldre aquest problema, podem considerar els casos en què x és menor o igual a 2019, x és entre 2019 i 2020, i x és major o igual a 2020.

1. Si x ≤ 2019, llavors |x - 2019| = 2019 - x i |x - 2020| = 2020 - x. Sustituint aquestes expressions a l'equació original, obtenim:

(2019 - x) + (2020 - x) = 3

Combina els termes:

4039 - 2x = 3

Resta 4039 de tots dos costats:

-2x = -4036

Dividir per -2:

x = 2018

Però aquesta solució no és vàlida perquè x ≤ 2019. Això significa que no hi ha solucions per a x ≤ 2019.

2. Si 2019 < x ≤ 2020, llavors |x - 2019| = x - 2019 i |x - 2020| = 2020 - x. Sustituint aquestes expressions a l'equació original, obtenim:

(x - 2019) + (2020 - x) = 3

Combina els termens:

1 = 3

Aquesta equació no té solució, per tant no hi ha solucions per a 2019 < x ≤ 2020.

3. Si x > 2020, llavors |x - 2019| = x - 2019 i |x - 2020| = x - 2020. Sustituint aquestes expressions a l'equació original, obtenim:

(x - 2019) + (x - 2020) = 3

Combina els termes:

2x - 4021 = 3

Suma 4021 a tots dos costats:

2x = 4024

Dividir per 2:

x = 2012

Aquesta solució és vàlida perquè x > 2020.
