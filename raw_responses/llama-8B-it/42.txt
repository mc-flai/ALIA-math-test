Comencem per analitzar les equacions donades:

a = b + 1
b = c + 2
c = d + 3
a + b + c + d + 4 = a + b + c + d

Podem simplificar l'última equació:

a + b + c + d + 4 = a + b + c + d

Restant a + b + c + d de tots dos costats, obtenim:

4 = 0

Aquesta equació és contradictòria, ja que 4 no pot ser igual a 0. Per tant, hi ha alguna cosa que no està bé en les equacions donades.

Però, si observem les equacions anteriors, podem veure que:

a = b + 1
b = c + 2
c = d + 3

Podem substituir aquestes equacions per obtenir:

a = (c + 2) + 1
a = c + 3

I també:

a = (d + 3) + 2
a = d + 5

Ara, podem igualar les dues expressions per a:

c + 3 = d + 5

Restant c de tots dos costats, obtenim:

3 = d + 1

Restant 1 de tots dos costats, obtenim:

2 = d

Ara, podem substituir d = 2 en les equacions anteriors:

c = d + 3
c = 2 + 3
c = 5

I també:

b = c + 2
b = 5 + 2
b = 7

Finalment:

a = b + 1
a = 7 + 1
a = 8

Ara, podem calcular la suma de a, b, c i d:

a + b + c + d = 8 + 7 + 5 + 2
= 22
