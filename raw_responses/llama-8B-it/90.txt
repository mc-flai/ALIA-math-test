Raonament: Per resoldre l'equació x² = 2014x + 2015, podem començar reorganitzant-la per obtenir una equació quadràtica estàndard: x² - 2014x - 2015 = 0. Aquesta equació té la forma ax² + bx + c = 0, on a = 1, b = -2014 i c = -2015.

Per determinar el nombre de solucions reals de l'equació, podem utilitzar la fórmula de la discriminant: Δ = b² - 4ac. Si Δ > 0, l'equació té dues solucions reals. Si Δ = 0, l'equació té una sola solució real. Si Δ < 0, l'equació no té solucions reals.

En aquest cas, a = 1, b = -2014 i c = -2015. Substituint aquests valors a la fórmula de la discriminant, obtenim:

Δ = (-2014)² - 4(1)(-2015)
Δ = 4.058.876 + 8060
Δ = 4.066.936

Com que Δ > 0, l'equació té dues solucions reals.
