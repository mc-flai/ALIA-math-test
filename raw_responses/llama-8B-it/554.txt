Comencem per analitzar les equacions donades:

1. w + x = 3
2. 1/w + 1/x = 1

Volem trobar el valor de x/w + w/x. Per fer-ho, podem començar a manipular les equacions donades.

De la segona equació, podem escriure-la com una fracció comuna:

(1/w + 1/x) = 1
((x + w)/wx) = 1

Multiplicant per wx, obtenim:

x + w = wx

Ara, podem substituir aquesta expressió per w + x a la primera equació:

x + w = wx
w + x = 3

Sobreescriurem la segona equació com:

x + w = 3

Ara, podem dividir per wx:

(x + w)/wx = 3/wx

Per trobar x/w + w/x, podem multiplicar per 2:

2(x/w + w/x) = 2(3/wx)

Ara, podem simplificar:

2(x/w + w/x) = 6/wx

Per trobar x/w + w/x, podem dividir per 2:

x/w + w/x = 3/wx

Ara, podem substituir x + w = wx a la darrera equació:

x/w + w/x = 3/(x + w)

Ara, podem substituir w + x = 3 a la darrera equació:

x/w + w/x = 3/3

x/w + w/x = 1
