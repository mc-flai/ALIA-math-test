Raonament: Per resoldre aquest problema, podem començar representant el nombre N com a 10a + b, on a és la xifra de les deu i b és la xifra de les unitats. La suma de les seues xifres seria a + b.

Segons la informació donada, el quocient de N entre la suma de les seues xifres és 8, per tant, podem establir l'equació:

(10a + b) / (a + b) = 8

Per simplificar l'equació, podem multiplicar tots dos costats per (a + b), obtenint:

10a + b = 8(a + b)

Desenvolupant l'equació, obtenim:

10a + b = 8a + 8b

Restant 8a de tots dos costats, obtenim:

2a + b = 8b

Restant b de tots dos costats, obtenim:

2a = 7b

Dividint tots dos costats per 7, obtenim:

2a/7 = b
